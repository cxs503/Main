## 核心功能

### 1. 工况清单生成（case_generator.py）
- 生成 130 个工况，覆盖四大计算模块：
  - 阻力计算（40 cases）
  - 稳性计算（40 cases）
  - 推进器计算（30 cases）
  - 几何计算（15 cases）
  - 预期失败（5 cases，用于测试失败处理）
- YAML 格式，包含参数范围、判据阈值、执行配置

### 2. 批量执行器（batch_executor.py）
- **并发执行**：ThreadPoolExecutor，最大并发 10
- **状态追踪**：pending → running → success/failed/timeout/skipped
- **失败隔离**：单工况失败不阻塞后续
- **判据校验**：自动检查计算结果 vs 预设阈值
- **超时控制**：单工况超时 30s

### 3. 报告生成器（report_generator.py）
- **4 张可视化图**：
  1. 工况状态分布饼图
  2. 各类别性能对比柱状图
  3. 执行时间分布箱线图
  4. 吞吐量时间线
- **论文级 Markdown 报告**：包含六要素（案例介绍、方法、结果、图表、注意点、误差判定）

## 扩展指南

### 添加新计算模块
1. 在 `batch_executor.py` 的 `ShipCalculationEngine` 中添加计算方法

### 自定义判据
在工况的 `criteria` 字段中设置阈值范围
