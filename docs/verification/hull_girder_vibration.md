## 1. 案例介绍

### 1.1 为什么做这件活（欠账定位）

平台 21 项能力清单覆盖 阻力/推进/耐波/操纵/稳性/结构，但**振动噪声学科在物理层是空白**：
改动前 `grep -rn "vibration" backend/services` 只命中数据驱动的机械健康模型
（`monitoring_service` / `fault_prediction_service`），没有任何船体梁结构动力学求解器。
概念设计阶段真正会被问到、且**能用精确解析解核验**的量是：全局垂向船体梁固有频率
（2 节点、3 节点 …）与其对螺旋桨叶频激励的避振裕度。本单即补齐该能力并给出可机器复算的证据。

### 1.2 物理模型

自由-自由 Euler–Bernoulli 梁：

```
EI · d⁴w/dx⁴ = m(x) · ω² · w(x)
```

均匀梁精确解 `w = A cosh(bx) + B sinh(bx) + C cos(bx) + D sin(bx)`，`b⁴ = m ω² / EI`；
自由-自由边界（两端 `M = V = 0`，`M = −EI w''`, `V = M'`）给出超越方程

```
cosh(bL) · cos(bL) = 1
```

根 `bL = 4.7300407448627, 7.8532046240958, 10.9956078380017, 14.1371654912575, 17.2787596573995 …`，
故 `f_n = (b_n L)² / (2π L²) · √(EI/m)`。

## 2. 怎么做的

`backend/services/hull_vibration.py` 内置**三条互相独立**的求解路径，让数值可被对撞而非被信任：

1. **闭式解** `uniform_beam_frequencies`：`cosh·cos = 1` 的根用二分法现算（**不硬编码**常数），
   仅在测试里用 `UNIFORM_BEAM_ROOT_REFERENCE` 当独立参考。
   残差取数值稳定形式 `cos(x) − sech(x)`（`cosh` 在 x ≳ 700 溢出）。
2. **传递矩阵（TMM）** `tmm_frequencies`：状态向量 `[w, w′, M, V]`，
   `u′ = A u`，`A = [[0,1,0,0],[0,0,−1/EI,0],[0,0,0,1],[−mω²,0,0,0]]`，
   每段用 4×4 矩阵指数（自实现 scaling-and-squaring + 20 项 Taylor，numpy-only）精确传播；
   自由-自由条件化为 `det T21(ω) = 0`（T21 = M/V 行 × w/w′ 列），行归一化后符号扫描 + 二分细化。
   **段内精确**，因此是阶梯梁（无闭式解）的参考解。
3. **Hermite 三次梁单元 FEM** `fem_frequencies`：一致质量矩阵，自由-自由，
   经 Cholesky 约化后用 `numpy.linalg.eigh` 解广义特征值问题；弃前 2 个刚体模态。

API：`POST /api/v1/calculations/vibration/hull_girder`（`backend/api/calculations.py`），
返回频率谱、模态、剖面特性、叶频/倍频避振裕度、附连水敏感性、以及**自检告警** `warnings`。

工程量：全部为小型稠密矩阵（≤ 65×65，n_elements=64），单次调用亚秒级——在 load15≈109 的机器上属于轻量活。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **TMM 的符号陷阱**：状态方程第四行必须是 `−mω² w`（`EI w'''' = mω² w` 且 `V = M' = −EI w'''`）。
   写成 `+mω² w` 时扫描只能找到 0 个根——静默失败，不报错。这是本单实际踩到并修正的缺陷。
2. **根的括号不能"每个半波一个根"地猜**：首个根 4.7300 落在 `3π/2 = 4.7124` 之上一丁点，
   第二个根 7.8532 又落在 `5π/2 = 7.8540` 之下一丁点。必须按 `π/2` 网格扫描符号变化。
3. **自由-自由梁的刚体模态不是精确 0**：广义特征值解给 ω² 的绝对误差 ~1e-9，`f = ω/2π` 放大到 ~1e-5 Hz，
   测试容差因此设在 1e-3 Hz（相对首阶弹性频率 <0.2%），而不是拿 `f == 0` 去卡。
4. **剖面理想化明显偏软**：4 板箱梁不计纵骨/纵舱壁/上层建筑，钢材仅占排水质量 3.9%（实船典型 10–20%），
   `I = 943 m⁴` 也低于实船量级。模块据此**主动抛 `warnings`**，并要求知道真实剖面者用
   `I_vertical_m4` / `steel_mass_per_m` 覆写（平台规则"几何必须先验证"）。
   因此 §3.3 的绝对频率只能当量级参考，不能当验证过的设计值。
5. **附连水系经验参数**：0.6 × 排水质量为概念阶段惯例，本仓无任何实船船体梁频率实测，
   故 2-node 频率的不确定度主要由该参数支配（0.497–2.425 Hz 区间），已随结果返回敏感性表。
6. **适用边界**：均匀梁 + 4 板箱梁 + 均布附连水；未含剪切变形/转动惯量（Timoshenko）、
   舱段刚度突变、上层建筑局部模态、阻尼。高阶（≥5-node）与 λ≈船深量级时 Euler–Bernoulli 会高估频率。

## 6. 误差判定（显式回答是否 <3%）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 超越方程根 bL（4 阶） | 独立参考常数 | 2.4e-15 | ✅ 是 |
| 均匀梁 f₁…f₄（TMM） | 闭式解析解 | 2.5e-12 | ✅ 是 |
| 均匀梁 f₁…f₄（FE, 64 单元） | 闭式解析解 | ≤1.6e-6 | ✅ 是 |
| FE 收敛阶 | 理论 4（三次 Hermite） | 观测 3.95–4.01 | ✅ 是 |
| 阶梯梁 FE(64) vs TMM | TMM（段内精确） | ≤7e-7 | ✅ 是 |
| 箱梁剖面 I（等面积极限） | 解析 `A·D²/2 + 2Bt³/12` | 1e-12 | ✅ 是 |
| 实船 2-node 频率绝对值 | **无实测基准**（本仓无实船船体梁频率数据） | — | ❌ 无法判定；只能给量级 + 附连水敏感性 |

结论：**求解器层面全部 <3%（实际 ≤1.6e-6）；实船绝对频率因缺实测基准不做精度宣称**，
已在响应 `warnings`/`notes` 与本节如实标注，不粉饰。
