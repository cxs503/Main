# 船舶阻力计算基准验证报告 [m1602-selfstart]

## 1. 案例介绍

### 物理背景
船舶总阻力系数 Ct 是船舶总体性能的核心参数，由摩擦阻力系数 Cf 和剩余阻力系数 Cr 组成：
- **Ct = Cf + Cr**
- Cf 由 ITTC-1957 摩擦线计算：Cf = 0.075/(log₁₀(Re) - 2)²
- Cr 由简化 Holtrop 方法估算：Cr = 0.002·(1+2·Cb)·Fn^2.5

- DTMB-5415: Cb=0.508, L/B=7.54, B/T=3.09 ✓ (瘦长舰船)
- KVLCC2: Cb=0.8098, L/B=5.52, B/T=2.79 ✓ (肥大油轮)

## 2. 方法

### 计算流程
1. 湿表面积：S = π·B·L·(0.5 + 0.25·Cb) [轴对称近似]
2. 雷诺数：Re = V·L/ν
3. ITTC-1957 摩擦系数：Cf = 0.075/(log₁₀(Re) - 2)²
4. 傅汝德数：Fn = V/√(gL)
5. 剩余阻力系数：Cr = 0.002·(1+2·Cb)·Fn^2.5 (Fn>0.05)
6. 总阻力系数：Ct = Cf + Cr

### 判定标准
- **通过**：|Ct_calc - Ct_exp| / Ct_exp ≤ 15%
- **Honest-FAIL**：方法适用范围外的已知失效（如 SUBOFF 在 Fr>0.4）

## 5. 注意点

### 已识别问题
1. **湿表面积公式不适用于船型**：S = π·B·L·(0.5+0.25·Cb) 是轴对称体近似，对 KVLCC2 等肥大船型严重低估 S，导致 Ct 系统性偏低 ~50%。
2. **Cr 公式在高 Fn 时发散**：Cr ∝ Fn^2.5 在 Fn>0.2 时增长过快，DTMB-5415 在 Fn=0.366 时误差达 602%。
3. **SUBOFF 适用范围**：Holtrop 方法标定于 Cb>0.55 的商船，SUBOFF (Cb=0.508) 在 Fr>0.4 时已超出适用范围。

### 局限
- 当前方法仅适用于中等 Fn (0.1-0.3)、Cb>0.55 的常规船型
- 不适用于：潜艇/回转体 (SUBOFF)、高速瘦长船 (DTMB-5415 高 Fn)、超肥大船 (KVLCC2)

## 6. 误差判定

| 船型 | 最大误差 | 是否<15% | 说明 |
|------|----------|----------|------|
| SUBOFF | 32.1% (SUBOFF-04) | ❌ | Honest-FAIL: Fr>0.4 超出方法适用范围 |
| DTMB-5415 | 602.3% (DTMB5415-04) | ❌ | Cr 公式在 Fn>0.2 时发散 |
| KVLCC2 | 56.1% (KVLCC2-04) | ❌ | 湿表面积公式不适用于肥大船型 |

**结论**：当前简化 Holtrop 方法仅对 SUBOFF 在 Fr<0.77 时可用（3/4 通过），对 DTMB-5415 和 KVLCC2 均不满足 15% 精度要求。

### 改进建议
1. **湿表面积**：改用 Holtrop 原始公式 S = L(2T+B)√Cb·(0.453+0.4425·Cb-0.285·√(Cb-0.035))
2. **剩余阻力**：改用完整 Holtrop-Mennen 方法或 Guldhammer-Harvald 方法
3. **SUBOFF**：改用 slender-body theory 或 CFD (RANS)
