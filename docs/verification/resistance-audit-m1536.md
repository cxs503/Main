# calc.resistance 独立复核报告（m1536 · 验证欠账线）

**结论先行**：平台 `POST /api/v1/calculations/resistance` 自述方法为「ITTC-57摩擦阻力 + Holtrop剩余阻力」，
能力审计将其判为 REAL。本次独立复核（不读端点源码、只按输入输出对基准）判决 **FAIL**：

| 复核对项 | 结果 |
|---|---|
| ITTC-57 摩擦系数 Cf | **PASS**（与解析式一致性 0.01%，实现正确） |
| Re / Fn 无量纲数 | **PASS**（0%） |
| 湿表面积 S | **PASS**（vs 公开基准 27194 m²：+4.2%；vs Denny-Mumford：+4.8%） |
| 总阻力系数 Ct | **FAIL**：+207.7%（KVLCC2@15 kn），全部 9 工况 +200%…+268% |
| 总阻力 RT | **FAIL**：参考 1719 kN，平台 5512 kN（+220.6%） |
| 有效功率 PE | **FAIL**：参考 13.27 MW，平台 42.53 MW（+220.6%） |
| 残余阻力项（k·Cf+Cw+Ca） | **FAIL**：+608%（0.005144 vs 0.0007264） |
| 几何前置校验（Cb ↔ ∇/(LBT)） | **FAIL**：端点接收 `displacement` 但输出与之完全无关 |
| 参考数据集自洽性 | **FAIL**：`benchmark_reference.json` 中 4/12 算例 Ct 与 Rt 互相矛盾 |

**是否有量 <3%？** 只有摩擦侧（Cf、Re、Fn）达成 <3%；**阻力/功率侧全部 >200%**，不存在达标项。

---

## 1. 案例介绍（物理背景 / 几何 / 参数）

静水阻力分解是船舶总体性能的主线：`Rt = (1+k)Rf + Rw + Rb + Rtr + Ra`，其中 `Rf` 由 ITTC-1957
摩擦线决定（对 Re 精确可解），残余项由船型回归式（Holtrop-Mennen 1984）给出。本复核选三条
**公开基准船型**，覆盖低速丰满型 / 中速集装箱船 / 阿芙拉型，使结论不只依赖单一船型：

| 船型 | L [m] | B [m] | T [m] | Cb | Cm | Cwp | ∇ [m³] | 公开 S [m²] | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| KVLCC2 | 320.0 | 58.0 | 20.8 | 0.8098 | 0.9980 | 0.8548 | 312622 | 27194 | Gothenburg 2010 / Tokyo 2015 基准油轮 |
| KCS | 230.0 | 32.2 | 10.8 | 0.6505 | 0.9846 | 0.7350 | 52030 | 9494 | Tokyo 2015 基准集装箱船 |
| AFRAMAX-110k | 244.0 | 42.0 | 14.8 | 0.8200 | 0.9950 | 0.8700 | 124000 | — | Holtrop 标定域代表型 |

几何先验证（平台精度前置规则）：三条船的 `Cb` 与 `∇/(L·B·T)` 自洽性误差 <0.01%，
KVLCC2 湿表面积复算 26490 m² vs 公开 27194 m²（−2.6%），KCS 8845 m² vs 9494 m²（−6.8%，见§5 局限）。

工况矩阵 9 个：KVLCC2 @ {12, 13.5, 15, 16.5} kn，KCS @ {18, 21, 24} kn，AFRAMAX @ {13, 15} kn。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **黑盒探测**：以 `urllib` 直接 POST 端点，输入用公开船型参数（`speed` 单位实测为 kn，年 0.5144 m/s）。
2. **独立参考栈**（`src/ship_verification/holtrop1984.py`，全部为公开文献公式的忠实重写，逐式标注出处）：
   - ITTC-1957：`Cf = 0.075/(log10 Re − 2)²`（解析，可作硬基准）；
   - Holtrop-Mennen 1984 全套：S 回归式、形状因子 `(1+k)`、`iE / c7 / c1 / c2 / c3 / c5 / c15 / c16 / m1 / m4 / λ`、
     波阻 `Rw`、球鼻艏 `Rb`、方尾浸没 `Rtr`、相关津贴 `Ca`；
   - **独立交叉线**：Schoenherr 线（镜像 ITTC-57，用于证明摩擦线实现无误）；
     Denny-Mumford 湿表面积式、Blasius/Prandtl-Schlichting 平板线（量级核对）；
   - **规范侧可行性带**：IMO EEDI 参考线 MEPC.203(62)（tanker：`1218.80·DWT^-0.488`），
     由 PE → PME（η_D=0.72, SFC=175 g/kWh, C_F=3.114）折算 attainable EEDI，检查结果是否物理可行。
3. **判定**：|相对误差| > 15% 记 FAIL（平台精度标准）；几何不过则不采信任何阻力结论。
4. **复数性/复现**：`fetch` 客户端注入式设计，比较逻辑纯函数化 → 31 条 pytest 离线全绿；
   审计产物 JSON/MD/PNG 由 `python -m ship_verification.audit_resistance` 一条命令重放。

```bash
PYTHONPATH=src python3 -m ship_verification.audit_resistance --out outputs/m1536
python3 -m pytest tests/test_ship_verification.py -q   # 31 passed
```

**失真机理可定位**：摩擦项 `Rf = 1517 kN`（平台）vs `1132 kN`（裸船体参考）——差异全部来自端点把
`ΔCf = 0.4e-3` 粗糙度补贴直接并入 Rf（合理但口径不同）；真正的错误在残余项：平台 `RR = 3996 kN`
（系数 0.004744）而参考 `k·Rf + Rw + Ra = 587 kN`（系数 0.000726）——**残余阻力系数被放大 6.5 倍**，
即「Cr_base = 0.005·C4」这一分段拟合式并非文献 Holtrop 结构（Holtrop 的 Cw 由
`c1·c2·c5·∇ρg·exp(m1 Fn^-0.9 + m4 cos(λ Fn^-2))` 给出，低速丰满船 Cw ~ 1e-5 量级）。

### 3.3 输入校验与规范可行性

- **位移探针**：`displacement` ×10 → RT 不变（5512.42 kN 完全相同）⇒ 端点接收位移却不使用，
  几何 Cb/∇ 未经交叉校验（违反「几何必须先验证 Cb/L/B」）。
- **IMO EEDI 交叉核对**（KVLCC2, 312622 dwt, 15 kn）：参考线 2.537 g CO₂/(t·nm)，对应 PME 21833 kW。
  参考栈 PE=13.27 MW ⇒ EEDI 2.141（0.84× 参考线，符合现代 VLCC）；平台 PE=42.53 MW ⇒ EEDI 6.865
  （**2.71× 参考线**，物理不可行）。⇒ 平台结果的错误方向与量级被规范侧独立证实。
- **参考数据集自洽性**：`backend/data/benchmark_reference.json` 的 SUBOFF-01…04 四例中，
  `experimental_ct` 与 `experimental_rt_n` 在**同一几何同一速度**下互不相容（Rt 比 0.5ρV²SCt 小 7.4–9.5 倍，
  相对误差 −86.5%…−89.5%）；另 8 例（DTMB-5415 / KVLCC2）缺 `wetted_surface_m2` 无法校验。
  任何以 Rt 列做判据的门禁都不可信。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **单位陷阱（踩坑）**：端点 `speed` 实为 **kn**（源码语义），首次以 m/s 传入得到 Fn=0.0708 的错误工况；
   本审计已固化 `KM_TO_MS=0.5144` 并在报告中显式写出。
2. **`(1+k)` 重复计入（自研侧踩坑）**：参考实现初版把 `form_factor_1pk()` 的返回值再乘 `(1+k)`，
   导致 KVLCC2 Rt 虚高 66%；已修并加回归测试 `test_form_effect_applied_once`。
3. **端点返回单位**：`rf/rr/rt` 已是 kN、`pe` 已是 kW（不是 N/W），首个版本按 N 处理导致误差符号翻转
   （−99.7%）；已修并写进注释。
4. **参考实现的适用范围**：`ρw`（Fn 相关波阻修正因子）只实现 Fn≤0.4 段（本审计全部工况 Fn≤0.26，安全）；
   Fn>0.4 时结果自动打 `fn_in_rhow_domain=False` 标记，不作结论。`LR` 取 L 近似；L<50 m 的 Ca 低长修正未实现。
5. **KCS 湿表面积偏低 6.8%**：源于 `Cwp=0.735/LCB=-0.7%` 的取值近似，故 KCS 几何项只作 ±10% 有界校验，
   不作 3% 硬判据——如实标注，不用宽容差掩盖。
6. **Holtrop 方法本身的精度**：HM84 对 VLCC 类丰满船常偏高 5–15%（其对标定集的 RMS 约 ±10%），
   因此本次结论建立在「平台偏差 200%+ 远大于方法自身不确定度」的量级差上，而非 3% 级精判；
   真正的 3% 级判据需要模型试验/CFD 结果（SUBOFF/DTMB/KVLCC2 试验 Ct），本轮无离线数据源，**未做**。
7. **未做的事**：未修改 8001 端点源码（该仓不在本工作树白名单内），故只出复核判决与参考实现；
   `optimizer/interfaces/resistance_eval.py` 自标 MOCK 且残余式同源失真，建议一并切换本参考内核（未改，避免越界）。

**判定**：摩擦/无量纲数侧 <3% 达标；**阻力-功率主链不达标（≥200%，超可接受门 15% 的 13 倍以上）**。
建议平台把 `calc.resistance` 的能力等级由 REAL 下调为 **MOCK（自述 Holtrop，实为分段拟合）**，
直至以 `src/ship_verification/holtrop1984.py` 作内核替换并补 Cb↔∇/(LBT) 一致性门；
同时修正 `benchmark_reference.json` 的 Ct/Rt 列（或以 Ct 列为唯一判据）。
