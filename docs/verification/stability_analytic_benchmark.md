# 稳性能力解析基准复核（wall-sided barge benchmark）

> 类型：验证欠账清偿（verification debt） · 目标能力：`calc.stability`（平台 `POST /api/v1/calculations/stability`，审计等级 REAL）
> 解析基准：矩形直立舷（wall-sided）驳船，全部静水力有闭式解
> 工件：`artifacts/stability_benchmark/benchmark.json`、`gz_verification.png`、`error_envelope.png`
> 代码：`backend/services/stability_reference.py`（精确解+衡准包络）、`backend/tests/test_stability_reference.py`（pytest）、`scripts/verify_stability_analytic_benchmark.py`（复算脚本）

## 1. 案例介绍（物理背景/几何/参数）

平台稳性端点输入 L/B/T/D、排水量、Cb、KG，输出 kb/bm/gm、GZ 曲线特征量（gz_max、φ_gzmax、消失角）与 IMO 完整稳性衡准面积（A0-30、A30-40、A0-40）。这些量只有在**几何与静水力同时有闭式解**的船型上才能做到零争议对标，因此基准取矩形驳船（Cb≡1，无舷弧、无梁拱、无上层建筑）：

| 参数 | 值 |
|---|---|
| L (垂线间长) | 100.0 m |
| B (型宽) | 20.0 m |
| T (吃水，平浮) | 6.0 m |
| D (型深至甲板边) | 10.0 m |
| KG | 5.0 m |
| 干舷 D−T | 4.0 m |
| ρ | 1.025 t/m³ |
| 排水体积 ∇ = LBT | 12 000 m³ |
| 排水量 Δ = ρ∇ | 12 300 t |

闭式静水力（恒成立，非拟合）：KB = T/2 = **3.0000 m**；BM = I_wl/∇ = B²/(12T) = **5.5556 m**；GM = KB+BM−KG = **3.5556 m**。

## 2. 怎么做的（方法/流程/工具链）

1. **独立精确解**（`stability_reference.py`）：棱柱体横剖面绕纵轴横倾 φ，物体系点 (y,z) → 空间系 Y = y cosφ + z sinφ、Z = −y sinφ + z cosφ。给定水线纵坐标 ζ，浸没高度 h(y) = clip((ζ + y sinφ)/cosφ, 0, D)，在 y 上分片线性；把每片按 h=0 与 h=D 两个交点再分段后**闭式积分**得面积 A、一阶矩 ∫y·h dy、∫h²/2 dy，无求积误差。用二分求 ζ 使 A = B·T（等排水），得浮心 B 的空间坐标，GZ = Y_B − KG·sinφ（即 KN − KG sinφ）。
2. **三重独立校验**：① 小角极限 GZ → GM·sinφ；② 与**多边形裁剪（Sutherland–Hodgman，另一套算法）**互算；③ 与**舷侧直立公式**（文献经典解，见下文）在有效域内互算。
3. **A 臂（闭式公式域）**：平台 `api.calculations.calc_stability` 实现的 GZ = sinφ·(GM + ½·BM·tan²φ)（wall-sided formula，Rawson & Tupper / Biran 经典解），在 0–90° 以 0.1° 步长与精确解逐点比对，求 3%/15% 判据的失效角。
4. **B 臂（在线端点域）**：向 `http://127.0.0.1:8001/api/v1/calculations/stability` POST 上述几何（cb=1.0, displacement=12300 t, kg=5.0），把返回的 kb/bm/gm/gz_max/φ_gzmax/消失角/A0-30/A30-40/A0-40 与精确值逐项对差。
5. 全部数字由 `scripts/verify_stability_analytic_benchmark.py` 程序化写入 `benchmark.json` 并出图，零手抄。

## 3. 计算结果

### 3.1 闭式 wall-sided 公式（平台 `calc_stability` 使用的模型）

| φ [°] | GZ 精确 [m] | GZ 闭式 [m] | 相对误差 |
|---|---|---|---|
| 10 | 0.6324 | 0.6324 | 0.000% |
| 20 | 1.3419 | 1.3419 | 0.000% |
| 21.80（甲板边入水） | 1.4856 | 1.4856 | 0.000% |
| 25 | 1.7139 | 1.7579 | **+2.57%** |
| 30 | 1.9710 | 2.2407 | **+13.69%** |
| 40 | 2.1544 | 3.5426 | **+64.4%** |
| 50 | 1.9676 | 5.7459 | **+192%** |

精确解自身：GZ_max = **2.1574 m @ 39°**（解析曲线峰值），消失角 **90.0°**（矩形剖面横倾到 90° 时 GZ 回零）。

**衡准包络**：wall-sided 公式首次超出 3% 于 **φ = 25.3°**，首次超出 15% 于 **φ = 30.5°**；理论有效上限由甲板边入水角 tanφ = 干舷/(B/2) = 0.4 → **21.80°**（龙骨边出水角 32.01°，故限制项为甲板边入水）。域内误差 < 1e-4%（数值零），域外为纯外插、无物理含义。

由此引出的**第一条结论**：该闭式公式本身可判 REAL，但**适用范围被平台完全无保护地外推**——端点接受任意 `heel_angle_deg`，40° 时臂长高估 64%，IMO 面积随之系统性偏大（A30-40 闭式 +35.1%，A0-40 +16.0%，A0-30 +2.55%），足以把"不满足衡准"的船判成"满足"。

### 3.2 在线稳性端点（`:8001`）对标矩形驳船

| 量 | 平台返回 | 精确值 | 相对误差 | 判据（<3% / <15%） |
|---|---|---|---|---|
| KB | 4.000 m | 3.0000 m | **+33.33%** | 不通过 / 不通过 |
| BM | 5.556 m | 5.5556 m | +0.008% | **通过** |
| GM | 4.556 m | 3.5556 m | **+28.14%** | 不通过 / 不通过 |
| GZ_max | 3.666 m | 2.1574 m | **+69.9%** | 不通过 / 不通过 |
| φ(GZ_max) | 40.0° | 39.0° | −1.0° | **通过** |
| 消失角 | 60.0° | 90.0° | **−30°** | 不通过 / 不通过 |
| A0-30 [m·rad] | 0.6573 | 0.5207 | **+26.2%** | 不通过 / 不通过 |
| A30-40 [m·rad] | 0.5483 | 0.3674 | **+49.3%** | 不通过 / 不通过 |
| A0-40 [m·rad] | 1.2056 | 0.8880 | **+35.8%** | 不通过 / 不通过 |

**定位**：BM 与解析式 B²/(12T) 在 0.01% 内吻合，说明水线面惯性矩与水线面系数链路正确；误差全部由 **KB 偏高 33%** 带入（GM 随 KB 线性传递、GZ 曲线整体抬高），即 KB 采用了不适合 Cb=1 满箱剖面的经验式（满箱剖面精确 KB = T/2，平台给出 2T/3）。消失角 60° 是曲线被削顶后的产物，也源于同一偏差。**结论：REAL 能力在满箱/近箱型剖面上误差超 15% 验收线，属精度缺陷而非证据等级缺陷。**

## 5. 注意点（踩坑/局限/适用范围）

- **踩坑（已修）**：闭式分片积分在"干片残留 −2.9 + 4e-16"这种舍入残差上会滑过"全干/全湿"判据并贡献 −4.29 m² 的负面积，导致 35°/45° 处面积不守恒（误差 7e-3 m²）与 89° 处除零。修法：子段先 clip 到 [0, D]、按 1e-12·D 容差判恒定段、并对重复节点（零宽段）跳过。修后 0–89° 全角域面积守恒误差 ≤ 6e-13 m²。
- **局限 1**：基准是矩形棱柱体。它让"精确解"成为可能，但不能替代带舭圆、舷弧、上层建筑、自由液面的船型验证；对真实船型只能作为**下限标定与公式有效域**的证据。
- **局限 2**：在线端点是黑盒（服务不在本仓内，本单只读扫描无法定位其 KB 经验式源码），因此本单给出的是"偏差幅度 + 归因到 KB"的判定，**未提交对 `:8001` 服务端的修复**；修复建议见下。
- **局限 3**：IMO 面积用梯形法以 0.1° 重采样计算，对 GZ 曲线的折点有小量偏置（`test_imo_areas_*` 用恒值/线性解析曲线锁定了积分器误差 < 1e-9）。
- **适用范围**：结论（3%/15% 判据）只对 wall-sided 剖面成立；对 Cb < 0.9 的船型，KB 经验式的偏差需另作基准（如系列船模 GZ 实测）复核，不宜由本单外推。

**修复建议（交下游单）**：
1. 端点增加几何一致性校验：由 L/B/T/Δ 反算 Cb 与输入 Cb 比对（本单已暴露：Cb=1.0 却给 Δ=12 300 t / 12 000 m³ 的两个口径会被静默接受），并对 Cb > 0.95 的接近箱型剖面上切换到 KB = T/2 类的剖面精确式或至少给出告警。
2. `calc_stability` 返回增加 `validity` 字段：φ 超过甲板边入水角（tanφ = 干舷/(B/2)）时置为 `extrapolated`，避免 40° 级外推静默通过 IMO 判定。

## 6. 误差判定（逐项回答"是否 <3%"）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| 参考解 submerged area 守恒（0–89°） | B·T | ≤ 6e-13 m² | **是** |
| 参考解 vs 多边形裁剪 GZ（2°–60°） | 独立算法 | ≤ 2e-6 相对 | **是** |
| 参考解 小角极限 | GM·sinφ | ≤ 0.2%（φ ≤ 1°） | **是** |
| 闭式公式 GZ（φ ≤ 21.8°） | 精确解 | < 1e-4% | **是** |
| 闭式公式 GZ（φ = 25°/30°/40°） | 精确解 | +2.57% / +13.7% / +64.4% | 否（25.3° 起破坏） |
| 平台 KB（Cb=1 满箱） | T/2 | **+33.33%** | 否 |
| 平台 GM | 3.5556 m | **+28.14%** | 否 |
| 平台 GZ_max / A0-40 | 2.1574 m / 0.8880 | **+69.9% / +35.8%** | 否 |
| 平台 BM / φ(GZ_max) | 5.5556 m / 39° | +0.008% / −1.0° | **是** |

**判定**：参考实现全部锚点达标（<3%）；平台稳性能力在满箱剖面上**未达标**（KB +33%、GM +28%、GZ_max +70%），超过 15% 不可接受线，如实记录为精度缺陷（honest FAIL 项），修复不在本单范围内。
