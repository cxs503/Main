# 轴系扭转振动引擎：解析基准验证与船级社适用性核查（mission m1694）

**结论先行**：平台「振动噪声」学科此前**无任何计算能力**（21 项能力清单无振动项、
`backend/services/` 无实现、研究台无报告）。本单新增引擎
`backend/services/shaft_torsion.py` + 端点 `POST /calculations/vibration/shaft_torsion`，
并用四条解析基准把证据等级钉到 **REAL**：

| 基准 | 独立真值来源 | 实测相对误差 | <3%? |
|---|---|---|---|
| 双惯量链一阶频率 | `f₁=√(k(J₁+J₂)/(J₁J₂))/2π` 闭式 | 1.33e-16 | ✅ |
| 均匀轴自由-自由模态（N=41 节点） | `f_n = n√(G/ρ)/(2L)` 精确谱 | 0.0257% (1 阶) / 0.2312% (3 阶) | ✅ |
| 均匀轴模态（N=81 节点） | 同上 | 0.0064% | ✅ |
| Holzer 表 vs 特征值法（3 站位实船链） | 两法互不共享代码 | 4.34e-14 | ✅ |
| Holzer 表 vs 特征值法（41 节点均匀轴） | 同上 | 3.93e-14 | ✅ |
| 受迫响应 vs 单自由度放大因子 | `1/√((1-r²)²+(2ζr)²)` 闭式 | 5.6e-16 | ✅ |

**不成立的部分（honest）**：实船算例（下表）的两阶频率与轴段应力量值**没有实验/试航
实测值可比**，因此它们是「模型内部一致 + 端到端可复算」的工程估计，绝对精度等级为
**WITHHELD**，不得当作已验证的实船真值引用。

## 1. 案例：直驱六缸二冲程推进轴系

### 1.1 物理背景
主机 9000 kW @ 102 r/min 直驱定距桨。扭转振动关心的核心问题是：任一激励阶次
（螺旋桨叶频 Z=4、柴油机发火阶次 6 及其倍频）在运转转速区间内**是否与轴系扭振固有
频率相遇**，若相遇则轴段扭矩/剪应力放大多少。这是船级社轴系扭振校核（各社规范
"扭振计算提交"条目）的第一层筛选，也决定是否必须装高弹性联轴器/减振器。

### 1.2 几何与参数（1-D 集总模型，3 站位）

| 站位 | 物理量 | 取值 |
|---|---|---|
| 1 螺旋桨（含附连水） | J₁ | 4800 kg·m² |
| 2 中间轴 | J₂ | 700 kg·m² |
| 3 主机回转件+飞轮 | J₃ | 12000 kg·m² |
| 1–2 尾轴 | k₁ = G·J_p/L（d=0.50 m, L=14 m, G=79.3 GPa） | 1.550e+07 N·m/rad |
| 2–3 中间轴 | k₂（d=0.30 m 段折算） | 3.100e+07 N·m/rad |
| 模态阻尼比 | ζ | 0.02 |
| 尾部轴段截面模数 | W_t = πd³/16 | 0.02454 m³ |
| 应力集中系数 | K_t（键槽） | 1.3 |

### 1.3 结果：固有频率与振型

| 阶 | f [Hz] | 归一化振型（桨 / 中间 / 主机） | 节点位置 |
|---|---|---|---|
| 1 | 8.735 | +0.012, +0.001, -0.005 | [1] |
| 2 | 41.876 | -0.002, +0.037, -0.001 | [0, 1] |

刚体模态 = 0.00e+00 Hz（自由-自由链的确认项）。
二阶 = 41.88 Hz 属"双节点"，工程上远高于运转激励带。

### 1.4 结果：Campbell 共振穿越（r/min 20–140）

| 阶 | 激励阶次 q | 共振转速 60f/q [r/min] | 频率 [Hz] | 节点站段 |
|---|---|---|---|---|
| 1 | 12 | 43.68 | 8.735 | [1] |
| 1 | 8 | 65.52 | 8.735 | [1] |
| 1 | 6 | 87.35 | 8.735 | [1] |
| 1 | 4 | 131.03 | 8.735 | [1] |

服务转速 102 r/min 时：
* 叶频（q=4）：一阶共振 131.0 r/min，留出 **+28.5%** 失谐 → `detuned`；
* 发火阶次（q=6，六缸二冲程）：共振 87.4 r/min，留出 **-14.4%** → `detuned`。

即：常用设计准则（1 节点 ≥ 10% 失谐）在该算例上**满足**，无需减振器即可通过第一层筛选。

## 2. 怎么做的

* **方法 A（特征值）**：`K φ = ω² J φ`。`J` 对角正定，故精确对称化为
  `A = J^-0.5 K J^-0.5` 后用**标准**对称特征值求解器，`φ = J^-0.5u`。
* **方法 B（Holzer 表）**：经典的逐站推算——给定试探 ω，从自由端以 Θ₁=1 前推
  `Q_i = Q_{i-1} + ω²J_iΘ_i`、`Θ_{i+1} = Θ_i − Q_i/k_i`，末端残余不平衡扭矩
  `R(ω) = ω² Σ J_iΘ_i` 的零点即固有频率（扫描 + 二分求根）。两法互不共享任何数值机械。
* **受迫响应**：质量归一化模态叠加，常量模态阻尼，跳过刚体模态（故要求激励自平衡，
  否则抛 `ChainError` 而不是给出无界幅值）。
* **基准阶梯**：双惯量闭式 → 均匀轴精确谱（`f_n = n c/2L`, `c=√(G/ρ)`）二阶收敛 →
  N=321 节点极限 → Holzer 交叉 → SDOF 放大因子闭式。
* **工具链**：纯 numpy（无 scipy 广义特征值依赖，见 §4 坑），pytest 38 项全绿，
  图件 matplotlib 生成于 `artifacts/m1694/`，全部数字由
  `tools/m1694_shaft_torsion_report.py` 程序化写入
  `artifacts/m1694/shaft_torsion_metrics.json` 后再注入本报告（零手抄）。

## 3. 误差判定（逐项回答"是否 <3%"）

| 关键量 | 基准 | 相对误差 | <3%? |
|---|---|---|---|
| 双惯量一阶频率 | 闭式 | 1.33e-16 | 是 |
| 均匀轴 1–3 阶频率（N≥41） | 精确谱 | ≤0.2312% | 是 |
| Holzer vs 特征值 | 互为独立法 | 4.34e-14 | 是 |
| 受迫响应幅值 | SDOF 闭式 | 5.6e-16 | 是 |
| 实船算例固有频率/应力绝对量 | 无实测/试航数据 | — | **无法判定（WITHHELD）** |

## 4. 注意点 / 局限 / 踩坑

1. **环境坑（已规避）**：本机 `scipy.linalg.eigh(K, J)`（广义对称，LAPACK `?sygvd`）
   在 n ≥ 41 时**段错误**，n=41 前正常。引擎因此改为 `J^-0.5KJ^-0.5` 精确对称化 +
   标准求解器，数学等价且现在只依赖 numpy；测试里 N 最大到 321 也没问题。
   **后来者请注意**：这不是本模块的边界，是宿主 BLAS/LAPACK 构建问题，凡需广义特征值
   的仓（TensorFEM 等）都应复核。
2. 模型是 1-D 集总扭转链：无陀螺耦合、无轴系回旋（whirl）、无齿轮啮合刚度时变、
   无纵/横向耦合。适用于 1 节点（及更高）扭振固有频率与失谐筛查，**不能**替代 3-D
   FE 转子动力学。
3. 阻尼是常量模态比，模型不给出阻尼估计；实际应由主机厂/联轴器厂家给。
4. 激励谐波扭矩系数 `Q_q` 必须外部给定（主机厂 excitation table / 桨尾流谐波分析），
   本引擎**不合成**这些系数，示例取名义扭矩 2% 仅为演示量级。
5. 实船算例无实测可比 → 绝对量级 WITHHELD；本单验证的是**求解器**，不是这台假想船的
   真实振动水平。
6. 端点在测试环境需 `DATABASE_URL` 指向 sqlite 才能 import（平台栈依赖），已在测试文件
   顶部处理，不影响容器内运行。
