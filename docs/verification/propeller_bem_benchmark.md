# 推进·敞水 BEM 模型的绝对量级复核（m1678）

- 复核对象：`backend/services/propeller_open_water.py`（叶元-动量 BEM 敞水模型）——能力 `propeller.open_water`（`audit_capabilities` 分级 REAL）的物理内核
- 复核基准：① KP505 敞水试验（Iftikhar & Takinaci 2023, Table 2，文献，独立）；② Wageningen B 系列 39/47 项回归（Oosterveld & van Oossanen 1975，`tools/verify/propeller_open_water/reference_bseries.py` 净室实现，独立于被复现代码）
- 生成脚本：`tools/verify/propeller_open_water/bem_benchmark.py`（**本报告全部数字由脚本注入**）
- 工件：`artifacts/m1678/propeller_bem_benchmark/benchmark.json` + fig1–fig4
- 机器判决（headline）：**FAIL（BEM vs KP505 试验：有效推力段最大绝对误差 29.9%，平台门槛 15%）**

## 1. 案例介绍

**物理背景。** 敞水试验把桨从船后分离，在均匀来流中测 `KT(J)`、`KQ(J)`，是推进学科的基准试验。平台此前用硬编码线性代理（`KT = max(0.05, 0.5-0.3J)`、`KQ` 随 `J` 递增、`η0` clamp 在 0.85）充当该能力（m1413 判 MOCK），后由 BEM 模型替换。BEM 模型合并时自陈的证明义务是：

> "No literature point data was reachable offline for mission 1393, so the published verification is analytic-bound + internal-consistency only"

即已发布的验证只有**上界**（`0 < η0 < η_ideal`）与**恒等式**（`η0 = J·KT/(2πKQ)`、Froude 不变性）。上界与恒等式是必要条件，却无法发现「内部自洽、外部偏差 30%」的模型。本单用树内两个独立基准补这一环。

## 2. 方法与工具链

1. **锚点 A（文献试验）**：KP505 表值只读地取自 `backend/data/propulsion_benchmark_reference.json`（本单新增，同时闭合 `docs/audit/m1413_propulsion_verification_debt.md` §6 第 5 项「B 系列/试验表值入库」欠账），并由测试逐点比对 `audit_open_water.py` 中的原始常数，防止两处漂移。
2. **锚点 B（回归）**：`reference_bseries.py` 的 39/47 项多项式，用于扫描（P/D, A_E/A_0, Z）参数面——试验数据不覆盖该面。
3. **误差定义**：`e = 100·(模型 − 基准)/基准`；统计量取平均绝对误差与最大绝对误差。主机统计带 `J∈[0.1, 0.7]`（有效推力段），同时给出全量程 `J∈[0.1, 1.0]`，避免用区间选择美化判决。
4. **判据**：平台标准 15%（超过即不可接受）、论文级 3%，对每个对比量逐项判定。
5. **诊断（不拟合）**：① 匹配同一 `KT` 所需等效螺距比（几何螺距偏置指标）；② 动量耦合项 vs 纯叶元项的推力占比；③ 零推力进速比 `J0` 对比。诊断量只用于归因，**不回写模型**——把拟合试验当验证是本仓明令禁止的伪证据。

## 4. 注意点（坑与局限）

1. **KP505 不是标准 B 系列桨。** 其剖面为弯度型、叶宽/螺距分布不同于 B 系列族，故「B 系列回归 vs KP505 试验」自带模型形式偏移；本单用 3.3 三路分解把这一份额量化，而不是拿它当挡箭牌。
2. **近零推力段相对误差失真。** `J→J0` 时 `KT→0`，相对误差分母趋零；故主机统计带取 `J∈[0.1, 0.7]`，全量程另列作参考。
3. **一级叶元/动量模型的上限。** BEM 未含剖面库（用 `Cl = 2π sinα`、`Cd = 0.012 + α²`）、未含梢涡卷起与桨毂涡损失，对照试验的偏差不可能为零；本单量化的是**偏差有多大**，不是声称 BEM 应当精确。
4. **未覆盖**：空泡、非均匀来流、桨-船干扰（伴流/推力减额）、尺度效应（Rn 修正）。`propeller.open_water` 若被用于自航预报，还需 `w`、`t`、`η_R` 的独立验证。
5. **本单不改模型。** 只做复核与归因；修复方案见 §6，需另立单并各自带判据。

## 7. 结论与建议（按优先级）

1. **降级**：把 `propeller.open_water` 的证据等级从 REAL 降为 MOCK，直到 `e(K_T)` 在有效推力段落到 15% 以内。本单的机器判决为 FAIL（BEM vs KP505 试验：有效推力段最大绝对误差 29.9%，平台门槛 15%）。
2. **修剖面模型**（根因主项）：用弯度型剖面（NACA a=0.8）的零升角与升力线斜率替换 `Cl = 2π sinα`，即在 `α` 中扣除理想迎角；当前实现把弯度剖面的升力完全算成对称剖面，等效螺距比因此系统性偏低（见 3.5 表）。
3. **修叶宽/螺距分布**：`chord_shape = sin(πt)^0.55` 与 B 系列真实叶宽分布差异较大，建议改为 B 系列可实现叶宽分布，并以 `A_E/A_0` 归一。
4. **加回归保护**：把本单 3.1 表作为回归基准（允许的偏差带由修复目标反推），CI 中运行 `pytest tests/verify/test_propeller_bem_benchmark.py`。
5. **不要用拟合消差**：任何把 `KT` 曲线拉向试验的参数整定都必须同时给出独立验证（另一桨型或另一工况带），否则只是把 MOCK 换成 calibrated MOCK。
