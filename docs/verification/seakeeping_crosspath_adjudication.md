# 耐波性双路径一致性裁决（m1679）

**结论一句话**：平台的 `/seakeeping/*`（路径 A，单自由度锚定核心）与数字孪生条带模型（路径 B）
对同一条船、同一海况给出**超出 15% 精度标准**的垂荡/纵摇答案；本单把偏差逐项量化、定位到
3 个实现缺陷与 3 个待裁决约定，并给路径 B 补上遭遇频率开关（默认关，行为零变更）。
绝对精度（对模型试验）仍 **WITHHELD**：离线无水池数据，本单不作任何绝对精度宣称。

## ① 案例介绍（物理背景 / 几何 / 参数）

耐波性回答「给定船、给定海况、给定航速，垂荡/纵摇响应多大」。平台有两条互不共享代码的
实现路径，用户从不同端点拿到不同数字，这本身是平台级缺陷。裁决算例取正典基准
`backend/data/benchmark_reference.json` v3.0 的 **KVLCC2-01**（正典 v3.0 为唯一数据裁决者）。

## ② 怎么做的（方法 / 流程）

1. **几何闸门先行**：Cb/L/B 残差 0.0e+00% 通过后才构造模型；两路径喂同一条
   水线（路径 B 水线退化为 Cwp=Cb，已声明，故路径 A 也给 Cwp=Cb），使比较只隔离响应模型差异。
2. **闭式锚点复核**（两条路径都必须满足）：长波极限垂荡 RAO→1（A 1.0051，
   B 1.0099）、SDOF 共振峰 1/(2ζ√(1−ζ²)) = 2.5516 @ r=0.9592、
   高频衰减斜率 -2.313（理论 −2）。
3. **逐项偏差分解**：路径 B 的公式在本工具里被独立重算（`path_b_terms` / `path_b_rao`），
   从而可以「一次只开一个效应」：同网格、同 Smith 因子、加/不加遭遇频率。
4. **判定带收紧**：全频段 RMS 会把 FK-only 的共振带噪声算进判决，故判决只在 λ ≥ 2L 带内出
   （此时 Γ(kL/2) ≥ 0.8 且带内无共振）；共振带单列 **WITHHELD**。
5. **工具链**：`tools/verify/seakeeping/crosspath_adjudication.py` → JSON + 4 图；
   `tests/verify/test_seakeeping_crosspath_m1679.py` 16 条测试锁定裁决事实与缺陷。

### 三个实现缺陷（可判定的硬缺陷）

1. **B 不收航速**：`speed_sensitivity` 中 B 的 0 kn 与 15 kn 垂荡 RAO 完全相同
   （敏感度 0.00%，A 为
   2.97%）。遭遇频率 ωe=ω−kU cosβ 属于运动方程，
   不属于「系数在零航速取值的声明近似」。补开关后 B 敏感度
   18.40%。
2. **B 横浪垂荡恒等于 0**：横浪（β=90°）B 垂荡 RAO=1.20e-08，
   A=1.2606。横浪垂荡有限（被削减）而非零。
3. **两路径频率窗不同**：A 在 0.05–1.50 rad/s（0.008–0.239 Hz）积分，B 自带入口用
   0.03–0.50 Hz、24 个频点 → 同一海况仅换窗即差
   4.90%（垂荡 σ），必须声明。

### 三个待裁决约定

- **Smith 因子**：A 用 e^(−kT)（龙骨值），B 用 e^(−kT/2)（吃水中值平均）；kT=0.53 时比值
  1.304，kT=0.90 时
  1.565 → 共振带可达 2 倍。
- **纵摇附加惯量**：κ55=0.25 vs
  0.806，单此一项把纵摇固有周期拉开
  36.5%（8.95 s vs 12.21 s）。
- **纵向相位 Γ(kL/2)**：A 对纵摇施加、对垂荡不施加（已声明的 FK artefact）。后果：A 的纵摇峰出现在
  ω=0.050 rad/s 而纵摇固有频率是
  0.702 rad/s，峰位偏离共振 —— 需衍射项才能修正，
  故共振带判 WITHHELD。

## ⑤ 注意点（坑 / 局限 / 适用范围）

- **共振带不可判**：两条路径都是 FK-only（无衍射），共振区纵摇量级不可信；本单不在该带出判决，
  也不把「A 更接近真值」当作结论 —— 只能说 A 的结构更完整（含 ωe、含有限横浪垂荡）。
- **南北极都不要抄**：路径 B 的 κ55=0.80 来自 2D 半圆附加质量沿 x² 积分（条带法正统），路径 A 的
  0.25 是常规取值输入；二者都不是「验证过的真值」。
- **KG 是声明输入**：KVLCC2 设计工况 KG=18.56 m 未验证；
  固有周期对 KG 的敏感度已单列（KG±1 m）。
- **路径 B 的 R_AW 无周期依赖**：`C_AW=0.055` 的幂律式对 Hs 平方、
  对波周期完全不敏感（3 s 海况与 12 s 海况同 Hs 给同一 R_AW），故下游「波浪失速/功率增加」仍无精度
  依据 —— 本单只登记该缺口，不冒充验证，也不引入无法核对的公式。
- **频率窗**：任何 σ 比较必须同窗，否则差异是记账而不是物理。

## ⑥ 误差判定（逐项 vs 基准，显式回答是否 <3%）

| 量 | 基准类型 | 误差 | <3%？ |
|---|---|---|---|
| 几何自洽 ∇/(Cb·L·B·T)−1 | 解析恒等式 | 0.0e+00% | **是** |
| 路径 A 长波垂荡 RAO→1 | 解析极限 | 0.51% | **是** |
| 路径 B 长波垂荡 RAO→1 | 解析极限 | 0.99% | **是** |
| 共振峰 1/(2ζ√(1−ζ²)) | 解析解 | <1e−12 % | **是** |
| 高频衰减斜率 vs −2 | 解析渐近 | 15.66% | 否（-2.313，网格/高频段截断所致，非模型错） |
| 路径 A vs 路径 B：垂荡固有周期 | 模型互校 | 3.84% | 否 |
| 路径 A vs 路径 B：纵摇固有周期 | 模型互校 | 36.48% | 否 |
| 路径 A vs 路径 B：垂荡 σ（15 kn） | 模型互校 | 324.12% | 否 |
| 绝对精度 vs 模型试验 | 水池试验 | — | **无基准，声明原因**：离线环境无 tank data，两路径均记 WITHHELD |

**是否满足平台 15% 精度标准？** 跨路径一致性 **不满足**（7/12 项超 15%），
这正是本单交付的结论；绝对精度 **无基准可判**，如实记 WITHHELD，不粉饰。

## ⑦ 裁决与落地

- 路径 A（`backend/services/seakeeping.py`）为 `/seakeeping/*` 响应统计的**唯一正典**（含 ωe、龙骨 Smith、
  纵向相位、有限横浪垂荡，闭式锚点机器验证）。
- 路径 B（数字孪生条带）继续服务 operable/estimator 端点，但必须：①启用遭遇频率开关
  `use_encounter_frequency=True`；②声明本单量化的偏差带；③不得作为路径 A 的独立确认。
- 本次已落地的最小改动：路径 B `regular_response` / `irregular_seastate` 新增
  `use_encounter_frequency`（**默认 False，出厂行为零变更**，回归测试 45 条全绿），并在模块
  docstring 写明「零航速声明仅限系数，遭遇频率属运动方程」。
- 未做（如实登记）：横浪垂荡朝向因子的物理修正、κ55 与 Smith 因子的单一化裁决、R_AW 的周期依赖
  —— 均会重基线化数字孪生端点或需外部基准，超出单干范围，建议后续单独立项。
