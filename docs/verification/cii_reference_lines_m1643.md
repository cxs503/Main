## 1. 案例介绍（物理/规范背景）

平台「绿色航行」学科经 `backend/services/polar/cii.py` 提供 IMO 碳强度指标（CII）链：
参考线 `CII_ref = a · capacity^(-c)`（G1）、年度折减因子 Z（G3）、评级边界 d1..d4（G4）、
达到值 CII 的「燃油质量路径 / 制动能量路径」双算，以及 EEDI/EEXI 关联。

已有的「CII vs 指南」验证函数 `verify_cii_ship_types()` 只做两件事：
(a) 质量路径 vs 能量路径自洽；(b) 复核 Z 时间表与评级边界的**手抄期望值**。
两者都是**自洽检验**：G1 系数表（整部规范中影响最大的一张表）**从未与外部权威比对**，
唯一的守护是「同样的数字复现同样的数字」。

本单复核的算例参数（全部为规范/算例输入，无拟合）：

| 项目 | 值 | 来源 |
| --- | --- | --- |
| 参考线形式 | CII_ref = a·capacity^(-c) | MEPC.353(78) G1 Annex Table 1 |
| 平台存储约定 | `c` 存为有符号指数（即 a·capacity**c） | `constants.CII_REFERENCE_LINES` |
| 容量基准 | DWT（除气体运输船分档） | G1 |
| 复核容量锚点 | 5 000 – 300 000 DWT，共 24 点 | 本单设定 |
| 折减因子 Z | 2023/24/25/26 = 5/7/9/11 % | MEPC.353(78) G3 |
| 评级边界 d1..d4 | 0.86 / 0.94 / 1.06 / 1.18 | MEPC.354(78) G4 |
| 代表性航次 | 20 000 DWT 杂货船，3 000 nm @ 14 kn，85% MCR，SFOC 195 g/kWh，HFO | 算例设定（量级取自 `polar.ships`） |

## 2. 怎么做的（方法与工具链）

1. **外部锚**：把 G1 表独立转录进验证脚本（与生产常量分开存放，避免同源），逐行比对
   `(a, c)`，并在 24 个容量锚点上重算 `CII_ref` 与平台调用值对比。
2. **免文档不变量**（不需要任何文件就能否决错误系数）：
   (i) 量级带 `1 ≤ CII_ref ≤ 100 g/(capacity·nm)`（已公布船队达到值大致落在 2–60）；
   (ii) 随容量严格单调递减（要求指数为负）；
   (iii) 同容量下杂货船/冷藏船参考线必须高于散货船（经验秩序）。
   不变量被写进生产代码 `cii.cii_reference_line_invariants()` 并由测试守护。
3. **后果量化**：用代表性杂货船航次走平台自身的 CII 链，分别以修复前/后的参考线计算
   达到值/要求值比与 A–E 等级，证明缺陷的实际后果。
4. 未实现类别（LNG 船、滚装/客滚/邮轮）**不猜系数**：改为显式 `NotImplementedError`
   （NOT_SUPPORTED），由 `CII_REFERENCE_LINES_NOT_SUPPORTED` 声明。

## 4. 注意点与局限

- **行业后果**：修复前，任何以 `general_cargo` 类别调用 CII 的用户都会得到「要求值小 555 倍 →
  必然 E 级」的结论；这不是精度问题而是可用性问题（评级完全失去分辨力）。
- **同源自洽不是验证**：旧 harness 对 Z 与 d1..d4 的复核是手抄期望值，对系数表则无锚；
  本单把「系数表 → 外部表 + 免文档不变量」补齐，但**不改变**该 harness 的其余结论。
- **不变量必须限定适用容量域**：G1 的气体运输船分两档（≥65 000 / <65 000 DWT），把大档线
  外推到 5 000 DWT 会得到 2.8e3 g/(dwt·nm) 的荒谬值——首版不变量就因此误报，已按类别
  限定容量域（`_CII_VALID_DWT`）。教训：结构性检验也要遵守公式的适用域。
- **未实现类别未猜值**：LNG 船、滚装（车辆）船、滚装货船、客滚船、邮轮在 G1 中确有参考线，
  但离线无规范附件可核，故仅声明 NOT_SUPPORTED；这是 WITHHELD，不是 MOCK。
- **Z 时间表后段未复核**：2027 年及以后 Z 值本单无可靠离线来源，仅复核 2023–2026 四档，
  其余按平台现状（2030 = 11%）保持并标 WITHHELD。
- **绝对 CII 仍未与实船/船队数据对标**：本单只验证参考线与评级映射；单船绝对达到值仍需
  实船油耗-航速-距离数据（WITHHELD，未伪造）。
