# 平台稳性引擎复核：箱形驳船解析基准（mission m1597）

**结论先行**：`POST /api/v1/calculations/stability`（部署版 `ship-performance-platform backend/api/calculations.py (deploy 2026-11-01)`）对箱形驳船（`Cb=1`，全部水力要素有闭式解）的浮心高度 **KB 恒定偏高 +33.3%**，经 GM 传播后最大复原力臂 GZmax 偏高 +241.5%、IMO 曲线面积偏高 +109.7%，稳性消失角被 60° 网格上界截断；5 个基准算例中 4 例出现 IMO 判据**判反**（3 例把不满足判成满足，1 例把满足判成不满足）。按平台证据分级，该能力应从 REAL 降级为 **REAL（摩擦/静水几何正确）+ MOCK（大倾角 GZ 曲线为经验拟合）混合**。

## 1. 案例介绍

横摇复原力臂 GZ(φ) 是完整稳性衡准（IMO IS Code 2008 Part A §2.2）的唯一输入量。经验船型公式（如 KB≈0.5~0.6T）**无法自证**，因此复核必须选取有闭式解的对象：矩形驳船（箱形、直舷、`Cb=1`）。其精确水力要素为

```
∇ = L·B·T ；KB = T/2 ；BM = I_T/∇ = B²/(12·T) ；KM = KB + BM
GZ(φ) = ( GM + ½·BM·tan²φ )·sinφ          （直舷区，精确恒等式）
```

直舷区失效界：舷侧出水（`tanφ = 2T/B`）与甲板边缘入水（`tanφ = (D−T)/(B/2)`）取小者；界外由多边形裁剪精确积分求解（无网格误差）。

基准算例（`artifacts/m1597/stability_audit.json`）：

## 2. 怎么做的

1. **基准实现**：`backend/services/box_hydrostatics.py`（纯标准库，零经验系数）。直舷区内用闭式 `(GM+½BM tan²φ)sinφ`；界外用 Sutherland–Hodgman 半平面裁剪求任意倾角下的浸水截面多边形，面积/形心由 shoelace 精确给出，水位偏移用二分求解使浸水面积恒定等于 `B·T`（静水平衡），浮心/重心投影到世界水平方向得 GZ。
2. **测量尺自校**：直舷区内解析式与多边形解最大偏差 **1.86e-13 m**（机器精度）；GZ 原点斜率 = GM 相对偏差 1e-6；浸水面积守恒相对 1e-12；Simpson 面积 vs 细分梯形相对 3e-5（离散底噪）。
3. **引擎黑盒复核**：`tools/verification/stability_engine_audit_m1597.py` 按 `StabilityInput`（length/beam/draft/displacement/cb/kg）逐算例 POST 真实部署端点（:8001），与基准逐量比对，并核对 6 条 IMO 判据的布尔结论。
4. **引擎公式冻结快照**：`backend/services/stability_engine_audit_snapshot.py` 记录被审引擎源码公式（KB=T(1−Cb/3)、BM=(Cwp²B³/12)/(B·T·Cb)、φ<15° 用小角度式、消失角在 0–60°/5° 网格扫描且缺省 60），用于无网络、无端点时的可复现诊断。
5. **回归测试**：`backend/tests/test_box_hydrostatics.py`（17 项，全部通过）。

## 4. 误差判定（逐项，是否 <3%）

| 量 | 最不利相对误差 | <3%? | 判定 |
|---|---|---|---|
| KB（浮心高度） | +33.4% | 否 | 否——经验公式写错一个系数，影响全部下游量 |
| BM（稳心半径，Cb=1 时） | +0.0% | 是 | 是——箱形极限下 BM 闭式正确 |
| GM（初稳性高度） | +800.0% | 否 | 否——KB 误差直接进入 GM |
| GZmax（最大复原力臂） | +241.5% | 否 | 否——大倾角曲线不可用 |
| A(0–30°) | +152.8% | 否 | 否——面积随 GZ 曲线一起偏大 |
| A(30–40°) | +255.1% | 否 | 否——最大偏差出现在此区间 |
| A(0–40°) | +109.7% | 否 | 否 |

基准自身的可信度：直舷区解析式与多边形精确解偏差 1e-13 m 量级、原位 GM 斜率 1e-6、面积守恒 1e-12 —— 测量尺误差远小于 3%，故上述超差归因于被审引擎而非基准。

## 5. 注意点 / 局限

1. **部署版与源码不一致（如实记录）**：端点返回 GZmax=1.367 m @40° 与源码快照的低角度分支一致，但其后曲线下降，而源码公式继续增长至 60° 时 2.425 m。因此**大倾角分支无法由随包源码复现**（部署构建与仓库快照不同步），本复核只把 ≤40° 作为已验证锚点；60° 样点与依赖它的面积/消失角仅在黑盒层面比较。
2. **端点输入无干舷/型深**：`StabilityInput` 只有 length/beam/draft/displacement/cb/kg，甲板边缘入水与淹湿修正根本无法表达，这是曲线在大倾角失真的结构性原因。
3. **`Cb<1` 无闭式基准**：本复核的绝对误差结论只对箱形驳船成立；对一般船型只能做公式级审查（KB/BM 系数、Cwp 指数），不能给出 GZ 逐点误差。
4. **裁决方向有双向风险**：4/5 算例判反，其中 A、C 两例把「消失角不足 55°」判成满足（偏危险/非保守），D 例把「GZmax 倾角 ≥25°」判成不满足（偏保守）；不存在单向安全偏置，不能靠经验加裕度规避。
5. **修复建议（不在本仓白名单，见派发单）**：KB 改 `T(5/6−Cb/3)`；BM 惯性矩用 `Cwp¹`；GZ 全角度统一用 `(GM+½BM tan²φ)sinφ` 并在 0–90° 细分网格积分；消失角扫描到 90° 且把网格上界如实报告为「≥上界」而非具体角度；补充型深/干舷入参以表达甲板入水。
