## ① 案例介绍（物理背景 / 几何 / 参数）

敞水性能 $K_T(J),K_Q(J),\eta_0(J)$ 是「阻力—推进—能耗」链枢纽。m1393 把旧版硬编码线性代理
（$K_Q$ 随 $J$ 上升、$\eta_0$ 截断平台，MOCK 级）替换为第一性原理条带法核，但其发布验证**只有
解析界 + 内部自洽**（当时离线无文献点数据）。m1585 随后把 O&O 1975 真系数表落进本仓，本单即清偿
「BEM 核从未对文献基准复核」这条欠账：用标准 Wageningen B 系列桨型做定量对账。

轴向诱导速度二分 + 切向固定点。ρ=1025 kg/m³。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **参考侧守门**：先验证 O&O 参考自身（39/47 项规模、$K_T$ 单调降、$\eta_0<\eta_{ideal}$ 动量界），
   确认尺子是 REAL 再量船。
2. **双核重放**：同一 J 网格上分别用 BEM 核（`open_water_point`）与 O&O 回归（`open_water`）
   逐点求 $K_T,K_Q,\eta_0$；零推力点 $J_0$ 各自二分；最佳效率点各自扫描+黄金分割。
3. **误差口径**：相对误差在 $K_{T,ref}>0.15$ 的「有效载荷区」统计（避开 $J_0$ 零穿越处
   相对误差发散——那是度量伪影，不是模型误差）。
4. **工具链**：纯 Python + matplotlib，CPU 秒级（本机 load15≈113/128 核，按容量纪律只做轻量活）。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

- **BEM 核不是 B 系列回归**：它用假设弦线形/剖面气动，系统性高估 $K_T$（+22…+30%）与 $K_Q$（+2…+17%）。
  它**不得**作为 B 系列交付值的替代；O&O 回归才是 B 系列的 canonical 参考。
- **相对误差在 $J_0$ 附近发散**是度量伪影（除以趋零的 $K_{T,ref}$），故误差口径限定在有效载荷区；
  工件里保留全网格原始行，可独立复算。
- **$J_0$ 一致性好（−3.7…−10.7%）且 $\eta_{0,max}$ 接近（−0.5…+8.7%）**：说明 BEM 核抓住了
  工作窗口与峰值效率这两个设计关键量，绝对 $K_T/K_Q$ 有系统偏差。
- 适用域：静水、无空化、无桨毂涡细节；高 $J$（>1.2）与低盘面比（<0.3）外推未验证。
- 本单**只复核、未改**任一实现；若要把 BEM 核调成 B 系列复现器，需换真实桨叶几何（另派单）。

## ⑥ 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 实测（BEM） | 参照（O&O） | 相对误差 | <3%? |
|---|---|---|---|---|---|
| $J_0$ (B4-70) | O&O 二分 | 0.9922 | 1.0618 | -6.6% | **否** |
| $\eta_{0,max}$ (B4-70) | O&O 扫描 | 0.7092 | 0.6951 | +2.0% | **否** |
| $K_T$ 有效载荷区 (B4-70) | O&O 回归 | 均值偏差 | — | 均值 +25.8% / 最大 30.5% | **否** |
| $K_Q$ 有效载荷区 (B4-70) | O&O 回归 | 均值偏差 | — | 均值 +12.0% / 最大 17.0% | **否** |
| $\eta_0$ 有效载荷区 (B4-70) | O&O 回归 | 均值偏差 | — | 均值 +12.5% / 最大 19.6% | **否** |
| $\eta_{0,max}$ (B4-55) | O&O 扫描 | 0.6504 | 0.6539 | -0.5% | **是** |

**结论**：BEM 核在结构/物理层面 REAL（动量界、单调性、$J_0$ 窗口、$\eta_{0,max}$ 量级全部成立），
但**不是** B 系列的 <3% 复现器——绝对 $K_T/K_Q$ 偏差 12–30%，超出平台 15% 门槛。
honest 判定：**WITHHELD（值级）/ REAL（结构级）**，与 m1585 对服务端的判级口径一致。
