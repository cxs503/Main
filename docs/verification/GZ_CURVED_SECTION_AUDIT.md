# 曲面剖面大倾角 GZ 引擎：解析基准复核 + 圆舭剖面支持（tp-mod-4 / m1812 models 席）

**一句话结论**：`src/ship_perf/hydrostatics.py` 的大倾角 GZ 路径原先**只能由直边梯形族驱动、
只有 wall-sided 一个（同样只对垂直舷侧精确的）对照**，真实船体的舭圆/曲面剖面无法表达也无基准。
本单（1）补齐「任意多边形剖面」入口与**圆舭剖面生成器**，（2）用**三条互相独立的基准**复核引擎：
圆柱浮筒解析解（KM = R 精确、GZ(θ) 闭式）、圆舭箱体解析静水力（裁角一阶矩）、剖面像素积分交叉。
结论：**引擎在曲面剖面上通过，关键量误差 ≤ 0.6%（远优于平台 15% 判据，亦满足本单 3% 自查线）**；
并给出「判据非空转」证据（把 `Cb·B·T` 冒充圆舭浸没面积，GZ 偏差被推到 1.25%·GZ_max，越过 1% 线）。

- 仓：TensorPlatform，分支 `agent/m1812`
- 被测实现：`src/ship_perf/hydrostatics.py`（`gz_curve_polygon` / `gz_curve` / `section_polygon_bilge_rounded` / `submerged_section_area`）
- 基准工具：`src/ship_verification/gz_curved_benchmark.py`

## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 为什么需要「曲面剖面」基准

平台的 GZ 模型（`gz_curve`）做法是：把横剖面写成多边形 → 逐倾角按**等体积水线**裁剪多边形 →
取浸没面积形心 `(y_B, z_B)` → `GZ = -y_B·cosθ + (z_B - KG)·sinθ`。这是正确的物理模型，
但此前**唯一可用的剖面生成器 `section_polygon(b,T,D,Cb)` 是直边梯形**，而真实船体有舭圆（bilge radius）、
圆舭散货/油船、圆剖面浮筒等。于是存在两处欠账：

1. **能力欠账**：`evaluate_stability` / `gz_curve` 无法表达曲面剖面，圆舭只能当尖舭处理
   （本单量化：同主尺度下舭圆 r=1.5 m 使 GZ 变化最大 0.028 m）；
2. **验证欠账**：唯一的解析对照 `wall_sided_gz` 只在舷侧垂直时精确
   （Cb=1 浮箱；本单复核 max|Δ| = 1.5e-12），对曲面剖面**零基准**（自洽测试不计证据）。

### 1.2 两个解析案例

| 案例 | 几何 | 参数 | 解析可得量 |
|---|---|---|---|
| A `log` 圆剖面浮筒 | 半径 R 的圆柱，半浸没（浸没面积 πR²/2） | R = 5.0 m，KG = 0.8R = 4.0 m（自龙骨起算） | KB = R(1−4/3π) = 2.87793 m；BM = 4R/3π = 2.12207 m；**KM = R = 5.00000 m（精确）**；GZ(θ) 闭式 |
| B `filleted_box` 圆舭箱体 | 宽 B、吃水 T、甲板 D、舭圆半径 r（与平底及舷侧相切） | B = 20 m，T = 6 m，D = 9 m，r = 1.5 m，KG = 3.0 m | A = B·T − (2−π/2)r² = 119.0343 m²；KB = 3.02162 m；BM = (B³/12)/A = 5.60063 m；GM = 5.62225 m |
| B' 尖舭基线 | 同主尺度 r = 0（矩形箱体） | B=20, T=6, KG=3.0 | KB = 3.0 m，BM = 5.55556 m，GM = 5.55556 m |

解析式（A 的 GZ）：浸没弓形半角 α = arccos(h/R)（h 为水线在圆心以下的深度），
面积 `A = R²(α − sinα cosα)`，形心在圆心以下 `d = (2/3)R³ sin³α / A`；
水线系浮心 (0, −d) 旋回船体系后代入 GZ 定义式。（h 由 `A = πR²/2` 反解得 h = 0。）

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **读码定性**：确认 GZ 引擎的核心是 `immersed_section`（Sutherland-Hodgman 半平面裁剪 + shoelace 形心 +
   等体积二分），它本身与剖面形状无关；短板在**入口**（只有梯形生成器）与**基准**（只有 wall-sided）。
2. **最小改动补入口**（不改变既有行为）：
   - 抽出 `gz_curve_polygon(poly, area_target, kg, angles)`；`gz_curve` 改为
     `gz_curve_polygon(section_polygon(...), Cb·B·T, ...)` —— 梯形族逐位不变（有逐位回归测试）；
   - 新增 `section_polygon_bilge_rounded(b, T, D, r, n_arc)`：平底 + 两舷等半径舭圆弧（与平底、舷侧相切）+ 垂直舷侧至甲板；
   - 新增 `section_area` / `submerged_section_area`：**圆舭是从矩形箱体裁角**，`Cb·B·T` 不再是浸没面积，
     必须由几何求面积目标（这条是本单最容易踩的坑，见 §5）。
3. **三条独立基准**（`src/ship_verification/gz_curved_benchmark.py`）：
   - A 解析：圆柱浮筒 KM = R 与 GZ(θ) 闭式；
   - B 解析：圆舭箱体 A / KB / BM / GM 闭式（裁角一阶矩 `z_c = [r³/2 − (πr²/4)(r − 4r/3π)] / a_c`）；
   - C 独立算法交叉：**剖面像素积分**（布尔场 + 逐水线向量化求和 + 体积配平取形心），
     与多边形裁剪完全不同算法；并用 1/3 粗网格估计该基准自身分辨率误差。
4. **小角度 GM 的独立读数**：`GM = dGZ/dθ|₀`（0.5°→1.0° 中心差分），与解析 GM 比较，
   从而不依赖 `km_transverse`（后者只对矩形水线面成立）。
5. **判据前置于动手**：C1–C6 六条（见测试 docstring），并显式加入「判据非空转」检查。

|---|---|---|---|---|---|
| 12 | 3.02409 / 2.87793 | 5.08e−2 | 1.08655 / 1.00000 | 8.65e−2 | 6.04e−3 |
| 24 | 2.91434 / 2.87793 | 1.27e−2 | 1.02594 / 1.00000 | 2.59e−2 | 6.85e−4 |
| 48 | 2.88703 / 2.87793 | 3.16e−3 | 1.00412 / 1.00000 | 4.12e−3 | 8.75e−5 |
| 96 | 2.88021 / 2.87793 | 7.90e−4 | 1.00002 / 1.00000 | 2.29e−5 | 1.10e−5 |

误差随 N 约按 **O(N⁻²)**（每倍 N 降 ~4–8×）收敛，正是内接多边形逼近圆的二阶收敛；
N = 48 时 GZ 全程误差 8.75e−5 m（GZ 量级 1.0 m ⇒ 0.009%）。

**机制观察**：`A` 类的形心本身误差（N=12 时 |ΔKB| = 0.146 m，5%）远大于 GZ 误差（6.0e−3 m），
因为多边形逼近圆时形心沿岸法向偏移几乎与 `cosθ/sinθ` 组合抵消——**GZ 对分面分辨率远比形心本身稳健**；
这一点以前没有证据，容易误判"多边形裁剪不能算曲面剖面"。

**结论：E1–E8 全部 < 3%，且全部 < 1%。** 判据本轮**通过**（不是 WITHHELD）：

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **`Cb·B·T` 不等于圆舭剖面的浸没面积**。圆舭是从矩形箱体裁角，`A = B·T − (2−π/2)r²`。
   沿用 `Cb·B·T` 作等体积目标会把 GZ 推偏 1.25%·GZ_max（C6 量化）。为此新增 `submerged_section_area`，
   并在 docstring 里写明"梯形族与圆舭族不可混用"。
2. **多边形顶点顺序致命**。第一版左舷舭圆弧按 φ 递增写入，使多边形自交，shoelace 面积直接错 12%
   （r=1.5 m 时 105.0 vs 119.0 m²）——自交多边形不会被报错，只会静默给错面积。
   现已按"从舷侧绕回平底"逆时针写入，并用闭式面积 + 收敛性双重守住。
3. **z 基线**：GZ 引擎假定 z 从龙骨（多边形最低点 z=0）起算，`KG` 同基准。
   首次试算把圆心放在 z=0（龙骨在 z=−R）却仍传 `KG=0.8R`，得到"GM<0 的翻船"，属坐标基线错而非引擎错。
4. **wall-sided 不是曲面剖面的基准**。它只在舷侧垂直时精确；直接拿它去校核 Cb≠1 的梯形族会得到
   0.354 m 的假偏差。本单的 C5 因此限定 Cb=1 浮箱。
5. **适用范围**：本单复核的是"给定剖面多边形 + 等体积水线"这条几何通路，二维（横剖面）模型，
   不含纵倾耦合、不含上层建筑/舱室进水；长度方向按单位船长处理（棱柱假设，与 `bm_transverse` 一致）。
6. **未接线**：`evaluate_stability` 仍走梯形族（保持向后兼容），圆舭入口通过
   `gz_curve_polygon + section_polygon_bilge_rounded + submerged_section_area` 显式使用；
   对接 API/服务层属其他仓（ship-performance-platform）职责，本单不动。
