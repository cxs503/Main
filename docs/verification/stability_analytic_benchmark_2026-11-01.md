serving 端点在**矩形剖面（Cb=Cm=Cw=1，唯一可得零经验系数精确解的几何）**上与精确解的系统性偏差为：

三条独立缺陷（源码级定位，`backend/api/calculations.py`）：

1. **浮心高公式错误** `calculate_kb`: `KB = T·(1 − Cb/3)`。矩形剖面给出 0.667T，精确值 0.5T → **+33.3%**；
   Cb=0.5~1.0 全域高于两条独立经验式（Morrish、中剖面式）25~39%，把 GM 抬高 60%（BOX-A）、114%（BOX-B）→ **稳性偏不安全**。
2. **大倾角复原力臂错用 sin²φ** `calculate_gz_curve`: `GZ = (GM + ½BM·sin²φ)·sinφ`，wall-sided 正确形式为 `tan²φ`；
   叠加 φ>40° 的人为收敛因子 `(60−φ)/20`，导致 GZ@50° 偏低 45%、`GZ_max` 偏低 35%，且消失角被硬编码为 60°。
3. **IMO 面积判据继承上述曲线误差**：Area_0_40 高估 40.9%（BOX-A）、77.0%（BOX-B），面积判据结论不可直接用于合规判定。
   另：5° 粗梯形积分的区间判据 `angles[i] ≥ start and angles[i+1] ≤ end` 在端部格点不闭合，进一步引入积分口径偏差。

对照端点 `/methods/hydrostatics/calculate` 物理口径正确（Morrish KB + `tan²φ` wall-sided），
但其排水量/静水力已与 serving 端点**互为独立实现**——同一物理量在两处走不同公式，属实现漂移，须收敛为单一库。

## 3. 方法：参考解怎么来的（零经验系数）

矩形剖面驳船在横倾 φ 时，水线为 `z = d + y·tanφ`，对浸水剖面做 `[0, D]` 裁剪后
**用二分法求解 d 使湿面积严格等于 B·T**（恒定排水体积），再由剖面矩求形心 (ȳ, z̄)，
`KN = ȳ·cosφ + z̄·sinφ`，`GZ = KN − KG·sinφ`。整个过程不含任何经验系数。

三路互校（矩形剖面舷侧垂直，wall-sided 公式在有效角域内是精确解）：

| 路径 | 算法 | 与主解的偏差 (m) |
|---|---|---|
| wall-sided 闭式解 | `(GM + ½BM·tan²φ)·sinφ` | 1.91e-14 |
| 多边形裁剪几何 | Sutherland–Hodgman 裁剪 + 鞋带公式 | 1.78e-14 |
| 恒定排水体积校核 | `A(φ) = B·T` | 2.58e-14（无量纲） |

三路一致性达机器精度（≤1e-13 m）⇒ 参考解可信；精确静水力 KB=4.0000 m、
BM=4.1667 m、GM=2.1667 m、Δ=16400.0 t。

## 7. 注意点与局限

- 精确基准**只对矩形剖面**成立（水线面为矩形时 I_wp、形心才有闭式解）。对真实船型本复核只能给出经验式量级一致性，
  要做 <3% 判据必须引入实际型线（横剖面曲线）并按 ITTC/IMO 的 KN 表法计算——超出本次单机轻量范围。
- 恒定排水体积解在超过甲板入水角后仍是几何精确解，但已不属完整稳性评估域，故 BOX-A 的逐角比较截到 59.5°。
- 平台曲线来自源码复刻（API 不返回曲线）；复刻与 API 聚合量差异 ≤1e-3 已核验。
- 本单为审计+基准，不修改被审计仓库（ship-performance-platform 不在本单 EDIT_WHITELIST 内），修复以独立派单交付：
  **mission 1559**（runner=native，repo=ship-performance-platform）；本单进展报告 **report 1136**。
- 复跑：`python3 scripts/verify_stability_analytic.py`（在线）/ `--offline`；守护：`pytest tests/test_stability_analytic_benchmark.py -q`（22 passed, 3 xfailed(strict) 即已知缺陷形态未变）。

## 8. 建议修复（最小改动）

1. `calculate_kb` → `KB = T·(5/6 − Cb/(3·Cw))`，`Cw` 由输入给出（缺省 `(1+2Cb)/3`）；消除与 `stability_hydrostatics.py` 的实现漂移，统一调用同一库。
2. `calculate_gz_curve` 大倾角项 `sin²φ → tan²φ`；删除 `(60−φ)/20` 人为收敛因子，改为按甲板入水角截断（或接横剖面 KN 表）。
3. 消失角改为在 `GZ(φ)=0` 上真实求根（无根则返回 null/“未消失”），不得硬编码 60°。
4. 面积判据积分区间判据改为 `[angles[i], angles[i+1]] ⊂ [start, end]` 的端部闭合处理，或提高到 1° 网格。
5. 输入自洽性校验：`displacement` 与 `ρ·L·B·T·Cb` 偏差 >3% 时拒绝计算（当前 `displacement` 仅作必填字段、完全未参与物理）。
6. 响应体补 `gz_curve` 字段，使曲线级复核不依赖源码复刻。
