## 1. 案例介绍

### 1.1 物理背景

耐波性研究船舶在波浪中的运动响应。本模块实现 **Salvesen-Tuck-Faltinsen (STF) 纵向切片理论**：
将船体沿纵向离散为 N 站，逐站计算 2D 水动力系数（附加质量 A33、辐射阻尼 B33），
再通过频域耦合方程组求解垂荡(heave)、纵摇(pitch)、横摇(roll) 的 RAO（Response Amplitude Operator）。

## 5. 注意点

### 5.1 局限

1. **略去 m 项**: STF 理论中的端部 Froude-Krylov 修正项未实现，对肥大船型（Cb>0.8）在短波区可能有 2-5% 影响。
2. **Lewis 形截面**: 剖面形状采用 Lewis 形近似，非真实船体型线。对 S175 等瘦削船型误差较小，对 KVLCC2 等肥大船型在舭部区域有偏差。
3. **横摇阻尼**: 采用固定阻尼比 ζ=0.08，实际横摇阻尼强烈依赖于舭龙骨、船型、振幅（非线性）。
4. **深水假设**: 色散关系 k=ω²/g 仅适用于深水(d/L>0.5)，浅水效应未计。

### 5.2 适用范围

- **Fn < 0.3**: 前航速对水动力系数的影响未计（多普勒修正仅在遭遇频率中体现）
- **线性理论**: 仅适用于小振幅波（波陡 ka < 0.1）
- **频率域**: 不适用于瞬态/非线性事件（砰击、甲板上浪）
