# PB-003 镜像复制绕向翻转（对称体一侧斑驳/中线黑缝）

**症状**：左右对称体一侧法向 98.6% 正确、另一侧仅 1.4%；DoubleSide+computeVertexNormals 下共享顶点法向对抵≈中线/艏柱黑缝。

**根因**：镜像复制同序 vstack（y→−y 反射不反绕向）= 整个右舷内外翻。

**治愈**：源头 `(faces+n_half)[:,::-1]` 反绕向；残泡用分段径向多数票保外向。

**勿重蹈**：
①开放面符号体积不可靠、trimesh.fix_inversion 实测会翻反——别用；
②非可定向结构（冲突子图奇环 4637 面无解）= 组合奇偶全局不可满足，**没有全局解，勿反复重试**——
显示层只需求几何法向一致，残量 1.7% 亚视觉噪声留账即可；
③纯 Python 面循环 61.6s 会拖死门禁，scipy csgraph/lexindex 向量化 21.95s（反比基线快 20%）。
