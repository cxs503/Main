# PB-005 门禁必须能失败（假门禁判例）

**症状**：全绿但物理错。TensorSPH 实锤：mass_conserved 拿张量自己比自己（永真）；3 个假门被拆；
密度门禁 3.8% 假过 → 修正测量后 10.0% honest FAIL（10% 门内根本不该过）。

**根因**：判据输入与被测对象同源（自比较/自报告）。

**设计规则**：
1. 判据输入必须独立来源：文献实验数据 / 解析解 / 异实现交叉；
2. 上线前红队自检：故意注入坏值（改一个系数/错一位小数），门必须红——红不了的门不算门；
3. 「修完后指标变差」可能是测量变诚实（见 PB-006），不是退步，禁止回调阈值凑过。

**平台机制**：mutation 轮每周注入种子 bug，门禁抓不到种子 = 验证能力不合格（owner 常设指令第 7 条）。
