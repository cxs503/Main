# PB-002 体素界面奇偶定理（DTMB 5415 水密壳构造判例）

**症状**：STL 水密门禁失败、边共享计数出现奇数、或体积近似正确但门红。

**根因（两条定理）**：
1. **奇偶定理**：纯填充/空界面的边共享计数只允许 {0,2,4}（Q1⊕Q2⊕Q3⊕Q4≡0）。出现奇数边=面放错位：
   d=0/d=1 方向环表交叉（+x 邻居空却发射 a=0 平面→固体内部幻面+界面洞）。体积近似对是孤立细胞自洽的假象。
2. **棋盘夹点**=count4 边（两 core 区仅沿一格棱相接），形态学闭运算只填封闭腔够不着表面；
   正解=**棱级手术**：格棱周围 4 格找对角空格，补 6-邻域 core 多的凹侧（iter1 +50 体素收敛）。

**判读纪律**：STL 无共享索引，process=False 必全边=1，必须 merge(process=True) 后判读；
体积真值=水淹填充（定向无关）；开放网格符号体积不可作基线（18871 作废教训）。

**实证**：127624 面全流形，体积 19568.7 = 水淹 22537.1×0.8683，官方点偏差 mean 0.2356m / p95 0.3608m（0.17%L）。
