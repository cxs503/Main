## 5. 注意点（坑、局限、适用范围）

1. **边界语义是浮点刀锋**：`resonance_margin` 在 |margin| 恰为 15% 时，`(1.15−1)/1 = 0.14999999999999991 < 0.15` 判不通过，而 `(0.85−1)/1 = −0.15000000000000002` 判通过——同一语义边界落在两侧。建议实现改为 `|margin| + 1e-12 >= tol`。本审计把它单列 INFO（非物理误差），并已钉进回归测试防漂移。
2. **场入射 −5 dB 是经验约定，不是物理定义**：它与扩散场精确积分的偏差随频率/面质量变化，在低频/轻质板处偏差最大（见 3.4 表与图 3）。**用它做精确交付时要标注为约定值**，严格场合应按角度积分或 ISO 10140 实测口径。
3. **A 计权的解析式与它自己的标准表值在频带两端有 ~0.13 dB 固有差**（31.5 Hz、16 kHz）：这不是实现错误，是 IEC 61672-1 解析近似与圆整表的差，故这两点门槛放宽到 0.2 dB 并已在测试里注明。
4. **板模型是 Kirchhoff 薄板**（a/h≈150）：厚板、夹层、加筋板格需 Mindlin/正交异性修正，本审计未覆盖。
5. **无基准的量不给假基准**：船体结构阻尼比 ζ、实船设备源级、螺旋桨叶频脉动压力幅值无公开基准，本审计**不编造**，仍标 WITHHELD。
6. **验证的是解析核，不是实船响应**：本单证明「公式实现对」；实际舱室噪声/振动水平取决于阻尼、源级与结构细节，需实测标定，不能由本审计外推。
