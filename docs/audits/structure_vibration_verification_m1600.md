# 结构 / 振动噪声域验证欠账清偿（m1600）：19 条闭式判据、14 项 FAIL、2 项 STUB 定性

- **任务**：m1600（tp-app-2 applications 席自找活）
- **对象**：船舶总体性能平台 `:8001`（`ship-performance-platform`）结构强度与振动噪声两域服务端点
- **判据来源**：第一性原理闭式解 + 公开标准曲线（BS 7608 / DNV RP-C203）+ 平台自身同域实现（跨实现交叉）
- **产物**：`tools/audit/structure_vibration_audit.py`（探针 + 台账 + 出图）、
  `tests/fixtures/structure_vibration_probe.json`（实机探针留痕，25 个端点）、
  `tests/test_structure_vibration_audit.py`（28 项验收）、
  `artifacts/structure_vibration_audit.json`、`artifacts/structure_vibration_audit_tables.md`、
  `artifacts/figures/fig1..fig4.png`
- **一句话结论**：两域共 **19 条判据，5 PASS / 14 FAIL / 0 WITHHELD**；振动域为**单变量经验拟合 + 手调占位**
  （判 MOCK），结构域存在**1e6 量级单位错误 + 剖面模数多乘一个 D + 板格屈曲系数低估 75% + 硬编码应力/应力幅**
  （判 MOCK）；唯一 REAL 的部分是**叶频恒等式**与**平台自有的疲劳寿命内核（BS-D 幂律 + Miner，逐位吻合）**。

## 1. 案例介绍（物理背景 / 几何 / 参数）

结构强度与振动噪声是总布置、板厚与推进轴系选型的直接约束域：结构侧的核心量是总纵弯曲应力
σ = M/Z（M 为总纵弯矩，Z 为 midship 剖面模数）、板格屈曲临界应力 σ_cr 与疲劳累积损伤 D；
振动侧的核心量是船体 2 节点垂向固有频率 f₁、叶频 f_BF = n·rpm/60 与其比值决定的共振风险。

两域在既有 20 篇进展报告中**从未被独立复核**（`/tensor/reports` 全量标题扫描：阻力 12 篇、稳性 4 篇、
耐波/操纵 3 篇、推进 3 篇、绿色 1 篇，结构与振动噪声 0 篇），因此本单属于"验证欠账"类增量。

复核用基准船取 KCS 量级公开几何（无实船数据依赖）：

| 参数 | 符号 | 值 | 单位 |
|---|---|---|---|
| 垂线间长 | L | 230.0 | m |
| 型宽 | B | 32.2 | m |
| 吃水 | T | 10.8 | m |
| 型深 | D | 19.5 | m |
| 排水量 | Δ | 52030 | t |
| 方形系数 | Cb | 0.651 | — |
| 螺旋桨转速 / 叶片数 | rpm / Z | 80 / 5 | rpm / — |
| 板厚（端点默认） | t | 15 | mm |
| 材料 | E / ν / σy | 206 GPa / 0.3 / 235 | — / — / MPa |

几何与参数适配性前置校验：Cb = ∇/(LBT) 由排水量反算 ∇ = Δ/ρ = 50 761 m³，
∇/(LBT) = 50761/(230·32.2·10.8) = **0.635**，与所报 Cb 0.651 相差 2.4% < 15%，
说明基准船几何自洽（本单不对 Cb 误差做进一步裁定，取端点所报值参与弯矩计算）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

三步法，全部机器可算、可重放：

1. **实机探针**（`--probe`）：对 `/api/v1/extended-calculations/vibration`（8 个变体：基准、
   排水量×2、几何相似 λ=1/2 与 λ=1.5、rpm 60/120、叶片 4、吃水×2）、
   `/api/v1/vibration/predict`（3 条不同 ship_id）、`/api/v1/structure/analyze`（6 变体：基准、
   板厚×2、型深×1.5、排水量×2、屈服 355、几何相似 λ=1/2）、`/api/v1/structure/plate`（4 变体）、
   `/api/v1/structure/fatigue`（2 变体）、`/api/v1/fatigue/analyze`、`/api/v1/fatigue/curves`
   共 **25 个端点调用**，原始响应逐条落盘为 fixture（零手抄源头）。
2. **闭式参照**（`build_ledger`）：对每个响应构造一条可判真假的判据，参照量只允许三类——
   (a) 恒等式（叶频）；(b) 闭式解（自由-自由梁 f₁ = (4.7300/L)²/2π·√(EI/m′)、
   箱形剖面 I=(BD³−bd³)/12、Z=I/(D/2)、Euler 板屈曲 σ_cr = kπ²E/(12(1−ν²))·(t/b)²、k=4 ⇒ C=3.6154、
   Miner D = Σn/N、双斜率 S-N N = 10^log a·Δσ^−m）；(c) 平台自身同域实现（`/fatigue/analyze`
   已用 BS-D log a=12.164 并被 S10 逐位验证，故可作为 `/structure/fatigue` 的内部交叉基准）。
3. **判决与出图**：>15% 相对误差判 FAIL（平台精度标准）；三态 PASS/FAIL/WITHHELD。判据集自带
   **反例层测试**：注入一条物理自洽的合成响应，13 条判据必须全部转 PASS，以防"恒 FAIL 的假审计"。

工具链：Python3 + urllib 探针 + matplotlib(Agg) 出图 + pytest 验收；无重算力进程
（本机 load15 = 125 ≥ 100，按容量纪律只做轻量审计，未起 CFD/DEM 作业）。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

1. **单位错误的定位**（`api/structure.py`）：源码 `max_stress = abs(M_total)/Z*1000`，而
   kN·m/m³ = kPa，换算 MPa 应为 `/1000`。方向反了 6 个数量级，与 Z 的第二个错误（见下条）叠加，
   使部署态应力比物理值大 6.4×10⁴ 倍，`utilization` 输出 47 055（应为 O(1)）。
2. **剖面模数多乘一个 D**：平台 Z = B·D²·0.015，而箱形剖面 Z = I/(D/2) ≈ t·B·D（翼板主导）
   + t·D²/3（腹板主导）；闭式 Z 对 D 的幂指数为 **1.200**（由 `box_section_modulus` 数值给出），
   故 σ 对 D 的参照指数 −1.200，实测 −2.0（S2 偏差 66.6%）。同时 `plate_thickness` 完全未进入
   强度通道（S3：板厚加倍应力不变）——即该端点**没有截面模型**。
3. **板格屈曲系数**：平台 σ_cr = 0.9·E·(t/b)²，隐含 k = 0.9/3.6154×4 ≈ 1.0；长板简支单轴经典
   k = 4 ⇒ C = 3.6154，低估 75.1%。此外 `actual_stress ≡ 0.5σy`（S6）是硬编码，安全系数只随 t/b 变化。
4. **S-N 截距脱钩**：`/structure/fatigue` 的 N = 10⁷(100/Δσ)³ 隐含 log a = 13.0，比其自称的
   DNV-C（C1 = 12.164）高 6.8×；而同一服务的 `/fatigue/analyze` 内核与闭式 BS-D 吻合到
   3.6×10⁻⁷（S10 PASS）。即**平台不缺 S-N 知识，是结构分支自成体系**（S9 内部交叉 585%）。据此
   失效归因可精确落在 `/api/v1/structure/*` 三个端点上，而非全平台。
5. **振动的量级陷阱**：V4 显示平台 f_hull=0.99 Hz 恰好落在闭式带 [0.615, 1.077] Hz 内（PASS），
   但 V2/V3 证明其尺度律与质量通道均不成立 —— **量级命中 ≠ 物理正确**，单点比对会把 MOCK 误判为 REAL。
   本单因此对固有频率同时给"量级判据（V4）"与"尺度律判据（V2）+ 灵敏度判据（V3）"，三条并存。
6. **ISO 6954 不可判定**：端点返回 `vertical_vibration=2.12` 无单位、无 1–80 Hz 计权、无谱量，
   却直接映射到"良好/舒适"。按证据分级，这属于 **NOT_SUPPORTED**（不得记 REAL），已在 V7 显式标注。
7. **适用范围**：闭式参照采用"裸壳箱形剖面"作 I/Z 的**保守下界**（真实剖面含纵骨与更厚板，
   Z 可达 1.5–1.75×），因此 S1 的 6.4×10⁴ 倍差是**下界估计**，任何合理剖面都无法弥合；
   固有频率带亦据此放大到 ×1.75。本审计不覆盖：三维舱段 FEM、屈曲后强度、桨-轴-船体耦合振动、
   噪声传播（SEA/BEM）、冰致疲劳等，这些仍是 WITHHELD。
8. **执行环境**：平台 `:8001` 首次 `/vibration/predict` 调用冷启动 ~30 s（首次探针曾超时，已改写为
   预热后重采），`/vibration/predict` 为 POST + 查询参数（GET 返回 405），此类协议细节已记入 fixture。

- 未修改平台源码（`ship-performance-platform` 不在本仓白名单内，本单为纯审计增量）；修复建议已精确到行：
