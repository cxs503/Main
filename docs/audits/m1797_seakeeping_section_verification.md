# m1797 · 耐波内核 2D 剖面水动力对解析基准复核

**复核对象**：`backend/api/seakeeping_physics.py`（mission 1515 审计 D5 判 MOCK 后合入的 STF 型纵向切片内核，
替代原单自由度硬编码振子；覆盖 `/seakeeping/rao`、`/seakeeping/motion`、`/seakeeping-advanced/strip-theory` 三端点）。
**复核类型**：已合并功能 → 独立解析参考复核（非自洽测试）。
**结论**：内核**可解析验证的部分全部通过**（长波 RAO 极限、深水色散精确到机器精度）；
**2D 零频附加质量存在形状盲缺陷**：误差 −11.0%（KVLCC2）～ −47.9%（BARGE60），不满足平台 15% 精度闸门与 3% 严格闸门。

## ① 案例介绍（物理背景 / 几何 / 参数）

切片理论把三维船体辐射-绕射问题降为逐站 2D 剖面问题，剖面的 2D 附加质量 A33 与阻尼 B33
是全船垂荡-纵摇耦合方程组的核心输入，直接决定垂荡自然周期与共振区 RAO 幅值。
内核构式为（与几何无关的曲线拟合）：

    A33_i = ρ·A_i·f_a(ν),  B33_i = ρ·ω_e·b_i²·f_b(ν),  f_a(ν) = 1 − 0.25ν²/(1+ν²),  ν = ω_e²T/g

其中 A_i 为剖面面积、b_i 为水线半宽。**f_a、f_b 只依赖 ν，不含剖面形状信息**——这是本复核的切入点。

解析参考（经典势流，可自证，见 `artifacts/verif/seakeeping_section/lewis_reference.py`）：

- ν = ω²T/g → 0 时线性自由面条件 ∂φ/∂z − (ω²/g)φ = 0 退化为 ∂φ/∂z = 0，**自由面即刚性壁**；
  镜像法给出 **A33(0) = ½·m_a(S ∪ S′)**（严格，任意剖面）。
- 半椭圆剖面（水线半宽 a、吃水 T）双体为整椭圆，m_a = ρπa² ⇒ **A33(0) = ρπa²/2**，
  对剖面排水面积 A_s = πaT/2 归一化 ⇒ **A33(0)/(ρA_s) = a/T**（精确）。
- 两个经典极限自校验：a = T（半圆）比值 = 1 ✔；T→0（半宽 a 平板）m_a = ρπa² 有限而 A_s→0，比值发散 ✔。

计算船（参数表见下）：KVLCC2（320 m 油轮）、KCS（230 m 集装箱船）、BARGE60（60 m 驳船，宽浅型）。

## ② 怎么做的（方法 / 流程 / 工具链）

1. `probe.py` 以 importlib 只读加载内核，取 `sectional_geometry()` 逐站 (b_i, A_i, dx)，
   在 ν = 1e-6 下调用 `section_coefficients()` 取零频 A33，与解析参考逐站对比；
2. RAO 长波极限：直接调用 `solve_rao()`，取 ω ∈ [3e-4, 3e-2] rad/s（kL 低至 3e-6），
   与解析极限 heave→1、pitch→1（rad/(ka)）对比；
3. 深水色散与遭遇频率恒等式精确性检查；
4. 反事实敏感性：monkeypatch `section_coefficients`（**仅内存，不改源文件**），
   把零频幅值换成解析值、保留内核同一条频率因子，重算垂荡 RAO 曲线，量化缺陷对已上线输出的影响；
5. A33 偏差经 T33 = 2π√((m+A33)/(ρgA_w)) 传播为自然周期偏移（工程影响量）；
6. 全部数字由 `probe.py` 写入 `evidence.json`，本文表格与报告 payload 由 `gen_doc.py` 从该工件生成（零手抄）。

工具链：Python 3.11 / numpy / matplotlib(Agg) / pytest 9.2.0。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **等价半椭圆是代理参考**：真实非椭圆剖面（含舭部圆弧、外飘）的 A33(0) 需数值双体解。
   本例用"同水线半宽、同剖面面积"的半椭圆作代理，偏差结论对 b_i 主导的零频极限是量级可靠的，
   但**逐站精确值应以 Lewis close-fit / Ursel 级数或自由面 Green 函数面元为准**。
2. **尝试过独立数值交叉但未采用**：自写常源（Hess-Smith）2D 面元在圆剖面复现闭式解误差 −0.39%，
   但对扁椭圆退化到 ρ·面积、未通过平板极限自校验，故**判定该实现不可用作参考，未纳入证据链**——
   这条如实记录，避免用不可靠数字支撑结论（异离散交叉需重做，已列为后续单）。
3. **B33 未做量级复核**：仅核验了 ν→0 与 ν→∞ 的极限趋势（f_b→0）与 ν≈1 峰值存在，
   量级需 Ursel 级数，超出本单范围。
4. **反事实敏感性偏小（峰值 +1.5%~+2.0%）**：说明该缺陷对"排水量主导"的大型船总体 RAO 峰值影响有限，
   但对附加质量主导的量（浅吃水驳船 T33 偏移 −17.4%、海洋工程小尺度结构）影响显著——
   **不夸大为"耐波全线失真"**。
5. 平台 15% 精度闸门：KVLCC2 −11.0% 在门内但无余量，KCS −25.1% 与 BARGE60 −47.9% 出界。
