## ① 案例介绍（物理背景 / 几何 / 参数）

总体性能的最终交付物是一条**闭合的功率链**，而不是五个域的分数之和：

```
R_T(V)  ->  P_E = R_T V  ->  T = R_T/(1-t)  ->  J = V(1-w)/(nD)  ->  K_T(J), K_Q(J)
        ->  eta_D = eta_O eta_H eta_R  ->  P_D = P_E/eta_D = 2 pi n Q  ->  P_S = P_D/eta_S
```

平台各域都有单点验证记录（阻力 m1536/m1771/m1773、推进 m1498 + 判例 PB-009、
几何 tools/verifier/geometry、稳性 m1785、耐波 m1780），但**域间闭合从未被机器裁判**：
m1498 复核推进域时只能「自算 R_T」绕开阻力端点，这本身就是闭合缺失的证据。主计划
M3「全链集成」因此没有可判门槛。

本单补的就是这一环：把 `/resistance/predict` 与 `/propulsion/predict` 的**各自回答**
互相对撞，判据全部是无需模型常数的恒等式 + 物理区间。

## ② 怎么做的（方法 / 判据 / 工具链）

判据设计原则：**只看端点自己的回答**，不引入任何拟合常数作为基准；
凡是必须用到经验量的地方（推力减额 t、准推进系数 η_D、伴流 w），一律取**物理区间**
并输出区间判据，避免把某个经验公式当成真值（PB-009 的血泪：`method` 字段不是证据）。

| 判据 | 表达式 | 依据 | 容差/区间 |
|---|---|---|---|
| I1 | `P_E = R_T·V` | 定义恒等式（零模型） | ±0.5% |
| I2 | `T = R_T/(1-t)` | 推力平衡；t 只取物理区间 | t ∈ [0.10,0.30] |
| I3 | `P_D = P_E/η_D` | 功率平衡；η_D = η0ηHηR 区间 | η_D ∈ [0.50,0.78] |
| I4 | `T(1-t)V / (R_T V) = 1` | 两端点交叉有效功率比 | 比值区间须含 1.0 |
| I5 | `K_T = T/(ρn²D⁴)` | 反演工作点须在 B 系列区间 | K_T ∈ [0.05,0.60] |
| I5b | `D/T` | 桨径吃水比 | [0.40,0.75] |
| I5c | `J = V(1-w)/(nD)` | 前进比可工作区间 | w∈[0.20,0.40] ⇒ J 区间须落在 [0.2,1.0] |
| I6 | `ΔR(λ)/ΔR(1)/λ³ = 1` | 傅汝德缩尺不变性（λ=1/2，V√λ，∇λ³） | ±5%（代理量，见⑤） |

三态判据：`PASS / FAIL / WITHHELD`（字段缺失一律 WITHHELD，不猜）。
门禁**双向**校核：合法合成闭环必须放行（1 例），8 例篡改必须拒绝。

工具链：Python 3.11 + urllib（仅标准库运行时依赖，无网络代理）+ pytest + matplotlib。

判据计数（5 工况 × 7 判据 = 35 条）：I1 全 5 PASS（阻力端点内部自洽，`rel_dev ≈ −9e−5`）；
I2/I3/I4 **各 5/5 FAIL**（共 15 条 FAIL）；I5/I5b/I5c 全 5 PASS（推进侧自参数自洽：
由 T/n/D 反演 K_T = 0.16 量级、D/T ≈ 0.56、J ≈ 0.49，都在物理区间内）；I6 全 5 PASS
（ΔR 归一化比 0.9515–0.9837）。

结论（可机检）：**推进侧自身自洽，阻力侧自身自洽，两端点之间不闭合**——
平台给出的螺旋桨推力只有阻力需求的 **24.7%–67.5%**（即缺口 32.5%–75.3%），
交付功率缺 14.7%–68.8%，交叉有效功率比 0.22–0.60（应为 1.0）。误差随 Fn 增大而恶化
（Ferry Fn≈0.26 最差，比值 0.220），符合「推进端点未按 R_T 反解转速/桨径」的指纹，
与 `src/ship_perf/propeller.py` 模块头注释记载的历史缺陷（旧服务 `n = V/(0.7D)`、
推力差 3 个量级）同型。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **区间判据不是精度判据**：I2/I3 判的是「是否落在物理可能带内」，不是「与真值差多少」。
   落在带内不等于准确（推力取 t=0.30 边界也能 PASS），但**落在带外一定是错的**——
   本单 5/5 工况都落在带外，故结论对 t、η_D 的经验取值不敏感（把 t 放宽到 0.05–0.35
   重新收紧下界，缺口仍在 −30% 以上）。
2. **`power` 字段语义未声明**：端点响应里没有说明 `power` 是 P_D、P_S 还是 P_B，
   本闸门按**交付功率 P_D** 处理并在台账标 `power_semantics_assumed='delivered'`；
   即便按 P_S（η_S≈0.98）解读也只解释 2%，不改变 FAIL。
3. **I6 是代理量**：端点不返回湿面积，`C_w` 无法反解，故用 `ΔR = R_T − R_F` 归一化到 λ³。
   ΔR 仍含粘压阻力与相关津贴（不按 λ³ 缩尺），所以容差放到 ±5% 且只作「标度可疑」信号。
   实测 0.9515–0.9837（1.6%–4.9% 偏离）落在容差内 → PASS，但**不能**据此宣称 Cw 严格不变。
4. **`/propulsion/predict` 的 L 用 Lwl**：端点 schema 只收 `L`，本单统一传 Lwl（与阻力
   端点 Lwl 同源），若服务内部用 Lpp 会引入 ~1.3% 的长度差——不影响量级结论。
5. **适用边界**：只覆盖单桨、常规 Cb 0.60–0.82、Fn 0.13–0.26 的商船工况；双桨、
   高速/半滑行（Fn>0.4）、冰区附加阻力不在本闸门适用域，需另立判据。
6. **本单不改船服务代码**（平台纪律：船舶缺口修复落 ship-performance-platform 仓）。
   本单产出的是**机器可裁判据资产 + 定量台账**，修复需在该仓执行；已按纪律派单
   （见 ⑥ 与本单 summary 的拆分说明）。

## ⑥ 误差判定（逐项，显式回答「是否 <3% / <15%」）

| 关键量 | 实测 | 基准 | 相对偏差 | 判据门 | 是否 <3%？ |
|---|---|---|---|---|---|
| I1 `P_E` vs `R_T·V` | 9848.59 kW | 9849.47 kW | −8.9e−5 | <0.5% | **是**（数值恒等式） |
| I2 推力缺口（KVLCC2，最轻） | 2886.8 kN | ≥4278.7 kN | −32.5% | <15% | **否** |
| I2 推力缺口（Ferry，最重） | 399.9 kN | ≥1619.1 kN | −75.3% | <15% | **否** |
| I3 功率缺口（KVLCC2，最轻） | 33572 kW | ≥39363 kW | −14.7% | <15% | **否**（且是最轻工况） |
| I3 功率缺口（Ferry，最重） | 6001 kW | ≥19220 kW | −68.8% | <15% | **否** |
| I4 交叉有效功率比（最好 KVLCC2） | 0.600 | 1.000 | −40.0% | <15% | **否** |
| I4 交叉有效功率比（最差 Ferry） | 0.220 | 1.000 | −78.0% | <15% | **否** |
| I5 反演 K_T | 0.161（KCS） | 区间 [0.05,0.60] | 带内 | 区间 | — （区间判据，非精度） |
| I6 波阻缩尺比 | 0.9515–0.9837 | 1.0 | 1.6%–4.9% | ±5% 代理 | **否**（2/5 工况 >3%） |

**总结论（honest）**：本单**不是** PASS 单。阻力域内部恒等式达标（<0.5%），
但阻力↔推进闭环在 5/5 工况上不成立，最小偏差 14.7%、最大 78%，远超 15% 门。
这不是「精度不足」，而是**跨域未接线**的结构性缺陷：单域复核无法发现，
只有把两个端点的回答放在一起才会暴露。修复归属 ship-performance-platform。
