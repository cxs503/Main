## 基准算例（闭式解，无平台中间量）

矩形浮箱 L=100 m, B=20 m, T=8 m, D=2T=16 m, KG=3.0 m, Cb=Cm=Cwp=1:

- ∇ = LBT = 16000 m³；KB = T/2 = 4.0000 m
- I_wp = LB³/12 = 66666.7 m⁴；BM = I/∇ = B²/(12T) = 4.1667 m
- KM = 8.1667 m；GM = KM − KG = 5.1667 m
- 甲板边缘入水角 φ_e = atan(2T/B) = 38.660°（此后 wall-sided 闭式解失效，基准在此止步）

平台（:8001 `/stability/evaluate`）返回 GM = 9.167 m，即 KM = 12.167 m，等于 KM_ref + T/2 = 12.1667 m。

根因判别：残差在全部 9 例上都 < 0.5 mm，故平台 KM 恰好多加了一次 KB（KB = T/2）。
等价写法 `GM = BM + T − KG`（T = KB 被加了两次）或 `KM = KB + BM` 而 BM 内部又含 KB。
误差量级随 T/B 增大而恶化（B/T=1.25 时 GM 误差最小、B/T=7.5 时最大），与上述函数形式一致。

## 影响面

稳性能力在能力清单中登记为 REAL，但本闸门显示其核心量 GM 在可解析核对的浮箱上误差达 +195.93%（阈值 3%，不可接受线 15%）；GZ 曲线消失角 90°–257° 物理上不可能（浮箱甲板仅 2T 高）。IMO/IS Code 判据若建立在错的 KN/GZ 上，天气衡准与完整稳性结论一并不可信。**该项不满足 >15% 不可接受线 → 判定不可接受。**
