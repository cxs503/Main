## 1. 案例介绍（物理背景 / 几何 / 参数）

频率域线性耐波核以单自由度传递函数给出垂荡/纵摇/横摇 RAO 与谱矩 σ：

    (M+A)η'' + Bη' + Cη = F(t)，ω_e = ω − kU cosβ，k = ω²/g（深水）

**遭遇频率的折叠问题**：随浪（cosβ>0）时 ω_e 在 ω ≥ ω_c = g/(U cosβ) 处过零并变号 ——
此时船速超过波速，SDOF 传递函数 1/√((1−r²)²+(2ζr)²)（r = ω_e/ω_n）在非正自变量上求值，
物理上无意义。旧版 `response_statistics` 把该频带按 r² 的偶对称静默计入 σ，既不报警也不报告，
于是"随浪高速"工况的响应统计混入了不可定义的能量。本单即对此做解析复核并修复。

## 2. 怎么做的（方法与关键设置）

1. **解析剪断频率**：随浪 ω_e ≤ 0 ⟺ ω ≥ ω_c = g/(U cosβ)，与代码"首个无效频点"逐工况比对（判据 L1）。
2. **解析尾部能量**：ITTC 谱 S = αA ω⁻⁵ exp(−Bω⁻⁴)，B = 691/T1⁴，令 u = ω⁻⁴ 得
   m0 = A/(4B)、尾部 = (A/4B)(1 − e^{−Bω_c^{−4}})，故**无效带能量占比闭式 = 1 − e^{−Bω_c^{−4}}**，
   与代码数值掩码逐工况比对（判据 L2）。该闭式不依赖任何文献表值，可在仓内机器判定。
3. **判据能判假**（L3）：把 ω_c 故意扰动 ±20%，闭式占比必须与平台数值显著偏离，否则判据是恒绿否决器。
4. **修复**：`response_statistics` 新增 `mask_invalid` 参数与四个完整性字段
   （`encounter_invalid`、`omega_e_first_invalid_rad_s`、`encounter_invalid_energy_fraction`、`m0_incident_m2`），
   mask 打开时把无效带置零再积分；`rao_curve` 暴露逐点 `encounter_valid`；端点 `POST /calculations/seakeeping_response`
   增加 `mask_invalid` 入参（默认 False = 历史数值逐位不变，L4 用独立重算验证）。
5. 工况矩阵：9 航速（0–20 kn）× 5 艏向 = 45 例，全部程序化写入 `numbers.json`，报告数字零手抄。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **坑（本单）**：解析尾部积分首轮写成了 e^{−Bω_c^{−4}}，把"ω_c 以上占比"算成了补集，
   表现为 2 kn 随浪给出占比 1.0000 的荒谬值——正是"低航速不应有无效带"这条物理直觉把它抓出来的；
   已改为 1 − e^{−Bω_c^{−4}} 并把推导写进脚本注释。
2. **数值 vs 解析的系统性小偏差**（占比数值恒低于解析 ≤0.0037）来自频率网格在 ω_max = 2.6 rad/s 处截断，
   尾部未计入；剪断频率误差 ≤ 网格台阶（0.0005 rad/s）。两者同源，非算法错误。
3. **局限**：掩码只解决"不可定义带被静默计入"的完整性问题，**不改**模型精度 ——
   加质量/阻尼仍是参数化输入（κ/ζ），实验精度仍为 WITHHELD；本单不声称 σ 的绝对精度。
4. **适用边界**：深水色散、单一艏向、线性小角度；ω_e→0 附近的强非线性（参数横摇/纯稳性丧失）不在模型内。
5. **端点契约测试**在宿主环境因缺 `psycopg2` 失败（`test_ship_seakeeping.py::test_endpoints_contract`），
   已用 git stash 在 HEAD 上复现，确认与本次改动无关（环境缺依赖）。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| 无效带起点 ω_c（3 工况） | 闭式 g/(U cosβ) | ≤ 0.044%（网格台阶） | **是** |
| 无效带能量占比（3 工况） | 闭式 1 − e^{−Bω_c^{−4}} | ≤ 0.0037（绝对） | **是** |
| 历史数值向后兼容 | 独立重算 σ = √∫RAO²S dω | 1e-12 相对 | **是** |
| 顶浪 σ 不受掩码影响 | 恒等式 | 1e-14 相对 | **是** |
| σ_垂荡 20 kn 随浪 raw vs masked | 本模型自洽（非外部基准） | 1.75% | **是**（但揭示缺陷量级 1.75%） |

**诚实声明**：本单不含与水池试验的比较；σ 的绝对实验精度仍为 WITHHELD（无船模试验数据入库）。
本单清偿的是"随浪工况响应统计把不可定义能量静默计入、且无从察觉"这条**完整性欠账**，
判据为闭式解析等式，故误差判定可做到机器级（<1%）。修复前 20 kn 随浪 σ_垂荡 被高估 1.75%
且平台不报警——量级未超 15% 门限，但属于"沉默的错误"。
