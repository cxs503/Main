## 1. 案例介绍（物理背景 / 几何 / 参数）
Wigley 抛物型船壳是薄船理论与 CFD 验证的标准解析船型，其半宽为
$$y(x,z)=\frac{B}{2}\Big(1-\big(\tfrac{2x}{L}\big)^2\Big)\Big(1-\big(\tfrac{z}{T}\big)^2\Big),\quad x\in[-L/2,L/2],\ z\in[0,T]$$
| 量 | 值 | 来源 |
|---|---|---|
| L / B / T | 100.0 / 10.0 / 6.25 m（L/B=10, B/T=1.6） | 标准 Wigley 几何 |
| Cb | 0.444444 = 4/9 | 闭式（精确） |
| Cm / Cwp | 0.666667 / 0.666667 = 2/3 | 闭式（精确） |
| 排水体积 ∇ | 2777.78 m³ = 4LBT/9 | 闭式（精确） |
| 湿表面积 S | 1487.91 m² | Gauss-Legendre 谱精度积分 |
| ρ / ν | 1025 kg/m³ / 1.19e-6 m²/s | 平台默认海水 |
| 航速扫描 | Fn = 0.10 … 0.35（11 点） | 覆盖排水型到方尾过渡区 |
被测端点：`POST /api/v1/resistance/predict`（平台自述“使用 Holtrop 方法”）；对照端点：`/resistance-advanced/holtrop`、`/resistance-advanced/ittc78`。
## 2. 怎么做的（方法 / 工具链 / 判据）
1. **精确参考面**（`references.py` + `michell_wigley.py`）：Cb/∇/Cm/Cwp 闭式；S 用 Gauss-Legendre 双重积分（n=200×200）；摩擦线用 ITTC-1957 闭式 $C_F=0.075/(\log_{10}Re-2)^2$；兴波用 Michell (1898) 薄船积分，两条独立路线（A：内层积分闭式 + θ 方向 Gauss-Legendre；B：dy/dx 中心差分 + 二维面元积分）互相核对。
2. **单因子探针**：逐 Fn 调用 `/resistance/predict`，从响应反解物理量——湿表面积由 $S=R_F/(\tfrac12\rho C_F U^2)$ 反推、剩余阻力系数由 $C_r=R_W/(\tfrac12\rho S U^2)$ 反推，**不相信自述的 method 标签**。
3. **闭合性归因**：把 $R_t-(R_F+R_W)$ 与平台自述相关补贴 $C_A=0.0004+0.0001L/100$ 逐点对比，判定“未返回的分量”是否即 R_A。
4. **Froude 相似性**：同一 Fn=0.20 下把主尺度按 1:2 几何缩放、速度按 $U/\sqrt2$ 缩放（v1 探针此处写错成 $U/\sqrt{0.5}$，即放大 1.414 倍，属假阳性，已在 v2 修正）。
5. **不确定性**：Michell 实施检查 = 两路线互差 -0.01%，θ 网格加倍差 -0.00%。
复现：`python3 audit_resistance_v2.py`（约 20 s，纯解析+轻量 HTTP）

## 5. 注意点（踩坑 / 局限）
1. **v1 工件的假阳性**：`audit_results.json`（m1568 遗留）中「Cw 缩放偏差 1.67」源于探针把降速写成 $U/\sqrt{0.5}$（放大 1.414 倍）；v2 修正后 Cw 缩放偏差远小于 3%（见 §3.3）。旧结论作废，本报告取代之。
2. **method 标签与实现不符**：`/resistance/predict` 自述 Holtrop，但其剩余阻力系数与分段线性 Fn 表 $C_r=c_1(Fn)\cdot c_{Cb}\cdot c_{B/T}\cdot c_{L/B}$ 复算到机器精度一致（C6 项），并非 Holtrop (1982/84) 的 $c_1c_2c_5\nabla\rho g\exp(m_1Fn^d+m_2\cos(\lambda Fn^{-2}))$ 回归。平台内已有真实 Holtrop 参考实现（`backend/services/resistance_holtrop.py`，m1545），但未接到该端点。
3. **湿表面积是回归值，不是几何值**：端点不接受 S 输入，用 Holtrop 湿表面积回归式；对几何精确已知的 Wigley 船，反推 S 低于解析值（C4），该误差按比例进入 Rf 与 Rt。`/resistance-advanced/ittc78` 提供 `wetted_surface` 入参，可作为修法模板。
4. **R_A 未在响应中返回**：$R_t-(R_F+R_W)$ 缺口与 $R_A$ 预测逐点吻合（C5），说明模型自洽但响应缺少分量字段，用户无法闭合账目。
5. **Michell 的适用域**：薄船理论仅对细长船、且 $Fn\lesssim0.35$ 有量级意义，在兴波峰区系统性偏低（不含破波/粘压），因此 C7 只作理论侧对照，不作闸门。本文采用单侧积分 + $4\rho g^2/(\pi U^2)$ 前因子约定（源强 $\sigma=2U\,y_x$ 已含两侧），修正了 v1 实现中多出的一倍。
