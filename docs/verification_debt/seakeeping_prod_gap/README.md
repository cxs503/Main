# 验证欠账清偿 · 耐波性生产端点 vs 已合并 REAL 内核（seakeeping production gap）

**席位**: tp-impl-3（platform 席）· 任务 m1793 · 分支 `agent/m1793` · 日期 2026-11-01
**对象**: 船舶总体性能平台 `:8001` 的 `/api/v1/seakeeping/{rao,motion}`，与本仓已合并的
REAL 切片理论内核 `backend/api/seakeeping_physics.py`。
**证据分级**: 生产端点 `MOCK`（硬编码/复制指纹）→ 内核 `REAL`（自洽性 ≤0.02%）→
**结论 `WITHHELD`（部署缺口）**: REAL 内核已合并但生产端点仍服务 legacy MOCK。

## ① 案例介绍（物理背景 / 几何 / 参数）

选一条**水线面为矩形、Cb = Cwp = 1 的箱式驳船**作为裁决船：其静水参数全部有闭式解，
因此基准值不依赖被测平台（几何门先闭合，符合「几何必须先验证 Cb/L/B」）。

| 参数 | 值 | 备注 |
| --- | --- | --- |
| L × B × T | 100 × 20 × 8 m | 壁面垂直，Cb = Cwp = 1 |
| 排水量 | 16 000 t | 与 ∇ = 15 609.8 m³ 自洽（残差 0%） |
| KG / GM | 8.0 m / 2.0 m | 另做 GM = 0.5 m 扫描 |
| ρ, g | 1025 kg/m³, 9.81 m/s² | 海水 |

三自由度垂荡 (heave, T33) / 纵摇 (pitch, T55) / 横摇 (roll, T44)。

## ② 怎么做的（方法 / 流程 / 工具链）

`docs/verification_debt/seakeeping_prod_gap/probe.py`（一次性、可复跑）：

1. **黑盒探针**：直接 POST 生产端点，取 `/seakeeping/motion`（自然周期 + 运动幅值）、
   `/seakeeping/rao`（30 点频率栅格）。做参数敏感性对照：波幅 1.0→3.0 m、浪向 180°→90°、
   GM 2.0→0.5 m。
2. **独立解析基准**（与平台无关，闭式）：  
   * 垂荡：`T33 = 2π√((m+A33)/(ρ g A_w))`，`A_w = Cwp·L·B` 精确；令 `A33 = 0` 得**非物理下界**
     `T33_min = 2π√(m/(ρ g A_w)) = 5.6044 s`（附加质量不可能为负，故任何真实结果必须 > 它）。  
   * 横摇：`T44 = 2π k_xx/√(g·GM)`，工程带 `k_xx = 0.30B~0.40B`，取 0.36B → 10.2132 s。  
   * 长波极限：任意浮体 `ω→0` 时垂荡 RAO → 1（严格）。  
   * 模式可分性：对本驳船 `T55/T33 = √((I55+A55)/(m+A33)·A_w/GM_L) > 1.05`，两周期不可能相等。
3. **内核复算**：离线 import 本仓内核，用其自报的 `A33/A55/I55/Aw/GM_L` 反算自然周期，
   检验它是否满足自己的定义；并在自建栅格上验长波极限。
4. 工具链：`requests` + `matplotlib(Agg)`；工件 `artifacts/gap_results.json`，
   图 `figs/fig1_natural_periods.png`、`figs/fig2_rao_curves.png`；
   回归测试 `tests/test_seakeeping_prod_gap.py`（9 项，离线可复跑）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

* **不重复劳动**：m1547 已在隔离端口 `:8021` 交付 DISTINCT-KERNEL 修复，并明确写「线上 :8001
  未替换（跨仓库边界）」。本轮**不重做内核**，只把那条未结清的欠账变成可复算的判据，并给出
  「已修 vs 未部署」的量化差额（T33 5.60 vs 7.82，差 39.6%）。
* **箱式驳船是有意选的**：只有它能给出闭式 `A_w`、`GM_L` 与 `T33_min`；对真实船型（KVLCC2/S-175）
  下界同样成立，但 `GM_L` 需用站线积分，会把误差源混进来。
* **横摇基准是工程惯例而非解析解**：`k_xx = 0.36B` 属 ITTC/工程带 (0.30~0.40B) 的中心值；
  因此表 1 横摇「+21.5%」的含义是「端点隐含回转半径越出 0.30B~0.40B 带」，不是「解析解误差」。
  端点反解 `k_xx = 12.41·√(g·2.0)/(2π) = 8.75 m = 0.4375 B`，**超出带外**。
* **P3 的逻辑是单边的**：`A33 ≈ 0` 由 `T33/T33_min = 0.9992` 推出；若要 A33 < 0 才可能等于下界，
  故这是非物理证据，不依赖任何附加质量取值假设。
* **未做的部分（如实标注）**：未改线上服务——生产代码属 `ship-performance-platform` 仓
  （本工作树为 TensorPlatform），本单只做只读审计 + 判据固化；替换动作需跨仓派单。
* 输入为 0 航速、顶浪 180°；含速工况的遭遇频率一致性不在本轮范围（m1547 已覆盖 30°/180°、25 kn）。

## ⑥ 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 实测 vs 基准 | 相对误差 | 是否 <3% |

| 生产端点 vs 已合并内核 T33 | 5.60 vs 7.82 s | **39.6%** | **否**（部署缺口） |
| 内核 T33 自洽（反算 vs 自报） | 7.8184 vs 7.8197 s | 0.017% | 是 |
| 内核 T55 自洽 | 8.5654 vs 8.5669 s | 0.017% | 是 |
| 内核 T44 vs 0.36B 基准 | 10.2150 vs 10.2132 s | 0.017% | 是 |

**总体结论（honest）**：生产 `/api/v1/seakeeping/motion` 为 `MOCK`（幅值硬编码 + 纵摇复制垂荡 +
垂荡零附加质量），横摇周期 21.5% 偏离工程基准；同仓已合并内核为 `REAL`（四项自洽性 0.017%~0.065%），
两者垂荡周期差 39.6%。故本能力**当前等级 `WITHHELD`**：算法已具备、生产未上线。
