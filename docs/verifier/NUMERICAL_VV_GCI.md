# 数值 V&V：网格收敛指数（GCI）工具箱 — mission 1700

**能力新增**：`services.vv`（`backend/services/vv/gci.py` + `cases.py`）。
在此之前，全仓 `Richardson` / `Grid Convergence Index` / `GCI` 检索命中数为 **0**，
平台没有任何手段回答「这个数字里有多少是离散误差」；战役第九波覆盖分析把
`numerical V&V / GCI` 列为六个零节点新域之一。本单交付可复用的解验证（solution
verification）工具箱，并用**解析解**把它自身先验证一遍——验证工具本身必须先被验证。

## 1. 案例介绍（物理背景 / 几何 / 参数）

GCI 不是物理模型，是与物理无关的确定性算术流程（Roache 1994/1998；ASME V&V 20；
Celik et al. 2008），因此它的“算例”必须是**离散解已知真值**的问题。本单用三个
解析基准，覆盖两种典型阶数与两种维度：

| 基准 | 方程与离散 | 名义阶 | QoI | 精确值 | 网格 |
|---|---|---|---|---|---|
| `conv_diff_1d_p5` | 1D steady convection-diffusion, -u''+5u'=0, central differences, QoI u(0.5), exact u=(e^{5x}-1)/(e^5-1) | 2 | u(0.5) | 0.07585818002 | n=20, n=40, n=80 |
| `poisson_1d_numerov` | 1D Poisson -u''=pi^2 sin(pi x) with the 4th-order compact Numerov scheme, QoI u(0.5), exact 1.0 | 4 | u(0.5) | 1 | n=8, n=16, n=32 |
| `poisson_2d_5pt` | 2D Poisson on the unit square, 5-point central differences, QoI u(0.5,0.5), exact sin(pi/2)^2 = 1.0 | 2 | u(0.5,0.5) | 1 | n=16, n=32, n=64 |

第三个基准的离散解有闭式：对 `sin(pi x) sin(pi y)` 特征模态，5 点算子特征值
`lambda_h = 4(1-cos(pi h))/h²`，故中心节点离散值 `u_h = (pi h)²/(2(1-cos pi h))`
（测试 `test_poisson_2d_center_value_matches_discrete_eigenvalue` 以 1e-12 相对
精度核对）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 估计量

三级网格 `h1 < h2 < h3`，`r21 = h2/h1`、`r32 = h3/h2`（允许非均匀），
`d21 = f2-f1`、`d32 = f3-f2`，`s = sign(d32/d21)`：

- 观测阶（隐式，不动点迭代）：`p = |ln|d32/d21| + ln[(r21^p - s)/(r32^p - s)]| / ln r21`
- Richardson 外推：`f_ext = (r21^p f1 - f2)/(r21^p - 1)`
- 细网格离散误差估计：`e1 = |f2 - f1|/(r21^p - 1)`；`GCI = Fs * e1/|f1|`，`Fs = 1.25`
  （≥3 级、渐近区）或 `Fs = 3.0`（仅 2 级、阶取名义值）
- Roache 收敛比：`CR = d21/d32`（`0<CR<1` 单调，`-1<CR<0` 振荡，`|CR|≥1` 发散）
- 渐近区指标：`A2/(r21^p A1)`，其中 `A1 = |d21|/(r21^p-1)`、`A2 = |d32|/(r32^p-1)`，
  要求落在 `[0.90, 1.10]`

`passed` 的判据（机器可裁）：收敛且阶可观测 + 渐近区指标在带内 + 观测阶与理论阶
偏差 ≤10%（若给出理论阶）+ 若给出精确值则真实误差被 GCI 带覆盖。

### 2.2 工具链

- `backend/services/vv/gci.py`：估计量本体（`Level` / `observed_order` /

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **Roache 收敛比的方向**：首版把 `CR` 写成 `d32/d21`，导致完全收敛的二阶序列被
   判为 divergence（`CR = r^p = 4 > 1`）。正确形式是 `CR = d21/d32`（细对变化 / 粗对
   变化），`|CR| < 1` 才是收敛。这一条由 3 个解析基准当场暴露。
2. **1D Poisson 的符号**：`-u''=f` 对应的三点式右端是 `-h²(f_{i-1}+10f_i+f_{i+1})/12`，
   首版漏了负号，Numerov 解收敛到 `-1` 而非 `+1`；观测阶仍为 4（误差序列自洽），
   说明**只看阶不能发现符号错误，必须对精确值**——这是本单方法论的直接教训。
3. **适用范围**：只适用于「同一 QoI、同一求解器、几何/物理设置不变、仅网格（或时间步）
   细化」的离散误差估计。它**不**替代与试验/文献的验证（validation），也**不**覆盖
   迭代收敛误差、统计/采样误差、模型形式误差。
4. **渐近区的必要性**：非渐近序列（如混合阶 `h + h²`）会给出无意义的高阶或负阶；
   负控测试 `test_non_asymptotic_order_flagged` 锁定了必须报警而不是照单全收。
5. **舍入极限**：当最细两级解在浮点下相同，阶不可观测，必须判 INDETERMINATE；
   `test_round_off_limited_sequence_rejected` 锁定该行为。
6. **非均匀细化比**：隐式迭代对 `r21=1.5, r32=2.0` 收敛良好，但比值极端不均（>3 倍
   差异）时迭代次数显著增加；实现里用阻尼更新并设 500 次上限，超限抛 `RuntimeError`。
7. **成本**：本单全部重算约 3 s（3 个基准 × 3 级网格 ≤ 64²）——不占 HPC 预算。

## 6. 误差判定（关键量 vs 基准，逐项列出）

基准即精确解（解析），因此可以逐项给真误差：

| 关键量 | 基准来源 | 数值 | 基准 | 相对误差 | 是否 <3% |
|---|---|---|---|---|---|
| `conv_diff_1d_p5` 最细网格 QoI | 解析解 | 0.074941838777 | 0.075858180021 | 0.0121 | 是 |
| `conv_diff_1d_p5` Richardson 外推值 | 解析解 | 0.075857960011 | 0.075858180021 | 2.9e-06 | 是 |
| `conv_diff_1d_p5` 观测阶 | 理论阶 2 | 2.0052 | 2 | 0.00261 | 是 |
| `poisson_1d_numerov` 最细网格 QoI | 解析解 | 1.000099699325 | 1.000000000000 | 9.97e-05 | 是 |
| `poisson_1d_numerov` Richardson 外推值 | 解析解 | 1.000000001519 | 1.000000000000 | 1.52e-09 | 是 |
| `poisson_1d_numerov` 观测阶 | 理论阶 4 | 4.0070 | 4 | 0.00174 | 是 |
| `poisson_2d_5pt` 最细网格 QoI | 解析解 | 1.003218964440 | 1.000000000000 | 0.00322 | 是 |
| `poisson_2d_5pt` Richardson 外推值 | 解析解 | 1.000000386829 | 1.000000000000 | 3.87e-07 | 是 |
| `poisson_2d_5pt` 观测阶 | 理论阶 2 | 2.0026 | 2 | 0.0013 | 是 |
| GCI 带一致性（真误差/GCI vs 1/Fs） | 渐近区理论 0.80 | 0.802–0.803 | 0.80 | 0.0039 | 是 |

结论：三类关键量（最细网格 QoI、外推值、观测阶）在全部三个解析基准上相对误差
均 **< 3%**：最细网格单解误差 0.32%–1.21%，Richardson 外推把误差压到 1.5e-9–3.9e-7
，观测阶偏差 0.13%–0.26%，GCI 带一致性偏差 0.39%。误差判定判据全部满足，
无一项需声明「无基准」；同时这张表也说明**单网格答案即使 <3% 也仍含 0.3%–1.2% 的离散误差**，
这正是 GCI 存在的意义：把「碰巧够准」与「已知有多准」区分开。
