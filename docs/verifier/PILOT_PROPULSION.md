## 1. 案例介绍（物理背景与判据来源）

平台 `/api/v1/propeller-design/wageningen-b` 自述返回 `method="Wageningen B系列回归公式"`，
能力清单把 `propeller.open_water` 记为 REAL。敞水性能是最基础的可验证功能：给定
(P/D, Ae/A0, Z, J)，输出 KT、KQ、η0。

验证不依赖实验序列数据（本机断网、无 B 系列回归系数表可取），而是采用**三条解析不变量 + 四条系列物理约束**，
它们对任何合法 KT/KQ 模型都成立，故可以**证伪**而不必依赖候选自证：

1. **敞水效率定义**（ITTC 7.5-02-03-02.1）：η0 = J·KT/(2π·KQ)。定义而非拟合，偏差即实现错误。
2. **动量理论（Froude/Rankine 作动盘）理想效率上界**：C_T = 8KT/(πJ²)，η_ideal = 2/(1+√(1+C_T))，
   真实螺旋桨 η0 ≤ η_ideal（黏性/诱导损失只会降低效率）。违反即物理不可能。
3. **B 系列结构**（Oosterveld & van Oossanen 1975）：KT、KQ 是 (P/D, Ae/A0, J) 的三重多项式，
   各叶数有独立系数集。直接推论：固定 J 时 η0 必须随 P/D 变化；Z=3..7 结果互不相同；
   KT 对 J 严格单调下降（越过零推力后为负）；KQ/KT 不是常数；J→0 时 η0→0。

采样网格（B 系列公开有效域内）：J ∈ [0.0, 0.1, 0.3, 0.5, 0.7, 0.9, 1.1, 1.4]，
P/D ∈ [0.6, 0.8, 1.0, 1.2, 1.4]，Z ∈ [3, 4, 5, 6, 7]，Ae/A0 参考点 0.65。

## 2. 怎么做的（方法/流程/工具链）

1. 读源码定位候选实现 `backend/api/propeller_design.py::calculate_wageningen_b`（只读，非本仓，未改动）。
2. 把 7 条判据实现为可独立测试的不变量（`pilots/propulsion_openwater.py`），每条返回
   measured / reference / tolerance / 文献出处，便于逐项报误差。
3. `tp_ver_propulsion.py` 通过 HTTP 逐点采样候选（40 点，耗时 1.097s），
   机器判决并写 JSON + 信用台账。
4. **反向对照（防判据过严）**：构造"物理可接受"的合成控制候选
   （`pilots/propulsion_control.py`：η0 取理想效率的 80%，KQ 由定义反解），控制候选 7/7 通过；
   平台 0/7 通过 ⇒ 判据不过严、失败有实质。
5. 单测 12 项（`tools/verifier/tests/test_propulsion_pilot.py`）覆盖解析参考值、控制候选通过、
   占位实现失败、以及解析可推导的结构性缺陷。

### 3.4 解析推导（可复算，不依赖采样）

候选主体为 `KT_base = 0.3·P/D − 0.2·J`、`KQ_base = 0.03·P/D − 0.02·J`，
再做叶数乘子、`×(0.5+Ae/A0)`、以及 `KT∈[0.05,0.5]`、`KQ∈[0.005,0.05]`、`η0≤0.85` 截断。
因 `KQ_base ≡ 0.1·KT_base`，代入定义：
η0 = J·KT/(2π·KQ) = 10J/(2π) = **1.5915·J**（未截断区）。
故 η0 与 P/D、Ae/A0、Z **完全无关**，仅由 J 决定，并在 J≥0.534 后被 0.85 截断；KQ/KT 恒为 0.100000。
实测（J=0.1/0.3/0.5 → 0.1592/0.4775/0.7958，与 1.5915·J 吻合到 1e-4）与解析式一致，
这是"实现缺陷"而非"精度不足"的判决依据；另有 Z=7 落入无修正分支（与 Z=4 同值）。

## 5. 注意点（踩过的坑 / 局限）

- **能力分级虚高**：能力清单标 `propeller.open_water` = REAL，但该端点实为线性占位式
  （源码注释自认"简化版…应使用完整回归系数表"）。建议降级为 **MOCK**，直至替换为真实回归/图谱实现。
- **无绝对精度比对**：本机无外网、无 B 系列系数表/试验报告，故未给出"对标试验值的绝对误差"，
  该判据记 **WITHHELD**；但上述 7 条是精确可证的结构性缺陷，足以判定不可接受（远超 15% 门槛）。
- 端点返回值仅保留 3–4 位有效数字（KT=0.23、KQ=0.023），量化误差约 0.2–2%，
  故定义恒等式容差取 3%（而非 0.1%）。
- 控制候选仅用于证明判据不过严，**不可**作为设计参考值。
- 采样共 40 次 HTTP 请求，属轻量负载（本机 load15≈123，未引入重算力进程）。
- 文档数字全部由 `propulsion_pilot_report.json` 注入，零手抄。

## 6. 误差判定（逐项 vs 基准，显式回答"是否<3%"）

| 关键量 | 基准/出处 | 平台实测偏差 | 是否 <3% |
|---|---|---|---|
| η0 定义恒等式 | ITTC 敞水定义 | 61.85%（最大） | **否** |
| η0 vs 动量理论上界 | 作动盘理论（硬上界） | +26.50% 超界 | **否** |
| η0 对 P/D 敏感性 | B 系列结构 | 跨度 0.0000（要求 ≥0.02）⇒ 0 敏感性 | **否** |
| J=0 时 η0 | 定义（P_E=T·Va=0） | 实测 0.50（应为 0） | **否** |
| KT 单调性/截断 | B 系列结构 | 4 处平台段 | **否** |
| KQ/KT 变化性 | B 系列结构 | 跨度 0.000000（恒 0.1） | **否** |
| 叶数分辨 | B 系列结构 | 1 对 Z 碰撞（Z=7 与 Z=4 相同） | **否** |
| 敞水效率绝对值 vs 试验 | 需 B 系列试验报告 | 未比对 | **未判定（WITHHELD，断网无表）** |

**结论（honest FAIL）**：候选在 7 条可精确判定的判据上全部失败，敞水性能判定为
**不可接受（>15%）**，证据等级应为 MOCK。修复需引入 Oosterveld & van Oossanen（1975）
完整回归系数表并重构截断逻辑；该修复位于 ship-performance-platform 仓，不在本单白名单内，
建议另派单（runner=native）执行。
