# 敞水（open-water）性能模块验证与重建 — mission 1393

**证据等级变更**：`propeller.open_water` 在此之前以 REAL 计入能力清单，但实现体
（`tools/batch_scan/batch_executor.py::ShipCalculationEngine.calc_propeller`）是硬编码线性替代式：

```
KT = max(0.05, 0.5 - 0.3*J)      KQ = max(0.01, 0.05 + 0.02*J)      eta0 = clip(J*KT/(2*pi*KQ), 0.3, 0.85)
```

它不含桨距比 P/D、盘面比 Ae/A0、叶数 Z 任何依赖，KQ 随进速比 **上升**（真实螺旋桨扭矩必须下降），
效率被夹到人造平台，且不存在零推力进速比 J0 —— 属 **MOCK** 级。本单把它换成一阶原理模型
（`backend/services/propeller_open_water.py`，叶元+动量 BEM），并用机器可判据验证。

## 1. 方法与工具链

- 几何：给定 D、P/D、Ae/A0、Z、轮毂比 x_h，弦长分布按 sin(pi t)^0.55 归一化，使叶面积精确等于 (Ae/A0)*pi*D^2/4；
  几何螺距角 beta(x) = atan((P/D)/(pi x))。
- 剖面：Cl = 2*pi*sin(alpha)（饱和于 1.10），Cd = CD0 + 1.0*alpha^2，CD0 = 0.012（Re~1e6 模型桨剖面量级，含粗糙度裕量）。
- 动量耦合：未知量取 **诱导轴向速度 u**（而非诱导因子 a = u/Va），故 J->0（系柱工况，a->1）仍正则；
  逐环带以二分法求 dT_be(u) = 4*pi*rho*r*u*(Va+u)*dr，切向诱导 a' 由角动量平衡 4*pi*rho*r^3*(Va+u)*omega*a'*dr = dQ_be 不动点求得。
- Prandtl 叶尖+轮毂损失，40 环带（验证用 16 环带，与 40 环带差 <1%）。
- 无量纲化：KT = T/(rho n^2 D^4)、KQ = Q/(rho n^2 D^5)、eta0 = J*KT/(2*pi*KQ)。
- 工具链：Python 3.11 + pytest 9.x + matplotlib 3.10；工件生成脚本 `tools/verification/open_water_benchmark.py`，
  测试 `tests/test_propeller_open_water.py`（29 例，全绿）。

## 2. 解析基准（可机器裁决）

理想作动盘（动量理论）效率上限 **eta_ideal = 2/(1+sqrt(1+C_T))**，其中 C_T = T/(0.5 rho V^2 A0) = 8*KT/(pi*J^2)。
任何真实推进器在同一推力下必须满足 0 < eta0 < eta_ideal，这是**无需外部数据**的解析判据。

不变性判据（精确可算）：
- 傅汝德缩尺不变性：D->kD、n->n/k 时 KT/KQ/eta0 不变（实测相对差 = 2.0e-16）；
- 密度无关性：rho 从 998 改到 1025，KT/KQ 相对差 < 1e-12；
- 叶面积守恒：由弦长分布积分的叶面积与 (Ae/A0)*pi*D^2/4 相对误差 = 4.75e-03；
- 零推力点：KT(J0) = -1.16e-05（J0 = 0.9930）；
- 动量上限违反次数（J = 0.2/0.4/0.6/0.8）= 0。

## 5. 注意点与局限

1. **绝对精度对文献值仍为 WITHHELD**：本机无外网（github/pypi 均不可达），Wageningen B 系列敞水图谱的
   点值数据无法取证，故未做文献点位对标，也未据此调参。可获得的可信基准只有解析作动盘上限与不变性，
   已全部逐项机器判定。
2. 剖面模型是透明的两级近似（薄翼 2pi 斜率 + 常数摩擦 + 抛物线阻力），无弯度（NACA a=0.8 平均线）与三维
   有限展弦比修正；因此**效率水平偏乐观**，偏乐观幅度与 CD0 强相关（见 3.4 表格区间）。
3. eta0/eta_ideal 位于 0.71–0.84，落在真实推进器 0.75–0.90 区间下缘，说明模型虽理想化但未越界。
4. J0 ≈ 0.99*(P/D)（P/D=1.0 时 J0=0.993）。真实 B 系列该值一般在 0.85–0.9*(P/D)，本模型 J0 偏高约 10–15%，
   与「扭矩偏小、阻力不足以把零推力点内移」是同一根源，已如实记录，不作掩饰。
5. 空化、片空泡、桨-舵干扰、非均匀伴流均不在模型内；大进速比下的风车/制动工况只保证趋势（KT<0）而非定量。

## 6. 误差判定（逐项、显式回答）

| 关键量 | 基准 | 结果 | 相对误差 | 是否 < 3% |
|---|---|---|---|---|
| eta0 < eta_ideal（4 个 J 点） | 解析作动盘上限（动量理论） | 全部满足 | 0 次违反 | ✅ 是（0/4 违反） |
| 傅汝德缩尺 KT/KQ/eta0 | 自身缩尺不变性（解析恒等） | 一致 | 2.0e-16 | ✅ 是 |
| 叶面积 vs 声明 Ae/A0 | 几何恒等（pi*D^2/4*Ae/A0） | 一致 | 4.8e-03 | ✅ 是 |
| KT(J0) | 0（零推力定义） | -1.2e-05 | 二分容差内 | ✅ 是 |
| KQ(J) 单调下降 | 螺旋桨物理必要条件 | 严格单调 | 定性判定（替代式失败） | ✅ 是（结构性） |
| eta_max 绝对值 | 已发表 B 系列图谱点值 | 无可用数据（离线） | 未评估 | ⚠️ **否 / 无法判定**（WITHHELD，理由见 5.1） |

结论：结构性与解析判据全部 < 3%（绝大多数为机器精度）；**绝对量级对文献值未能判定**，本单不宣称达到 15% 或 3% 精度，
需要一次带网络取证（B 系列图谱点值或空泡筒试验数据）的后续单来完成。

## 8. 后续取证与更正（m1650，2026-11-01）

本节为**追加**内容，上文（§1–§7）保持原样留痕。§5/§6 那条「绝对精度对文献值 WITHHELD」的欠账已在仓内结清，
证据与数字见 `docs/reports/m1650-propeller-bem-vs-bseries-verification.md`（报告 id 1240）、
`artifacts/m1650/propeller_bem_vs_bseries/audit.json`、脚本 `tools/verify/propeller_open_water/bem_vs_bseries.py`。

1. **§5.4 / §6 关于 J0 的结论方向错误，本次更正**：上文写「真实 B 系列 J0 一般在 0.85–0.9×(P/D)，本模型 J0 偏高 10–15%」。
   该「0.85–0.9」是口头经验、非图谱点值。正典 Oosterveld & van Oossanen 表给出 J0/(P/D) = 1.055–1.113
   （B4-70 1.062、B4-55 1.098、B4-40 1.113、B5-80 1.055、B3-50 1.080），而本模型恒为 0.993×(P/D)：
   **J0 实为偏低 6.5–10.7%（均值 8.1%），方向与上文相反**。
2. **绝对精度已可判定、但未达 3%/15%**：对正典表，载荷带内 KT 均值误差 18.0%、KQ 16.4%（均超平台 15% 可接受门），
   eta0 12.0%（门内）；积分量 eta_max 3.8%（最大 6.8%）、J_opt 4.6%、J0 8.1%。
   对 KP505 实测试验：本模型 KT 22.6%、KQ 9.9%，正典表 KT 13.9%、KQ 15.5%（后者为「换桨型/尺度」固有带）。
3. **根因定位**：载荷带内 dKT/dJ 比正典表陡 108–156%（即推力-进速斜率过陡），故低 J 推力偏高、J0 偏低、效率在
   eta_max 处反而接近；与 §5.2「剖面无弯度、无三维有限展弦比修正」的判断一致。
4. **图表外的一处文档漂移（已登记未改代码）**：`blade_element_section` 的 docstring 写 `Cd = 0.008 + 0.9α²`
   夹紧 `[0.006, 0.08]`，代码实际为 `CD0 + 1.0α²` 夹紧 `[0.008, 0.10]`。改常数会移动 m1393 全部已发表数字，
   故留待「模型改进」单处理（审计字段 `section_docstring_drift`）。
5. **能力项口径建议**：`propeller.open_water` 应注为「REAL 实现，KT/KQ ±15–20%、效率 ±4%」，
   而不是「REAL 且精度未定」。未作任何调参，本模型未针对上述基准拟合。
