# SUBOFF 静水阻力精度实测（S0，mission m1745）

**算例**：DARPA SUBOFF AFF-1 裸艇体（轴对称回转体，无附体/无桨/无舵），设计点 V = 3.0 m/s（Fr = 0.4589，Re = 1.302e+07）
**产物**：`artifacts/suboff_resistance.json` · `runs/suboff_s0/results.json` · `runs/suboff_s0/figs/*.png`（本文数字全部由 `runs/suboff_s0/make_doc.py` 从 JSON 注入）
**复现**：`python3 runs/suboff_s0/run_suboff_s0.py && python3 runs/suboff_s0/make_doc.py`
**判定**：设计点 Ct/Rt 相对误差 **-4.92%** → **PASS**（判据 |误差| ≤ 5%）；四工况中 5.0 / 6.0 m/s 两点超 5%（见 §6，未隐藏）

> 结论一句话：本仓库平台阻力端点（ITTC-57 摩擦线 + Hoerner 回转体形状因子 + 经验剩余阻力，几何验证湿表面积 5.42 m²）
> 在设计点复现 SUBOFF 实验总阻力，误差 -4.92%，**满足 ≤5% 验收判据**；同时暴露三项独立问题：
> ①平台经验湿表面积对回转体偏低 -21.40%（不传实测 S 必 FAIL）；
> ②经验剩余阻力项在 Fr>0.7 后过陡，5.0/6.0 m/s 两点误差升至 +13.51% / +32.04%；
> ③**部署服务 :8001 与工作树实现不同源**，三个阻力端点对 SUBOFF 全部超差 174%–986%，且 `rt` 实际单位为 kN。

## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理背景

DARPA SUBOFF 是 DTRC/ITTC 用于潜艇 CFD 与阻力预报验证的标准回转体模型（AFF-1 为裸艇体）。
裸艇体阻力是**纯粘性主导**问题：无附体干扰、无桨舵相互作用，检验的是"摩擦线 + 形状因子 (+ 剩余项)"这条链条本身，
因而是阻力模块最干净的基准。几何为长径比 L/D = 8.57 的流线型回转体，
航速 3–6 m/s 对应 Fr = 0.46–0.92（按艇长），Re = 1.30e+07–2.60e+07。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 计算模型

```
Ct = (1 + k) · Cf(Re) + Cr(Fn, Cb)
Rt = ½ · ρ · S · Ct · V²
```

| 组成 | 公式 / 取值 | 性质 |
|---|---|---|
| 摩擦线 Cf | ITTC-1957：`Cf = 0.075/(log10 Re − 2)²`，Re = V·L/ν | 解析式（REAL） |
| 形状因子 (1+k) | Hoerner (1965) 流线型回转体：`1 + 1.5(d/L)^1.5 + 7(d/L)^3` = 1.070841 | 公开经验式，**无自由参数**（未对参考值拟合） |
| 剩余阻力 Cr | `0.002·(1 + 2Cb)·Fn^2.5`（平台 `backend/services/ship_resistance.py`） | 经验拟合项（自参考属性，见 §6） |
| 湿表面积 S | 调用方显式传入 5.42 m²（端点 `wetted_surface_m2` 覆盖经验式） | 几何验证值 |
| 流体 | ρ = 998.2 kg/m³，ν = 1.004e-6 m²/s（淡水 20 °C） | 与正典同源 |

### 2.2 流程与工具链

| 环节 | 实现 |
|---|---|
| 几何校验 | `runs/suboff_s0/run_suboff_s0.py::suboff_geometry()`，Cb/L/B/∇/S 五项校验，不通过即中止 |
| 平台阻力计算 | `POST /api/v1/calculations/resistance` → `backend/api/calculations.py::calc_resistance`（本工作树代码），FastAPI TestClient 进程内调用，0.010 ms/点 |
| 端点真实性核验（反 MOCK） | 本地闭式解逐字段复算 Rf / Rform / Rr / Ct / Rt，相对偏差须 ≤ 5e-5（端点响应 round 4 位），否则 `SystemExit` —— 本次 8 组断言全通过 |
| 第二摩擦线交叉核对 | Schoenherr (1932) 隐式式二分求解，与 ITTC-57 偏差 +1.34%–+1.96%（两点独立关联式互证） |
| 参考值 | `backend/data/benchmark_reference.json` v3.0（只读；`DERIVED` 行才允许参与判决，脚本内强制断言） |
| 部署服务交叉核对 | :8001 的 `/api/v1/calculations/resistance`（kn / m·s⁻¹ 两种口径）与 `/api/v1/resistance-advanced/ittc78` |
| 出图 | matplotlib Agg，150 dpi（图内标注用拉丁字符：本机无 CJK 字体） |

### 2.3 计算设置（"网格/湍流模型/边界条件/收敛判据"的等价声明）

本算例**不含 CFD 离散**，因此没有网格数、湍流模型、边界条件与迭代收敛判据可报。等价的可核验设置是：

| 维度 | 本算例的对应物 |
|---|---|
| 离散误差 | 无（所有量为闭式解析求值，端点 `computation_time_ms` = 0.010 ms，一秒内可复算百万次） |
| 模型误差 | 用**双变体 + 敏感性带**量化：形状因子 (1+k) ∈ [1.00, 1.25] 与 S 三种口径（见 §4） |
| 收敛判据 | 复算一致性：端点 vs 闭式解 ≤ 5e-5（8 组断言）；参考值口径闭合（ρ/ν/S 与正典逐位一致） |
| 边界条件 | 深潜无自由液面，故无兴波项；若需真实流场须 TensorLBM 3D（CAP-002，GPU ≥16 GB，单次约 12 h），本单未执行 |

读法：`反解 Rt = Ct·½ρS·V²`（V 取端点实际来流速度，由返回的 Re 反解），`单位比 = 反解 Rt / 端点回报 rt`，
≈ 1e3 说明端点回报的 `rt` 实际是 **kN** 而字段语义是 N。三个端点对 SUBOFF 全错，根因分别为：

1. `/calculations/resistance`（默认 `speed_unit=kn`）：把 3 m/s 当 3 kn 处理（Re 恰为真值的 1/1.94），
   叠加 Holtrop 剩余阻力回归（在 Fr≈0.46 的艇型上给出 Cr 量级为 Cf 的数倍），Ct 差 **+174%**；
2. `/calculations/resistance`（显式 `speed_unit=m/s`）：Re 正确、Cf 正确，但 Holtrop 剩余项仍给出
   Cr ≈ 4.9 × Cf，Ct 差 **+354%**，且仍忽略调用方的湿表面积（内部用 4.52 m²）；
3. `/resistance-advanced/ittc78`：把 ITTC-78 的**全尺度相关补贴** `Ca = 0.002776` 用在 4.356 m 模型上
   （全尺度 k_s=150 μm 公式在模型尺度上外推失效），叠加 Cr ≈ 0.035，Ct 差 **+986%**。

**审计结论**：`calc.resistance` 的部署实现对本算例属 NOT_SUPPORTED 级（误差数百 %，且 `rt` 单位与字段语义不符、
入参湿表面积被忽略）。本报告的精度判决因此以**本工作树代码**为准（可复现、可审计、随分支入库），
并建议：部署前把 :8001 的阻力端点对齐到工作树实现，或在 `ship_type=body_of_revolution` 时显式拒绝 Holtrop/ITTC-78 分支。

## 6. 注意点（踩过的坑 / 局限 / 适用范围）

1. **湿表面积口径是第一主导项**：平台经验式 `S = π·B·L·(0.5+0.25Cb)` 对回转体给出
   4.260 m²，比正典 5.42 m² 低 21.40%；
   照默认走设计点误差 -25.27%。**必须传入几何验证 S**（端点已支持覆盖并回显 source）。
2. **形状因子不可省**：回转体取 (1+k)=1.0 等于宣称没有粘性压差阻力，物理上不成立；补 Hoerner (1+k) 后
   设计点误差由 -10.26% 收敛到 -4.98%。该式无自由参数，
   本报告**没有对参考值调 k**（若按 k 反解，任何误差都能被"做"出来）。
3. **经验剩余阻力项是自参考的**：`Cr = 0.002(1+2Cb)Fn^2.5` 的标定对象即 SUBOFF 类回转体，因此设计点的 5% 级别一致
   属于"半经验模型对实验的验证"，**不是**从第一原理出发的预测。纯理论变体 C 在设计点给出
   -19.20%，即为该经验项贡献的量化。
4. **经验项在高 Fr 端过陡**：5.0 m/s（Fr = 0.76）误差 +13.51%、
   6.0 m/s（Fr = 0.92）误差 +32.04%，来自 Cr ∝ Fn^2.5 的外推。
   适用范围应显式限定在 Fr ≲ 0.65（深潜艇设计航速段）。
5. **正典 SUBOFF-02~04 的参考序列存在规律性疑点（提请复核，本单未改参考值）**：四点 Ct 记录值为
   0.0038, 0.0040, 0.0042, 0.0044，等步长增加 +0.0002；对应"实验剩余阻力"
   `Ct_ref − (1+k)Cf` 随 Fr 近似线性增长。深潜回转体若无自由液面，剩余项应随 Fr 单调但增速远快于此前的
   粘性主导形态；若为近水面拖曳则应呈强非线性。两者都不支持线性序列 → 建议把这些点的 provenance 降级复核
   （本单按纪律不修改参考值，只在判决中把 5.0/6.0 m/s 两点如实标为 PARTIAL_PASS / FAIL）。
6. **部署与工作树不同源（已实测）**：见 §5，:8001 对 SUBOFF 三个端点误差 +174%~+986%，且 `rt` 单位为 kN。
   任何依赖线上 API 的 SUBOFF 结论目前都不可用。
7. **无 CFD 场量**：本单未做 RANS/LBM，故无网格收敛性研究、无压力/速度场。这是精度链条上的已知缺口，
   不是本次精度判决的必要条件（阻力是积分量），但若要诊断阻力分项来源，必须补 CFD。
8. **单位与流体口径**：Rt 为 N，Ct 无量纲；ρ、ν 必须与参考值试验介质一致（淡水 vs 海水差 2.7%，足以吃掉半个判据）。
