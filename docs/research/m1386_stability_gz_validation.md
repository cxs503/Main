# 已合并能力复核：右倾力臂 GZ 的壁式闭式解 vs 精确箱体静水力（m1386）

> 复核对象：`POST /api/v1/calculations/stability`（能力 `calc.stability`，证据等级 REAL）
> 复核类型：**验证欠账清偿**（已合并功能对解析基准独立复核），非功能新增
> 工具链：Python 3.11 · FastAPI TestClient · pytest 25 项 · matplotlib（全部工件见 `artifacts/m1386/`）
> 判据来源：`docs/QUALITY_BAR.md`（误差 >15% 不可接受；几何先验证）与 IMO IS Code 2008 第 2.2 条完整稳性口径

## ① 案例介绍（物理背景 / 几何 / 参数）

船舶完整稳性的核心量是**右倾力臂 GZ(φ)**：横倾 φ 时浮心 B 与重心 G 的水平错位。
平台 `calc.stability` 采用教科书**壁式（wall-sided）闭式解**

```
GZ(φ) = sin φ · ( GM + ½ · BM · tan²φ )
```

该式并非经验拟合，而是一条**解析恒等式**：当横剖面浸湿部分始终是等宽梯形
（既不出现甲板边缘入水、也不出现舭部出水）时严格成立。它的成立条件正是复核的关键：

* 水线先触到**低舷侧舭部**：`tan φ = 2T/B`；
* 或先淹到**高舷侧甲板边**：`tan φ = 2(D−T)/B`。

因此有效上限为 `φ_lim = atan( 2·min(T, D−T) / B )`。一旦越界，`tan²φ` 会**无界增长**，
而真实 GZ 必然有峰值并趋于零——即壁式解在域外不只不准，而是**非物理**。

复核基准取唯一存在封闭精确解、且与平台代码零共享的几何：**等截面矩形箱形驳船**
（垂直舷侧、平底、完整水线面、干舷 D>T）。其直立静水力解析可写出
`KB = T/2`、`BM = B²/(12T)`、`GM = KB+BM−KG`，正好是壁式公式的全部输入——
于是「同一组输入下，闭式解是否等于真实静水力」成为可机器裁定的命题。

## ② 怎么做的（方法 / 流程 / 关键设置）

**独立参考解（不共享代码路径）**：`backend/services/stability_reference.py`

1. 将箱体横剖面 `[(−B/2,0),(B/2,0),(B/2,D),(−B/2,D)]` 绕纵轴旋转 +φ（右手系，艏向为轴）；
2. 对旋转后的多边形做 Sutherland–Hodgman 半平面裁剪，得到 `z ≤ ζ` 的浸湿剖面；
3. 用**鞋带公式 + 多边形质心公式**求浸湿面积 A(ζ) 与形心 (y_B, z_B)——解析精确，无离散化误差；
4. 对 ζ 做 200 次二分，使 `A(ζ) = B·T`（**等排水量横倾、无纵倾**，箱体沿长度均匀）；
5. GZ = y_B − y_G，其中 G=(0, KG) 随船体同步旋转（`y_G = KG sinφ`）。

**为什么这是"独立"的**：整个过程唯一的外部输入是几何 (B,T,D,KG)；壁式闭式解只作为被检对象
出现，不参与参考解的构造。参考解自身也做了三项自检（见测试 Phase 1）：

* 等排水量守恒：任意横倾角下浸湿面积 = B·T，相对偏差 < 1e-10；
* 小角极限：φ=1° 时 GZ 与 `GM·sinφ` 一致（相对差 < 1e-3）——校验符号与尺度约定；
* GZ(0) = 0。

**平台侧改动（最小、向后兼容）**：`backend/api/calculations.py`

* 新增可选入参 `beam_m / draft_m / depth_m`（兼容别名 `beam / draft / depth`，
  因 `services/ship_proxy.stability()` 正是按这套名字投递）；给定 B、T 即解析算出 `φ_lim`；
* 响应新增 `wall_sided_valid`、`heel_validity_limit_deg`、`gz_box_exact_m`（独立箱体校核臂）、
  `validity_note`；原有字段（`righting_arm_m` 等）数值与语义**完全不变**；
* 硬边界：`|φ| ≥ 90°` 直接 400（`tan²φ` 奇异；旧实现此时返回 ~1e32 m 的力臂）；
* 未给几何时采用保守默认上限 25°（`DEFAULT_WALL_SIDED_LIMIT_DEG`），并在 `validity_note` 明示。

**验收测试**：`tests/test_m1386_stability_gz_validation.py`（25 项）
Phase 1 参考解自检（面积守恒/小角极限/零角）→ Phase 2 闭式解对基准（域内一致、域外 15% 越界、有界性）
→ Phase 3 端点行为与回归门（默认调用不变、奇异角拒绝、判定随 φ_lim 变化而非硬编码的**变异探针**）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **箱体必须有干舷**：首版参考模型把剖面深度取成吃水 T，二分求解"等排水量水线"退化为
   "整个剖面没入水下"（任意 ζ 都满足 A = B·T），GZ 变成纯几何转动。加入 D > T 与
   干舷条件后才有唯一解——这也是 φ_lim 里出现 `min(T, D−T)` 的物理原因。
2. **符号约定易错**：旋转矩阵取 `(y cosφ − z sinφ, y sinφ + z cosφ)` 时，数值 GZ 与
   `GM sinφ` **反号**（相差 −1）。是靠 φ=1° 的解析小角极限自检抓出来的；若无该自检，
   后续误差表会整体翻转而不自知。教训：任何数值参考解先做小参数渐近校验再谈对标。
3. **`tan²φ` 的无界性是真实缺陷而非理论洁癖**：旧实现 φ=89° 返回 6838 m 力臂（GZmax 甚至被算成
   5.6e32 m），若下游据此刻画 IS Code 面积/消失角，结论完全失真。
4. **代理层参数名不一致**（本次顺带发现，仅部分修复）：`services/ship_proxy.stability()` 投递
   `length/beam/draft/cb/displacement/kg`，而端点历史入参是 `displacement_t/gm_m/kb_m/bm_m`；
   pydantic 默认忽略未知字段 → **经代理的稳性请求长期静默使用默认值**（1000 t、GM=1 m、φ=10°）。
   本次用 `validation_alias` 打通 `beam/draft/displacement`，但 `kg` 仍无对应语义（端点用 kb/bm/gm
   三元组），映射策略需业务确认，未擅自改动——列为待办。
5. **适用范围**：基准是箱形驳船，只能裁定"壁式恒等式是否被正确实现、其定义域在哪"，
   **不能**替代真实船型（含舭部圆弧、外飘、上层建筑）的 GZ 复核；真实船型需静水力曲线/横截曲线
   数值积分对比，属后续欠账。默认 25° 上限是经验保守值，非解析导出。
6. **测试环境**：后端 `api/__init__.py → api.auth → database.config` 在验证沙箱缺 `psycopg2/cryptography`
   （无网络不可装）。测试用 `sys.modules["api"]` 包桩隔离该导入链，被测模块本身未被替换/打桩。

## ⑥ 误差判定（逐项对照，显式回答是否 <3%）

| 关键量 | 基准（精确箱体静水力） | 平台值 | 相对误差 | <3%？ |
|---|---|---|---|---|
| GZ(φ)，φ ≤ φ_lim（案例 A/B/C 全域） | 独立静水力积分 | 壁式闭式解 | ≤ 2.0e-13 % | **是** |
| GZ(30°) 案例 A（φ_lim=21.8°） | 0.978 m | 1.181 m | +20.7 % | 否（域外） |
| GZ(40°) 案例 A | 1.059 m | 2.014 m | +90.2 % | 否（域外） |
| A30 案例 C（φ_lim=11.3°） | 0.3507 m·rad | 0.4674 m·rad | +33.3 % | 否（域外） |
| A40 案例 A | 0.1798 m·rad | 0.2723 m·rad | +51.4 % | 否（域外） |
| 消失角 案例 A | 78.3° | 不存在（GZ 单调增） | 定性错误 | 否（域外） |
| 等排水量守恒（参考解自检，测试断言） | B·T | B·T | ≤ 1e-10 | 是 |

结论：**域内该已合并能力通过复核（误差 ≪3%，实际为机器精度）**；
**域外不满足 15% 门槛且非物理**，因此本单不是"改数"而是"加门禁 + 给独立校核臂"：
越界时端点显式置 `wall_sided_valid=False`、给出解析上限，并附精确解对照值供下游判断。
原有域内数值一字未改（回归测试 `test_default_request_unchanged` 锁死）。
