# 冰区阻力三实现交叉复核（m1702 · 自找活 tp-mod-4 · models 席）

**结论先行**：仓库里三个都自称"Lindqvist / 第一性原理"的层冰阻力实现，在共同船型与共同工况下有 **2 个带真实缺陷（共 5 条验收判据 FAIL）**，且**量级相差 6.1–9.1 倍**；平台"正确"的那条（polar 生产路径）通过了全部 20 条解析判据。同时定量证明：`ice_resistance_uq` 的单点标定使"对试验值验证"成为构造性同义反复（标称残差恒为 0），且标定因子只做刚性缩放，**无法修正指数误差**。

工件：`outputs/ice_crosscheck/ice_crosscheck.json`（44 条判据全量）、4 张图、脚本 `docs/ice_crosscheck/audit_ice_resistance.py`、测试 `tests/test_ice_resistance_crosscheck.py`（12 passed / 6 xfail(strict) 债务台账）。本文所有数字均由脚本程序化写入 JSON 后读出，零手抄。

## ① 案例介绍

三个被审计实现（全部在册、全部在用）：

| 代号 | 文件 | 角色 |
|---|---|---|
| **A** | `backend/services/ice_resistance_uq.py` `_lindqvist_raw` / `lindqvist_ice_resistance` | Lindqvist 形式分解 + 单船单点标定因子；冰区阻力 UQ/PCE 服务的物理内核 |
| **B** | `optimizer/ice_class/objectives.py` `evaluate_ice_resistance` | 冰级设计 NSGA-II 优化的目标函数（最小化 R_ice） |
| **C** | `backend/services/polar/resistance.py` `ice_components` | 极地航次优化器的生产路径（第一性原理分解） |
| **R** | `backend/services/ice_canon.py`（本单新增） | 参考分解：只含可由推导得到的标度，系数约定显式标注 |

共同审计船（PC6 量级杂货船）与参考工况：

| 参数 | 值 |
|---|---|
| L / B / T / Cb | 150 m / 23 m / 8.5 m / 0.70 |
| 水线进流角 α | 30°（B 用 20° 作为 α_stem） |
| 层冰厚 h | 0.80 m（扫描 0.20–1.50 m） |
| 冰抗压强度 σ_c | 1.5 MPa（扫描 0.5–2.5 MPa） |
| 冰–船摩擦 μ | 0.10（扫描 0.02–0.25） |
| 航速 V | 2.0 m/s（扫描 0–3 m/s） |

**判据来自推导，不来自系数**：挤压 `R_cr ~ σ_c h²`（过程区面积 ~ h²）；破断 `R_br ~ σ_f h^1.25 B`（弹性地基梁 l_c = (E h³/(12ρg(1-ν²)))^{1/4} ~ h^0.75，M_f = σ_f h²/6，P = 4M_f/l_c）；浸没 `R_sub ~ h B T`（浮力失衡 × 受淹首部面积）；加质量项 `1 + C_v V/√(gh)`。

## ② 怎么做的

1. 读三处实现 + `docs/ice_class/README.md` 所载公式，确认三者对同一物理量的建模路径；
2. 写 `backend/services/ice_canon.py`：把上述推导显式实现为参考模型（系数 `C_CRUSH/C_BREAK/C_FLEX/C_VEL` 全部标注为约定值，不做拟合）；
3. 写 `docs/ice_crosscheck/audit_ice_resistance.py`：对每个实现做
   - 对数域最小二乘测标度指数（h / B）、中心差分测各驱动量导数（σ_c, μ, V, T, B）；
   - 用 σ_c→0 且 V→0 隔离浸没项（因为 A/B/C 都把 h^-0.5 的加质量因子并进浸没项）；
   - 在仓库自带三条实船试验基准（MV Arctic / Polarstern / Terry Fox）上比对绝对量级；
   - 标定循环性：标称残差 + 偏离标称点（h±50%、V±50%）的行为。
4. 判据共 44 条（4 实现 × 9 条聚合 + 2 实现 × 4 条分项），写成 pytest：正判据直接断言，缺陷写成 `xfail(strict=True)` 台账（修好即 xpass 报错，强制更新台账）。

工具链：纯 Python/numpy/matplotlib，无重算力（load15≈108，按容量纪律只做轻量活）。

## ⑤ 注意点 / 局限 / 适用范围

1. **R 不是完全独立的第三方**：它与 C 同源于同一套教科书推导（差别只在 `C_CRUSH`、`C_BREAK/C_FLEX`、`E` 与 `ν` 的约定）。C=R 只能算**佐证**，不是外部验证。本单的独立性体现在**判据是可推导的标度**，而不是"两个实现互相点头"。
2. **系数不确定性未消**：破断系数在梁端条件不同下可取 `σ_fh²/(3l_c)` 或 `(2/3)σ_fh²/l_c`（1 倍差）；挤压过程区因子可取 0.5–1.0。故一切结论只建立在**指数与单调性**上，不建立在绝对系数上。
3. **A 的两条缺陷是结构性的**：浸没项写成 `(ρw-ρi) g h B (…)(0.3 L)`，完全没有吃水 T；速度项写成 `0.05 ρ B h V²`（占总阻力 0.25%）。这不是"精度差"，是模型缺项——任何标定因子都补不回来（3.4 表证明：因子 1.07–1.41 只是刚性缩放）。
4. **B 的三条缺陷影响面最广**：它的目标是冰级设计优化的被最小化量，量级低 11.5×、且对冰强度与摩擦完全不敏感（`SIGMA_F=500 kPa`、`MU_ICE=0.1` 是模块常量）。Pareto 前沿的 R_ice 轴因此不是物理量，只保留相对排序意义；本单不改数（改动会连锁到 `runs/ice_class/` 已归档结果），只把欠账写成台账。
5. **浸没项速度端不可用总阻力判定**：经典分解把速度耦合全部放在浸没项，而浸没在总阻力中占比小（本船 2.5 m/s 时约 5%），所以"总阻力对速度不敏感"是模型的正常后果，**不是**缺陷——判据因此放在 σ_c→0 的隔离子项上（K8）。这是本单方法上的一处自我修正。
6. **适用边界**：层冰（level ice）、连续破冰、无冰脊、无肩部/舷弧效应；碎冰道（brash channel）与冰脊阻力不覆盖（`polar/channel.py` 有独立标定路径，另有其基准）。
7. **不动生产数**：本单只新增参考模块与判据，未改 A/B/C 任何一行物理代码（避免推翻已归档的 UQ 与 Pareto 结果）；修复建议见下。
