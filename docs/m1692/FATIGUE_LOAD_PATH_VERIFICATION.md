# m1692 — 数字孪生疲劳链「载荷侧」独立验证：UR S11 波纹参数分支 + 海况传递律

**被验证对象（已在主线服役）**：`backend/services/digital_twin/models/fatigue.py`
（`wave_bending_moment` / `wave_parameter_C` / `spectral_fatigue`），其在线消费者为
`backend/services/digital_twin/online_predictor.py`（剩余寿命预测）与
`surrogate_registry.py`（代理模型采样面）。

**为什么这一单**：m1653 已经把疲劳链的**计数侧**钉死在 ASTM E1049-85（雨流 + 宽频修正），
但整条链的**载荷侧**从未与任何外部基准对齐：
① 波浪参数 `C(L)` 的三段定义是否按 IACS UR S11 Rev.7 §3.2.1 落地；
② 从设计海况 `Hs = 11 m` 外推到任意海况的**传递律**是否符合线性波浪理论。
两处都是"已合并功能 + 无外部复核"的典型验证欠账，且经 m1653 之后仍未被覆盖。

## 结论（一句话）

抓到 2 处实质缺陷：`C(L)` 在 `L ≤ 90 m` 误用长船公式（最大 **+12.16 %**）；
应力幅按 `(Hs/11)²` 二次律外推（物理上应为线性），在 `Hs = 5 m` 使**剩余寿命高估 ×11.61**
（非保守、不安全方向）。两处均已修复并通过新增 18 条测试 + 独立基线复核。

## 方法

* **基线 1（规范）**：IACS UR S11 Rev.7 §3.2.1 波浪参数分段式
  `C = 0.0412L + 4 (L≤90)`、`C = 10.75 − ((300−L)/100)^1.5 (90<L≤300)`、`C = 10.75 (L>300)`，
  与 §3.2 波浪弯矩 `M_wh = 0.19 C L² B Cb`、`M_ws = 0.11 C L² B Cb`。
  参考实现独立重写（`scripts/verify_fatigue_load_path.py::ref_wave_parameter_C`），不复用被验证代码。
* **基线 2（解析）**：线性波浪理论——线性 RAO 模型的波浪载荷 ∝ 波幅，故
  `σ_a(Hs) = σ_design · Hs/11`。平台自身的线性切片模型可作为该锚的内部交叉检验
  （`seakeeping.irregular_seastate` 的 `heave_rms` 应与 `Hs` 严格成正比）。
* **基线 3（时域）**：窄带 Rayleigh 损伤 vs 12 万点合成记录的雨流计数（ASTM E1049-85），
  用于确认修复没有破坏计数侧闭合。
* 全部数字由 `scripts/verify_fatigue_load_path.py --tag before|after` 程序化产出
  （`artifacts/m1692/fatigue_load_path_{before,after}.json`），图表由
  `scripts/make_m1692_figures.py` 生成，本文件表格由脚本注入（零手抄）。

## 缺陷一：`C(L)` 的 `L ≤ 90 m` 分支

原代码只有一个分支式 `10.75 − ((300−L)/100)^1.5` 覆盖全部 `L`。该式恰在 `L = 90 m` 处
与规范值 7.708 几乎相交（7.7068），所以长船量级从来看不出问题；但 `L = 50 m` 处给 6.7972，
规范值 6.0600，**+12.16 %**，随 `L` 减小继续放大。属于"取样点恰好落在两支交点附近"的
隐蔽类缺陷。修复：新增 `wave_parameter_C(L)` 三段显式分支。

## 缺陷二：海况传递律 `(Hs/HS_IACS)²`（核心）

`spectral_fatigue` 用二次律从设计点外推：

```
sig_a = sig_design * (Hs / HS_IACS) ** 2      # 旧
sig_a = sig_design * (Hs / HS_IACS)           # 新（线性波浪理论）
```

二次律意味着"波高减半 → 应力降到 1/4"，违反线性波浪理论（RAO 与波幅无关）。
方向是**非保守**的：低估应力 → 低估损伤 → 高估寿命（`D ∝ σ³`）。
量化（`L=180, B=30, T=18, Cb=0.82, Tp=9 s`）：

逐点数值见文末 **T2/T3**（由 `scripts/make_m1692_figures.py` 从 JSON 注入）。要点：
`Hs = 5 m` 时应力低估 54.55 %、剩余寿命高估 **×11.61**；`Hs = 2 m` 时寿命高估达 **×2955**；
`Hs = 12 m`（高于设计点）则反向低估寿命 ×0.77（偏保守）。

修复后：`σ_a(2Hs)/σ_a(Hs) = 2.000000`（误差 0.0 %），与线性基线逐点误差 2.0e-14 %，
自相似性与时域闭合均达标。

## 通过项 / 未被破坏的东西

* 波浪弯矩系数 0.19 / 0.11 与 sag/hog 比 0.5789 与规范一致（`L = 180` 处误差 0.000 %）。
* 计数侧闭合：窄带 Rayleigh 损伤 vs 雨流 = 1.87 %（修复前后不变，m1653 的结果未被回退）。
* 平台线性性交叉检验：`heave_rms / Hs` 在 `Hs = 2–11 m` 内 spread = 0.0000 %，证实线性锚成立。
* 回归：`tests/`（除 2 个需要数据库的收集失败文件与 1 个**先于本单存在**的
  `test_propeller_open_water::TestBatchExecutorUsesBemModel` 失败）**522 passed / 9 skipped / 1 xfailed**；
  该 propeller 失败已在 `git stash` 掉本单改动后复现，与本单无关。

## 注意点 / 局限

1. `M_wh` 被当作"应力幅 + 设计海况 `Hs = 11 m` 对应的极值循环"，这是建模约定而非规范原文；
   本单只验证"在该约定下外推律必须是线性"，未验证"11 m 是合适的等效设计海况"（该值应与
   北大西洋长期海况统计挂钩，属另一单）。
2. `sigma_rms_mpa` 形参历史上被当作应力**幅值**使用（与返回值 `sigma_amp_MPa` 同量纲），
   名实不符；为不破坏调用方未改名，已在 docstring 显式声明。
3. 冰致循环项 `ICE_CYCLE_RATE = 0.020` 仍是**声明式经验系数**（无公开基准），未在本单复核；
   它对 `Hs = 0` 附近的总损伤有支配作用，属剩余验证欠账。
4. `nu0 = 1.4/Tp` 沿用 JONSWAP 的 `Tz ≈ 0.71 Tp` 近似，本单未单独复核（属于频域统计参数，
   与 m1653 的谱宽修正同族）。
5. 修复改变数值结果（同海况下寿命最多缩短 ×11.6）：`online_predictor` 的剩余寿命输出、
   `surrogate_registry` 的采样面会随之变化，属**修正而非回归**；如需历史对比请用
   `artifacts/m1692/fatigue_load_path_before.json`。
