# 船舶阻力计算基准验证报告 — m1479

## ① 案例介绍

**物理背景：** 船舶总阻力系数 Ct 是船型设计、主机选型和能效评估的核心参数。
Holtrop-Mennen 方法是商船阻力估算的工业标准（ITTC 推荐），但其适用范围为
Cb > 0.55 的丰满船型。本验证对 TensorPlatform 内置的简化 Holtrop/ITTC-57
阻力计算模块，针对三类经典船型进行实验数据对标：

| 船型 | 类型 | 来源 | L (m) | B (m) | T (m) | Cb |
|------|------|------|-------|-------|-------|-----|
| SUBOFF | 轴对称潜体 | Roddy 1990 (DTRC) | 4.356 | 0.508 | 0.508 | 0.508 |
| DTMB-5415 | 水面战斗舰 | ITTC V&V 2010 | 5.720 | 0.759 | 0.246 | 0.508 |
| KVLCC2 | 超大型油轮 | SIMMAN 2008 | 320.0 | 58.0 | 20.8 | 0.8098 |

**验证目标：** 计算 Ct vs 实验 Ct 的相对误差，判定是否 <15%（ITTC 可接受阈值）。

## ② 方法

**计算流程：**
1. 从 `backend/data/benchmark_reference.json` 读取 12 个基准案例（每船型 4 个速度点）
2. 使用 `api/calculations.py` 中的 Holtrop/ITTC-57 简化公式复算：
   - 湿表面积：S = π·B·L·(0.5 + 0.25·Cb)（轴对称体近似）
   - 摩擦阻力系数：ITTC-1957 公式 Cf = 0.075/(log₁₀Re - 2)²
   - 剩余阻力系数：Cr = 0.002·(1+2Cb)·Fn^2.5（Fn>0.05）
   - 总阻力系数：Ct = (Rf + Rr) / (0.5ρSV²)
3. 误差计算：error_pct = |Ct_calc - Ct_exp| / Ct_exp × 100%
4. 判定：error_pct ≤ 15% → PASS，否则 → FAIL

**工具链：** Python 3.11 + matplotlib（出图）+ 纯数值计算（无外部求解器）

## ⑤ 注意点与局限

### 关键发现

1. **SUBOFF（轴对称潜体）表现最佳**：3/4 通过，平均误差 13.9%。仅 Fn=0.918 时
   误差 32.1% 超限——这在预期内，因为 Holtrop 方法不适用于极高 Fn 的细长体。

2. **DTMB-5415 在高速段严重发散**：Fn>0.24 时误差达 219%-602%。根因是简化剩余阻力
   公式 Cr ∝ Fn^2.5 在高速段过度放大，且湿表面积公式（轴对称近似）不适用于瘦削船型。

3. **KVLCC2 系统性低估约 50%**：尽管 Holtrop 理论上适用于丰满油轮，但计算 Ct 仅为
   实验值的一半。根因是湿表面积公式 `S = π·B·L·(0.5+0.25·Cb)` 严重低估了大型商船的
   实际湿表面积（应使用 Holtrop 原始公式或 Guldhammer-Harvald 近似）。

### 算法改进建议

| 优先级 | 改进项 | 预期效果 |
|--------|--------|----------|
| P0 | 湿表面积公式改为船型专用（Holtrop 原始 S 公式） | KVLCC2 误差降至 <15% |
| P1 | 剩余阻力系数改用 Holtrop 分项公式（Cp, LCB 等参数） | DTMB-5415 高速段改善 |
| P2 | 增加船型识别逻辑，SUBOFF 用 slender-body 理论 | SUBOFF 全速段 <10% |

### Honest-FAIL 声明

当前简化 Holtrop/ITTC-57 实现仅对 SUBOFF 中低速段（Fn<0.8）有工程可用精度。
对 DTMB-5415 高速段和 KVLCC2 全速段的误差超过 15%，**不应直接用于工程决策**。
上述误差已如实记录，未做任何数据修饰。

**结论：** 当前阻力计算模块对 SUBOFF 基本可用（75% 通过率），但对 DTMB-5415 和
KVLCC2 的精度不可接受。主要改进方向为湿表面积公式和剩余阻力系数模型。
