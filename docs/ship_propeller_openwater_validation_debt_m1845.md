# 螺旋桨敞水性能的验证欠账：三条 B 系列代码路径的实测对账（mission m1845）

**结论先行**：平台 `propeller.open_water` 能力（证据等级 REAL）所用路径 **经得住外部实测检验**
——对 NMRI KVLCC2 拖曳水池敞水试验，`K_T` 中位误差 3.57%、
`K_Q` 中位误差 3.43%（J ≤ 0.45 段）。但同一平台内**另有两条**
自称"官方 Oosterveld & van Oossanen (1975)"或"已验证"的实现，实测对账分别为
**`K_Q` 中位偏大 49.46%** 与 **`K_T=K_Q=0`（恒零，100% 误差）**。
本单为纯只读审计 + 可落地的替换件，不改动被审仓库。

---

## ① 案例介绍（物理背景 / 几何 / 参数表）

Wageningen B 系列是螺旋桨初步设计的行业基准。敞水性能由三个无量纲量刻画：

```
K_T = T /(ρ n² D⁴)      K_Q = Q /(ρ n² D⁵)      η₀ = (J / 2π)·(K_T / K_Q)      J = V_a /(n D)
```

Oosterveld & van Oossanen (1975) 把系列试验结果回归为
`K_T, K_Q = Σ C_i · J^s_i · (P/D)^t_i · (Ae/Ao)^u_i · Z^v_i`（K_T 39 项、K_Q 47 项）。
本次外部基准取 **NMRI（日本海上技术安全研究所）第 3 号拖曳水池 2006 年 KVLCC2 螺旋桨敞水试验**，
该数据从未参与任何系数拟合，属真正的外部真值：

| 参数 | 数值 |
|---|---|
| 直径 D | 0.0896 m |
| 毂径比 | 0.155 |
| 螺距比 P/D (0.7R) | 0.7212 |
| 伸张面积比 Ae/Ao | 0.431 |
| 叶数 Z | 4 |
| 测量点 | 17 个 J（0 → 0.798，含 0.399/0.449 两次重复） |

被审的三条代码路径（同一平台内并存）：

| 代号 | 文件 | 自称来源 | 实际实现 |
|---|---|---|---|
| **A** | `backend/data/official/Wageningen_Bseries_coeffs.dat` + `backend/api/open_water.py` | O&O 1975 | 真实回归表（47 项成对表） |
| **B** | `platforms/shared/methods/wageningen_b.py` | "verified"，引 Troost 数据 | 手拟合二项式 `K_T = .320 − .280J − .01J² + …` |
| **C** | `backend/methods/propulsion/wageningen.py` | "Oosterveld & van Oossanen (1975)" | 系数表为伪造填充（见 ⑤） |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **判据先立**：平台精度规则 = 相对误差 ≤ 15% 不可接受线；"verified" 标签 = 3% 目标。
   判定采用稳健统计（中位 + p95），避免零推力交叉点附近相对误差发散污染结论。
2. **真值链**：以仓库内已存在的官方回归表（A 的数据文件）作为"实现基准"，
   以 NMRI 实测作为"物理基准"。二者互相独立于 B、C 的代码。
3. **取证（forensics）**：用 AST 直接读 `KT_COEFFICIENTS`/`KQ_COEFFICIENTS` 字面量，
   统计 K_Q/K_T 系数比、±1e-5 填充项占比、有效位数——判断系数表是否为发布表。
4. **几何扫掠**：J ∈ [0, 0.8]（步长 0.05）× P/D ∈ {0.6, 0.8, 1.0, 1.2, 1.4} × Ae/Ao ∈ {0.40, 0.55, 0.70} × Z ∈ {3,4,5}，
   仅保留 `K_T,ref ≥ 0.05` 的物理加载段，共 706 个状态点，逐点求 B/C 对 A 的偏差。
5. **工具链**：纯 Python（numpy/matplotlib 仅用于成图），无 CFD、无新增算力进程
   （入场时 load15 ≈ 123 ≥ 100，遵守轻量纪律）；产物全部由脚本生成，数字零手抄。

## ④ 注意点（踩坑 / 局限 / 适用范围）

1. **相对误差在零推力点发散**：最初的判定把 J ≤ 0.8 全段纳入，得到 K_T max = 17496%（分母趋 0）。
   现改为"加载段判据"（J ≤ 0.45 / K_T,ref ≥ 0.05），并把 max 曾出现的尾部单独讨论——
   这不是掩盖数据，而是拒绝让不可定义量主导结论；全段数据仍在 JSON 中可查。
2. **A 表 ≠ 3% 命中**：中位 3.57%，故对 NMRI 实测（非系列桨）
   **不满足 3%**，但满足 15% 线。判为 REAL 是成立的，宣称"3% 精度"则不成立。
3. **hull 尺度演示**：`propulsion_wageningen.json` 参考值偏粗（见 3.2），不能当验收基准。
4. **未做的事**：未做雷诺数修正（ITTC 尺度效应）、未评估空泡/斜流工况；
   B 系列的 Rn 修正项 `ΔK_T = −0.0003(7 − log₁₀Rn)²` 在两个实现中均不统一（A/C 无、C 有但表已废），
   本单未裁决其正确性——留作后续验证欠账。
5. **审计边界**：只读。被审仓库未改动，替换件以"可直接落盘的模块 + 测试"形式交付。

## ⑤ 取证细节：伪造系数表如何被识别

| 指标 | 观测值 | 判读 |
|---|---|---|
| K_Q 系数 / K_T 系数（逐项比） | min=0.100000，max=0.100000 | **恒等于 0.1**：K_Q 表是 K_T 表的等比复制，不可能是独立回归结果 |
| ±1e-5 / ±1e-6 填充项 | 51 / 82（62.2%） | 高阶项为占位填充 |
| 不同有效位数种类 | 4 | 官方表系数为 6 位有效数字（如 0.00880496、−0.204554） |
| 前 5 项 / 全表在设计点占比 | 1.1427 | >1：后续项在做负向抵消，物理上不成立 |
| 实际输出 | 所有几何下 K_T、K_Q < 0 → 被 `max(0.0, …)` 截断为 0 | **该实现恒返回零推力** |

对比官方表首项：`0.00880496`（K_T）、`0.00379368`（K_Q）；伪造表首项：`0.219`（K_T）、`0.0219`（K_Q）——
后者恰是前者的整体缩放版，且与 K_T 表严格成 10:1。

## ⑥ 误差判定（逐项，显式回答是否 < 3%）

| 关键量 | 基准 | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|
| K_T，A（官方表） | NMRI 实测，J ≤ 0.45 | 中位 3.57%，p95 10.75% | **否**（中位即超 3%） | 是 |
| K_Q，A（官方表） | NMRI 实测，J ≤ 0.45 | 中位 3.43%，p95 11.26% | **否** | 是 |
| η₀，A（官方表） | NMRI 实测，J ≤ 0.45 | 中位 0.36% | **否** | 是 |
| K_T，B（"verified" 回归） | NMRI 实测 | 中位 5.17% | 否 | 是 |
| K_Q，B（"verified" 回归） | NMRI 实测 | 中位 49.46% | 否 | **否** |
| η₀，B（"verified" 回归） | NMRI 实测 | 中位 36.33% | 否 | **否** |
| η₀，B（几何扫掠） | 官方表，706 点 | 中位 23.65% | 否 | **否** |
| K_T/K_Q，C | 官方表 | 恒零 → 100%（706 点全中） | 否 | **否** |
| 替换件 vs 官方表（构造性） | 官方表，18 个状态点 | 0.000%（rtol 1e-12 断言通过） | **是** | 是 |

**显式回答**：核心物理量对实测基准**不满足 3%**；满足 15% 线者仅限"官方表路径（A）"及其替换件。
B 路径的 K_Q / η₀ 与 C 路径的全部输出**连 15% 线都不满足**，其"verified"标记属虚假证据。
