# 船舶阻力计算验证报告

## 任务概述

验证 TensorPlatform 阻力计算 API 与文献基准的符合度。

## 验证方法

使用 backend/data/benchmark_reference.json 中的实验数据，对比计算值与实验值。

### 基准数据来源

- **SUBOFF**: Roddy, J.D. (1990). 'DARPA SUBOFF Model Experiments', DTRC-90/012
- **DTMB-5415**: ITTC V&V Workshop
- **KVLCC2**: SIMMAN 2008

### 计算方法

使用 backend/api/calculations.py 中的简化 Holtrop-Mennen 公式：
- ITTC-1957 摩擦阻力线
- 经验剩余阻力系数

## 问题分析

### 1. SUBOFF 系列

- 低 Fn (≤0.765) 时表现良好，误差 <15%
- SUBOFF-04 (Fn=0.918) 误差 32.1%，超过阈值

### 2. DTMB-5415 系列

- 中等速度 (Fn=0.687) 时误差 7.5%，可接受
- 高速 (Fn>1.0) 时误差急剧增大（>200%）

### 3. KVLCC2 系列

- 全系列误差 >49%，问题最严重
- 原因：简化公式未考虑满载船型的特殊流动特性

## 根本原因

1. **剩余阻力系数 Cr 过于简化**: 使用 `0.002 * (1 + 2.0 * Cb) * Fn ** 2.5` 经验公式，未考虑船体形状差异
2. **高速时流动特性变化**: 高速时兴波阻力主导，简单公式无法捕捉
3. **摩擦阻力线适用性**: ITTC-57 在低 Re 时需要修正

## 误差判定

| 指标 | 误差 | 是否<3% |
|------|------|---------|
| SUBOFF 低Fn 平均 | ~7.8% | 否 |
| SUBOFF 高Fn | 32.1% | 否 |
| DTMB5415 高速 | >200% | 否 |
| KVLCC2 全系 | >49% | 否 |

**结论**: 简化方法在高速区域不满足 15% 误差要求，需要更精确的方法。

## 建议改进方向

1. **分速度区间使用不同方法**:
   - Fn ≤ 0.3: 简化公式可接受
   - Fn > 0.3: 需要 CFD 或专用经验公式

2. **引入船型系数修正**:
   - 针对 SUBOFF、DTMB-5415、KVLCC2 分别建立修正系数

3. **使用更精确的摩擦阻力线**:
   - ITTC-78 或 Grigoropoulos 公式

4. **添加不确定性说明**:
   - 在 API 响应中增加 uncertainty 字段
