## 1. 案例介绍（物理背景/几何/参数表）

### 1.1 物理背景

DARPA SUBOFF 是美国海军研究的标准回转体模型，广泛用于 CFD 验证和阻力预报基准测试。
该模型为轴对称回转体，无附体，几何简单但流态复杂（高 Fr 数下兴波阻力显著）。

## 2. 方法/流程/关键设置/工具链

### 2.1 计算方法

平台采用 **ITTC-1957 摩擦阻力线 + Holtrop 简化剩余阻力** 方法：

- **摩擦阻力系数**: Cf = 0.075 / (log₁₀(Re) - 2)²  （ITTC-1957）
- **雷诺数**: Re = V·L/ν，ν = 1.004×10⁻⁶ m²/s（15°C 淡水）
- **剩余阻力系数**: Cr = 0.002·(1 + 2·Cb)·Fn²·⁵ （简化 Holtrop，Fn > 0.05）
- **总阻力系数**: Ct = Cf + Cr
- **总阻力**: Rt = ½·ρ·S·Ct·V²

### 2.2 工具链

- **API 端点**: POST `/api/v1/calculations/resistance`
- **验证脚本**: `tools/validate_suboff_resistance.py`
- **测试文件**: `tests/test_suboff_resistance_validation.py`
- **可视化**: matplotlib (Agg backend, 150 dpi)

### 2.3 关键设置

- 水密度 ρ = 998 kg/m³
- 运动粘度 ν = 1.004×10⁻⁶ m²/s
- 重力加速度 g = 9.81 m/s²

### 3.2 误差判定

| 关键量 | 基准值 | 判定标准 | 实际最大误差 | 是否 <15% |
|--------|--------|---------|------------|----------|
| Ct | Roddy (1990) 实验 | ≤15% | 300.9% | ❌ **否** |
| Rt | Roddy (1990) 实验 | ≤15% | 99.5% | ❌ **否** |

### 3.3 HONEST-FAIL 声明

**所有 4 个工况均超过 15% 误差阈值，判定为 HONEST-FAIL。**

**根因分析**:
1. Holtrop-Mennen 方法标定对象为 Cb > 0.55 的商船船型
2. SUBOFF 为轴对称回转体（Cb ≈ 0.542），船型差异大
3. SUBOFF 工况 Fn > 0.45，进入高速兴波主导区，Holtrop 剩余阻力模型不适用
4. 湿表面积估算公式 S = π·B·L·(0.5 + 0.25·Cb) 对回转体精度不足

**改进建议**:
- 对 SUBOFF 类回转体：采用 slender-body theory 或 CFD (RANS)
- 对高 Fr 数工况：需引入兴波阻力专门模型（如 Michell 积分）
- 平台应增加船型适用范围检查，对超出范围的工况给出警告

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 踩过的坑

1. **benchmark_reference.json 中 Fn 值错误**: 原始文件中 SUBOFF 的 Fn 值（0.236, 0.315...）与实际计算值（0.459, 0.612...）不符。已在校准中修正。
2. **API 字段名不一致**: 平台 API 使用 `speed` 而非 `speed_ms`，`displacement` 为必填字段。
3. **湿表面积估算偏差**: 平台使用 S ≈ 4.63 m²，而文献值为 5.42 m²，差异约 15%。

### 5.2 局限

- Holtrop 方法仅适用于 Cb > 0.55 的排水型商船
- 当前实现未考虑附体阻力、粗糙度补贴、空气阻力
- 剩余阻力模型为简化公式，未区分兴波阻力和粘压阻力

### 5.3 适用范围

| 船型 | Cb 范围 | Fn 范围 | 适用性 |
|------|---------|---------|--------|
| 油轮/散货船 | 0.75-0.85 | 0.10-0.16 | ✅ 适用 |
| 集装箱船 | 0.55-0.70 | 0.18-0.28 | ⚠️ 边界 |
| 回转体 (SUBOFF) | ~0.54 | >0.4 | ❌ 不适用 |
| 高速艇 | <0.50 | >0.4 | ❌ 不适用 |
