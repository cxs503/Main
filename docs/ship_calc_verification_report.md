## 1. 案例介绍 (Case Introduction)

### 1.1 物理背景

船舶总体性能计算是船舶设计的核心环节，包括：
- **阻力计算**：预测船舶在静水中航行时的总阻力
- **稳性计算**：评估船舶在横倾时的复原能力

本报告验证 TensorPlatform 的阻力和稳性计算模块，对标：
1. **ITTC-1957 摩擦线**（国际拖曳水池会议标准）
2. **DARPA SUBOFF 实验数据**（Groves et al. 1989）
3. **墙侧公式解析解**（初稳性理论）

### 1.2 平台算法概述

**阻力计算** (`backend/api/calculations.py`):
- 湿表面积：`S = π·B·L·(0.5 + 0.25·Cb)`（轴对称体近似）
- 摩擦阻力：ITTC-1957 摩擦线 `Cf = 0.075 / (log₁₀(Re) - 2)²`
- 剩余阻力：经验公式 `Cr = 0.002·(1 + 2·Cb)·Fn^2.5`（Fn > 0.05）
- 总阻力：`Rt = Rf + Rr = ½·ρ·S·(Cf + Cr)·V²`

**稳性计算** (`backend/api/calculations.py`):
- 墙侧公式：`GZ = GM·sin(φ) + ½·BM·tan²(φ)·sin(φ)`
- 复原力矩：`RM = Δ·g·GZ`（Δ 为排水量）

### 1.3 参数表

|------|------|-----|------|

### 3.3 稳性验证

**墙侧公式测试**:
- ✅ 零横倾时 GZ = 0
- ✅ 小角度线性近似有效（5° 时非线性项 < 5%）
- ✅ 正 GM 给出正复原力臂
- ✅ GM 敏感性正确（GZ ∝ GM）

**GZ 曲线特征**:
- 小角度（< 10°）：线性主导，GZ ≈ GM·sin(φ)
- 中角度（10-15°）：非线性项逐渐显著
- 大角度（> 15°）：墙侧公式不再适用，需交叉曲线

## 5. 注意点 (Notes & Limitations)

### 5.1 已识别的局限

1. **SUBOFF 适用性**:
   - Holtrop-Mennen 方法针对船型优化，对轴对称体（潜艇）精度有限
   - 建议：对 SUBOFF 使用专用轴对称体阻力预测方法

2. **兴波阻力缺失**:
   - 高傅汝德数（Fn > 0.3）时，兴波阻力占比显著
   - 平台经验公式低估兴波阻力，导致高 Fn 区低估 20-35%
   - 建议：实现完整 Holtrop-Mennen 方法或添加兴波修正

3. **粘性压差阻力**:
   - 未考虑形状阻力（form drag）
   - 对钝体（高 Cb）影响较大
   - 建议：添加粘性压差阻力分量

4. **墙侧公式适用范围**:
   - 仅适用于小角度（< 15°）
   - 大角度需使用交叉曲线（cross curves）或数值 GZ
   - 建议：实现静水力曲线查询功能

### 5.2 踩过的坑

1. **参考数据错误**:
   - 初版测试使用了错误的 SUBOFF 参考值（0.55 N @ 1 m/s）
   - 实际 Groves 1989 数据为 6.81 N @ Fn=0.15 (V=0.98 m/s)
   - 教训：必须从原始文献获取参考数据，不可依赖二手来源

2. **ITTC-1957 参考值**:
   - 网上流传的"Cf 参考值"多为错误数据
   - 正确做法：直接用公式计算验证
   - 教训：解析公式可直接验证，无需外部参考

### 5.3 适用范围

| 工况 | 平台精度 | 建议 |
|------|----------|------|
| 低 Fn (< 0.25) | ±18% | ✅ 可用 |
| 中 Fn (0.25-0.35) | ±13% | ✅ 可用 |
| 高 Fn (> 0.35) | -35% ~ 0% | ⚠️ 需改进 |
| 小角度稳性 (< 15°) | 解析精确 | ✅ 可用 |
| 大角度稳性 (> 15°) | 不适用 | ❌ 需交叉曲线 |
