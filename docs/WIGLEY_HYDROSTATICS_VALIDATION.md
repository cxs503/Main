## 1. 案例介绍（物理背景/几何/参数表）

### 1.1 物理背景

Wigley 船型是船舶流体力学中广泛使用的标准数学船型，由 W.C. Wigley 于 1930 年代提出。
其半宽面由简单的二次多项式定义，具有解析的静水力积分结果，是验证静水力计算程序的标准基准。

### 1.2 几何定义

Wigley 船型的半宽面方程为：

$$y(x,z) = \frac{B}{2} \left[1 - \left(\frac{2x}{L}\right)^2\right] \left[1 + \frac{C}{2}\left(\frac{2z}{T}\right) - \left(1+\frac{C}{2}\right)\left(\frac{2z}{T}\right)^2\right]$$

其中：
- $x$ 为纵向坐标（从船中起算，$-L/2 \leq x \leq L/2$）
- $z$ 为垂向坐标（从基线起算，$0 \leq z \leq T$）
- $C$ 为参数，通常取 $C=0$（标准 Wigley）或 $C=1$（改进型）

## 2. 方法/流程/关键设置/工具链

### 2.1 计算方法

平台采用 **梯形数值积分** 方法从船体型值表计算静水力参数：

- **型值生成**: Wigley 解析公式在 $(n_{stations} \times n_{waterlines})$ 网格上采样
- **排水体积**: 对横剖面面积沿船长积分（梯形法则）
- **水线面面积**: 对半宽沿船长积分（梯形法则）
- **浮心**: 一阶矩/零阶矩
- **稳心半径**: $BM = I / \nabla$，其中 $I$ 为水线面惯性矩

### 2.2 工具链

- **API 端点**: POST `/api/v1/calculations/hydrostatics`
- **验证脚本**: `tests/test_wigley_hydrostatics_validation.py`
- **可视化**: matplotlib (Agg backend, 150 dpi)

### 2.3 关键设置

- 水密度 ρ = 1025.0 kg/m³
- Wigley 参数 C = 0（标准型）
- 积分网格：81 站 × 41 水线

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 踩过的坑

1. **Wigley 参数 C 的默认值**: 平台 Wigley 实现使用 C=0（标准型），与文献中常见的 C=1（改进型）不同。验证时必须确认参数一致。
2. **坐标系约定**: 平台使用 x 从尾垂线起算（0 到 L），而解析公式通常以船中为原点。积分时需正确变换。
3. **湿表面积计算**: 湿表面积无解析解，数值积分结果依赖于网格密度和曲面近似方法。

### 5.2 局限

- 当前验证仅针对标准 Wigley 船型（C=0），未覆盖 C≠0 的改进型
- 未验证大倾角稳性（GZ 曲线），仅验证了小角度静水力参数
- 湿表面积计算采用平面片近似，对曲率大的区域可能有系统偏差

### 5.3 适用范围

| 船型 | 适用性 | 说明 |
|------|--------|------|
| Wigley 标准型 (C=0) | ✅ 已验证 | 误差 <0.005% |
| Wigley 改进型 (C≠0) | ⚠️ 未验证 | 公式相同，预期精度相当 |
| 实际船型（型值表输入） | ⚠️ 间接验证 | 积分方法相同，但型值质量影响结果 |
| 多体船/小水线面船 | ❌ 不适用 | 单值函数假设不成立 |
