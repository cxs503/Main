## 1. 案例介绍（物理背景 / 几何 / 参数）

结构强度是总布置、板厚与材料选型的直接约束域。本次复核的核心量：

- 总纵弯曲应力 σ = M/Z（M 为中横剖面设计波浪+静水合成弯矩，Z 为箱形剖面模数 I/(D/2)）；
- 板格屈曲临界应力 σ_cr = kπ²E/(12(1−ν²))·(t/b)²（长板简支单轴经典 k=4）；
- 疲劳累积寿命 N = 10^log a·Δσ^−m（DNV-RP-C203 C1 in air：log a = 12.164，m = 3）。

基准船取 KCS 量级公开几何（无实船数据依赖）：

| 参数 | 符号 | 值 | 单位 |
|---|---|---|---|
| 垂线间长 | L | 230.0 | m |
| 型宽 | B | 32.2 | m |
| 吃水 | T | 10.8 | m |
| 型深 | D | 19.5 | m |
| 排水量 | Δ | 52 030 | t |
| 方形系数（输入） | Cb | 0.651 | — |
| 板厚 | t | 15 | mm |
| 加强筋/板格间距 | b_req | 600 | mm |
| 材料 | E / ν / σy | 206 GPa / 0.3 / 235 | MPa |

**几何前置校验**（先验后算）：由 Δ/ρ = 52 030/1.025 = 50 761 m³ 反算
Cb = 50 761/(230·32.2·10.8) = **0.635**，与输入 0.651 相差 2.5% < 15%，
几何自洽，可进入强度判据。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

四步，全部机器可算、可重放、无手抄：

1. **探针层**：对三个端点各打 7 组变体（基准、板厚×2、型深×1.5、排水量×2、屈服 355、
   板格间距×2、几何相似 λ=1/2），共 **21 次调用**，原始响应逐条落盘为 fixture。
2. **判据层**：每条判据只允许三类参照——闭式解 / 规范值 / 物理界限，
   **>15% 相对误差判 FAIL**（平台精度标准）；上限型量（工作应力、许用应力）按"须 ≤ 限值"判。
   共 12 条判据（J1–J12），分布：船体梁 6、板格屈曲 4、疲劳 2。
3. **部署面层**：比对在线进程工作树与修复分支的源文件指纹（字节数 + MD5 + mtime），
   以区分「代码错（CODE_DEFECT）」与「部署漂移（DEPLOY_DRIFT）」。
4. **抗假审计层**：反例测试注入"物理正确"的合成响应，要求量级类与规范类判据全部转 PASS
   （实测 8/12 转 PASS），并断言指纹相同时判决必须翻为 CODE_DEFECT。

工具链：Python3 + urllib（探针）+ matplotlib/Agg（出图）+ pytest（24 项验收）。
**容量纪律**：本机 load15 = 120.96 ≥ 100（nproc=128），故全程只做闭式算术与 HTTP 探针，
未起任何 CFD/DEM 重算力进程。

## 4. 注意点（坑 / 局限 / 适用范围）

1. **最大坑：把"已合并"当成"已生效"**。报告 1192 的修复在分支侧真实存在（测试也是绿的），
   但服务面读的是另一棵树。任何"复核通过"的结论必须以**服务面响应**为裁决对象，
   源码/分支存在性不能替代部署验证——本单的指纹比对就是为此加的机器门。
2. **判据类型要分清**：工作应力、许用应力是**上限型**量（须 ≤ 限值），若按对称 ±15%
   判等值，物理正确的 103.8 MPa 会被 175 MPa 判 FAIL（本单初版即踩此坑，已在反例层固定）。
   尺度律/幂指数类判据则必须用**相对误差**判。
3. **单点量级命中 ≠ 物理正确**（与 m1600 的 V4 教训同源）：板格屈曲端点在 t 与 b 通道上
   精确正确（J7/J8 PASS），但系数 k 错 3.6 倍（J6），只看单一工况会误判为 REAL。
   故本单对同一物理量同时设"量级判据 + 尺度律判据"。
4. **弯矩取值的作用域**：J3 的闭式值依赖 M = 1.173×10⁶ kN·m（KCS 量级设计弯矩，沿用 m1600
   取值）。J1/J2 用规范许用与屈服界限作判据，不依赖 M 假设，结论因此与 M 无关。
5. **疲劳判据的年循环率假设**：J10/J11 取 N_yr = 1.0×10⁶ cycles/yr（等于平台自身隐含值
   2.854×10⁷/28.5 = 1.0018×10⁶，取整），该假设在脚本中显式声明；寿命偏差 5.85 倍远大于
   假设不确定度，不影响结论方向。
6. **适用范围**：本审计只覆盖结构强度三端点；`/fatigue/analyze` 内核（BS-D + Miner）
   在 m1600 已判 REAL，不在本次复核范围。也未验证修复分支本身的物理正确性
   （需先部署再复跑本脚本 `--all`，即可一键判定）。
