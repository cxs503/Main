## 1. 案例介绍

### 1.1 物理背景

船舶总阻力 $R_T$ 是船舶总体性能的核心参数，直接影响推进功率需求和能耗评估。
ITTC 推荐的标准分解为：

$$C_T = (1+k)C_F + C_R + \Delta C$$

其中 $C_T = R_T / (0.5 \rho S V^2)$ 为总阻力系数，$C_F$ 为摩擦阻力系数（ITTC-1957 公式），
$C_R$ 为剩余阻力系数（兴波+粘压），$(1+k)$ 为形状因子。

### 1.2 验证对象

平台当前阻力计算使用简化 Holtrop-Mennen 方法，核心公式：

$$S = \pi \cdot B \cdot L \cdot (0.5 + 0.25 \cdot C_b)$$
$$C_F = \frac{0.075}{(\log_{10} Re - 2)^2}$$
$$C_R = 0.002 \cdot (1 + 2C_b) \cdot F_n^{2.5}$$
$$C_T = C_F + C_R$$

## 2. 方法

### 2.1 验证流程

1. 从 `backend/data/benchmark_reference.json` 读取 12 个基准工况的实验数据
2. 使用与 API 端点**完全相同**的计算逻辑（独立复算，不依赖 HTTP 调用）
3. 逐工况比较计算 Ct/Rt 与实验值，计算相对误差
4. 生成 Ct-Fn 对比曲线图
5. 汇总误差分析，识别系统性偏差

### 2.2 判据

- **通过**: $|C_{T,calc} - C_{T,exp}| / C_{T,exp} \leq 15\%$
- **失败**: 误差 > 15%
- **Honest-FAIL**: 已知方法适用范围外的工况，误差大但已文档化

### 2.3 工具链

- Python 3.11 + pytest（测试框架）
- matplotlib（可视化）
- 独立复算脚本（零手抄，所有数字从代码/数据文件读取）

## 4. 误差分析与根因诊断

### 4.1 KVLCC2（丰满油轮）— Ct 误差 ~50-56%

**根因 1：湿表面积公式错误**

当前公式 $S = \pi B L (0.5 + 0.25 C_b)$ 是**轴对称回转体**近似，适用于潜艇等细长体。
对 KVLCC2（Cb=0.81 的丰满船型），该公式给出 S ≈ 40,958 m²，而文献值约 16,500 m²，
**高估约 2.5 倍**。

**根因 2：缺少形状因子 (1+k)**

ITTC 标准方法中，粘性阻力为 $(1+k)C_F$，其中形状因子 $(1+k)$ 对丰满船型约 1.2-1.4。
当前计算直接使用 $C_F$，低估了粘压阻力。

**根因 3：剩余阻力系数公式过于简化**

$C_R = 0.002(1+2C_b)F_n^{2.5}$ 是经验拟合，对低速丰满船型（Fn<0.15）精度有限。

### 4.2 SUBOFF（潜艇模型）— Ct 误差 2-32%，Rt 误差 439-911%

**Ct 误差在 15% 以内是巧合**：由于 $C_T = R_T / (0.5\rho S V^2)$，S 的误差在分子分母中部分抵消。
但 **Rt 误差极大**（439-911%），因为 S 计算值（4.36 m²）与实验值（5.42 m²）偏差 19.6%。

**物理有效性**：Holtrop 方法标定于 Cb>0.55 的商船，SUBOFF（Cb≈0.51，Fn>0.4）
超出方法适用范围。当前 Ct 误差较小是数值巧合，不代表方法正确。

### 4.3 DTMB-5415（水面战斗舰）— Ct 误差 7-602%

低速工况（Fn=0.34）误差 31%，中速（Fn=0.69）误差 7.5%，高速（Fn>1.3）误差急剧增大。
高速时兴波阻力占主导，简化 $C_R$ 公式完全失效。

## 5. 注意点与局限

### 5.1 已识别的算法缺陷

| 缺陷 | 影响 | 优先级 |
|------|------|--------|
| 湿表面积公式仅适用于轴对称体 | KVLCC2 Ct 误差 ~50% | P0 |
| 缺少形状因子 (1+k) | 所有船型粘性阻力低估 | P0 |
| 剩余阻力系数公式过于简化 | 高速工况误差极大 | P1 |
| 无船型适用范围检查 | 用户可能误用 | P1 |

### 5.2 改进建议

1. **P0**: 湿表面积公式改为船型自适应：
   - 商船：Holtrop-Mennen (1984) 公式
   - 潜艇/回转体：当前公式（或更精确的 Gertler 公式）
   - 高速瘦长船：Danckwardt (1959) 近似

2. **P0**: 引入形状因子 $(1+k)$，使用 Hughes 或 Holtrop 经验关联式

3. **P1**: 剩余阻力系数改用 Holtrop 完整公式（含船型修正项）

4. **P1**: 增加船型适用范围检查，对超出范围的工况返回 warning

### 5.3 本报告局限

- 仅验证了 12 个工况，未覆盖完整速度范围
- 实验数据来自文献，可能存在尺度效应修正差异
- 未验证稳性计算（留待后续）

## 6. 误差判定

| 船型 | 关键量 | 最大误差 | 是否<15% | 说明 |
|------|--------|---------|---------|------|
| KVLCC2 | Ct | 56.1% | **否** | 湿表面积公式错误 + 缺形状因子 |
| SUBOFF | Ct | 32.1% | **否**（仅 Fn>0.9） | 方法适用范围外 |
| SUBOFF | Rt | 911.2% | **否** | S 计算值偏差 |
| DTMB-5415 | Ct | 602.3% | **否** | 高速工况 Cr 公式失效 |

**结论**: 当前阻力计算对 KVLCC2（平台主要目标船型之一）的 Ct 误差约 50-56%，
**远超 15% 可接受阈值**。需要优先修复湿表面积公式和引入形状因子。
