# 推进学科验证欠账核查（m1413）

**范围**：`propeller.open_water` / `calculations.propulsion` / `propeller-design/*` 的证据等级复核
**方法**：自洽-物理判据（定义恒等式 + 动量理论上界 + 输入敏感性），不依赖文献表值
**结论**：两项能力声称 REAL，实测判定 **MOCK**（15 项判据失效）；锚点套件 11/11 通过（最差相对误差 4.6e-16）

## 1. 为什么这是"验证欠账"

| 证据链环节 | 状态 |
|---|---|
| `audit_capabilities` 分级 | `propeller.open_water` = **REAL** |
| `backend/data/benchmark_reference.json` | 12 个算例，**全部是阻力**（SUBOFF / DTMB5415 / KVLCC2），零推进算例 |
| `backend/services/ship_proxy.py` | 只代理 `resistance` + `stability`，**无 propeller 端点** |

即：分级为 REAL 的能力在全仓范围内没有任何机器可裁的证据。本单补的是**判据本身**，
而非再写一份"跑通了"的说明。

## 2. 锚点套件（`tools/benchmarks/propulsion_anchors.py`）

全部为文献无关的**精确定义式 / 量纲不变性 / 由第一性原理推导的上界**，
因此可离线自证，不引入任何"记忆里的表值"（那类数值才是本仓最危险的伪证据来源）。

| 编号 | 判据 | 类型 | 结果 |
|---|---|---|---|
| P-A1..A3 | ITTC-57 摩擦线在 Re=10^k 处退化为精确有理数 0.075/(k−2)² → C_F(10⁶)=4.6875e−3, C_F(10⁷)=**3.000e−3**, C_F(10⁹)=1.530612e−3 | 恒等 | PASS |
| P-B1 | 敞水效率恒等式 η_o = J·K_T/(2πK_Q)（经 K_T/K_Q 定义往返） | 恒等 | PASS |
| P-B2 | 动量二次方程数值解 vs 闭式 η_i=2/(1+√(1+C_T)) | 推导一致性 | PASS (≤1e−10) |
| P-B3 | 物理可容许上界 η_o ≤ η_ideal(C_T) | 上界 | PASS |
| P-C1 | Froude 缩放不变性（T∝λ³，**Q∝λ⁴**） | 不变性 | PASS (4.6e−16) |
| P-D1 | 推进链恒等式 η_D = η_o·η_H·η_R | 恒等 | PASS |
| P-D2 | P_D = 2πnQ | 恒等 | PASS |
| P-E1 | 0.7R 空泡数闭式 | 恒等 | PASS |

**开发期被锚点自己抓出的两个错误**（保留为教训）：
1. K_Q ∝ Q/(ρn²D⁵) ⇒ 力矩在 Froude 缩放下按 **λ⁴** 缩放，不是 λ³（初版误用 λ³，被 P-C1 打红）；
2. 推进链若同时用敞水 Q 与 η_R，会重复计入 η_R（初版 0.516 vs 0.732，被 P-D1 打红）。

## 3. 对在线平台的判定（判据 J1–J7，`platform_propulsion_judge.py`）

### 3.1 B 系列回归（`POST /propeller-design/wageningen-b`）

固定几何 (P/D=1.0, Z=4, A_E/A_O=0.55) 扫 J：

| J | K_T | K_Q | 报告 η₀ | J·K_T/(2πK_Q) 反推 | 动量上界 η_ideal | 判定 |
|---|---|---|---|---|---|---|
| 0.2 | 0.2730 | 0.0273 | 0.318 | 0.318 | 0.375 | OK |
| 0.4 | 0.2310 | 0.0231 | 0.637 | 0.637 | 0.535 | **J2 越界** |
| 0.6 | 0.1890 | 0.0189 | 0.850 | 0.955 | 0.791 | J1+J2 |
| 0.8 | 0.1470 | 0.0147 | 0.850 | 1.273 | 0.885 | J1+J2+J3 |
| 1.0 | 0.1050 | 0.0105 | 0.850 | 1.592 | 1.049 | J1+J2+J3 |

决定性证据（不依赖文献）：

- **J4 `K_Q/K_T ≡ 0.1000`** 在全部 13 个算例（J、P/D、Z、A_E/A_O 四维扫描）中精确不变。
  真实 B 系列回归中该比值随载荷与几何显著变化（约 0.15–0.20），恒为 0.1 只能是占位式。
- **J5 η₀ 在 J ≥ 0.6 处饱和于 0.850**，且对 P/D ∈ {0.8, 1.0, 1.2, 1.4}、Z ∈ {3,4,5,6}、
  A_E/A_O ∈ {0.35, 0.55, 0.85} 全部返回同一个 0.850 —— 是 clamp，不是效率。
- **J1 恒等式最大偏离 87%**（J=1.0）；**J3 反推 η₀ = 1.592 > 1**，违反能量守恒。
- K_T 对 P/D 呈**线性**（斜率 0.063），真实 B 系列为 P/D 的二次式。

> 注：K_T 量级（J=0.6 时 0.189）在 P/D=1.0 的合理带内，说明模块并非全空壳，
> 而是 **K_T 用了一阶近似、K_Q 由固定比例生成、η₀ 被钳位**。故判 **MOCK** 而非 STUB。

### 3.2 推进链（`POST /calculations/propulsion`，L=150 m, ∇=25000 t, D=5 m, n=120 rpm）

| 航速 kn | T [N] | Q [N·m] | P_D [W] | η_o | η_H | η_R | η_D |
|---|---|---|---|---|---|---|---|
| 10 | 3143.0 | 1042.0 | 13094 | 0.988 | 1.10 | 1.00 | **1.087** |
| 14 | 3016.5 | 1010.4 | 12697 | 1.369 | 1.10 | 1.00 | **1.506** |
| 20 | 2826.7 | 962.9 | 12100 | 1.923 | 1.10 | 1.00 | **2.115** |

- **J6 η_D 与 η_o 均 > 1**（最高 2.115），违反能量守恒；链内乘法本身自洽（误差 2e−4），
  说明是**输入量纲/耦合错误**而非显示错误。
- **η_H ≡ 1.10、η_R ≡ 1.00 为硬编码**，不随几何/载荷变化。
- **J7 排水量 25000 → 250000 t 输出逐位相同**：推力与阻力-排水量完全解耦。
  量级上，150 m / 25000 t 船 14 kn 阻力应约 10² kN 量级，而返回 T ≈ 3.0 kN，
  偏差约两个数量级 → 疑似 kN↔N 单位错误或阻力未参与。

### 3.3 空泡数（`POST /propeller-design/cavitation`）

平台 σ_n = 2.749，按 0.7R 标准定义（V_R = √(V_a² + (0.7πnD)²)）
本仓锚点 σ_n = 4.928，**偏差 44.2%**（> 15% 不可接受线）。平台标注方法为
"Burrill 空泡准则"但未公开 σ 定义，属**定义未文档化导致的可复现性缺口**；
该差异不必然等于算错（可能含推力载荷修正），但按纪律判 **WITHHELD**，需平台补文档。

## 6. 建议（按优先级）

1. **降级**：把 `propeller.open_water`、`calculations.propulsion` 从 REAL 改为 MOCK，
   待 §3 判据全绿再升回。分级失真比算错更危险——下游派单会以此为"已验证"。
2. **修 K_Q**：以 K_T 同样的 P/D 二次式单独回归 K_Q，删除 `K_Q = 0.1·K_T`；
   删除 η₀ 的 0.850 clamp，改为 J·K_T/(2πK_Q) 直接计算（恒等式即自检）。
3. **修推进链**：t、w、η_R 由船型/载荷计算而非硬编码；推力必须由阻力 R/(1−t) 导出，
   使 η_D = η_o·η_H·η_R < 1 成为**结构性保证**而非事后检查。
4. **补空泡定义文档**：公开 σ_n 与 τ_c 的公式与单位，否则无法复现比对。
5. **剩余欠账**：B 系列 KT/KQ 表值（或 ITTC 敞水试验曲线）入库为
   `backend/data/propulsion_benchmark_reference.json`，届时本套件的 J1–J7 可直接叠加
   绝对量级判据，形成完整三段式（恒等 + 上界 + 表值）。

## 7. 局限

- 在线审计依赖服务可达；本轮审计时刻 8001 曾一度拒绝连接（首轮探测 exit 7），
  说明**该服务存在可用性抖动**，判据套件因此设计为可离线运行。
- §3.1 的 0.535 / 0.791 等上界以 8K_T/(πJ²) 定义 C_T（基于轴向动量、V_a = JnD），
  对重载高 J 点属偏松上界；用于"越界即错"的一侧判定是充分的，但不宜当作紧致精度基准。
- 未覆盖：桨后伴流场、空泡剥蚀、非均匀来流下的非定常推力——这些需要试验或 CFD，
  不在本套件能力内。
