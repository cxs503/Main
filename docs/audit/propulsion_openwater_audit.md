## ① 案例介绍（物理背景 / 参数域 / 基准）

敞水性能是「船—机—桨」匹配链的第一环：推力系数 K_T(J)、扭矩系数 K_Q(J) 与敞水效率
η0 = J·K_T/(2π·K_Q) 决定给定伴流分数与推力减额下的推力、收到功率与桨负荷；其误差会沿
"推力→扭矩→功率→EEDI/航速"链路放大。平台能力台账把 `propeller.open_water` 记为 **REAL**，
被审端点返回 `method: "Wageningen B系列回归公式"`，即对外声称按 Oosterveld & van Oossanen (1975)
B 系列回归多项式实现。

审计参数域：叶数 Z ∈ {4,5}，螺距比 P/D ∈ {0.6, 0.8, 1.0, 1.2, 1.4}，盘面比 Ae/A0 ∈ {0.40, 0.70, 1.00}，
进速系数 J ∈ [0, 1.4] 步长 0.05，共 **870** 个采样点（HTTP 200 866 个，覆盖率 99.54%；
4 个超时点如实剔除不插补）。

文献基准：B4-70 / P/D=1.0 / Ae/A0=0.70 的 K_T、K_Q、η0 数据表，快照存
`docs/audit/data/propulsion_wageningen_ref.json`（sha256 前缀 `7089c64c797f4a4e`，源 `Wageningen B-Series propeller data (Oosterveld & van Oossanen, 1975)`）。

## ② 怎么做的（方法与工具链）

判据只依赖两类**非循环依据**，避免"用实现验自己"：

1. **定义级恒等式**（与被审实现无关）：η0 ≡ J·K_T/(2π·K_Q) 必须自洽；J→0 时 η0→0；
   K_Q/K_T 必须随工况变化（若恒定则说明 K_Q 是 K_T 的常数倍复制，而非独立计算）。
2. **文献基准表**逐点对表（B4-70 单系列），阈值沿用平台精度标准 15%。

工具链（均在本工作树）：`tools/audit/prop_openwater_probe.py`（只读探针，落 `artifacts/audit/prop_openwater_probe.json`）
→ `tools/audit/prop_openwater_audit.py`（判据机 G1–G10，落裁决 JSON/MD 与 4 张图）
→ `tests/test_prop_openwater_audit.py`（10 项回归：判据可分辨性 + 工件回放，离线可跑）。

判据**可分辨性**单独受测：注入复刻端点行为的合成样本必须 FAIL，注入"自带零推力点、几何相关、
K_Q 非 K_T 常数倍"的玩具物理模型必须 PASS —— 证明这些判据不是恒 FAIL 的死判据。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. "调用成功 + 字段齐全"**不等于 REAL**。端点 HTTP 200、返回三项系数、还带
   `method: "Wageningen B系列回归公式"` 字样，实现却是 `KT=0.3·P/D−0.2·J`、`KQ=0.03·P/D−0.02·J`
   线性式乘 `(0.5+Ae/A0)` 再加三段 clamp。审计必须看物理不变量，不能看字段名。
2. 同仓 `backend/methods/propulsion/wageningen.py` 文件头郑重引用 Oosterveld & van Oossanen (1975)，
   但系数表大量条目为 ±0.00001000 占位（39 项 KT 表中同一数量级重复 13 次）——**引用文献名 ≠ 使用文献系数**，
   这是比端点更隐蔽的一类伪 REAL。
3. 15% 对表所用基准是平台内"近似"表（其 `notes` 自述 approximate）且 J=0.8 有算术错误，因此 G9 只能作量级证据；
   **定级主依据是 G2/G3/G4/G6/G7/G8 六条结构性判据**，它们不依赖任何基准表。
4. 局限：判据 G6 的"零推力点应存在"以 J≤1.4 为窗、K_T≤0.02 为界；G8 的 15% 弱依赖门为工程经验值而非文献硬数。
5. 未做：**未修改被审仓** `ship-performance-platform`（不在本工作树白名单内），修复建议见末节，由对应席位落地。

## ⑥ 误差判定（逐项，显式回答"是否 <3%"）

| 关键量 | 基准值 | 端点相对误差 | 是否 <3% |
|---|---|---|---|
| K_T @ J=0.0 | 0.40 | 10.0% | 否 |
| K_T @ J=0.6 | 0.18 | 20.0% | 否 |
| K_T @ J=1.0 | 0.03 | 300.0% | 否 |
| K_Q @ J=0.6 | 0.027 | 20.0% | 否 |
| K_Q @ J=1.0 | 0.008 | 50.0% | 否 |
| η0 @ J=0.6 | 0.6366 | 33.5% | 否 |
| η0 @ J=1.0 | 0.5968 | 42.4% | 否 |
| η0 对 P/D 敏感性 | 应 ≥1% | 实测 0.0（零敏感性） | 否 |
| K_Q/K_T 工况变异 | 应 ≥5% | 实测 0.0e+00（恒定） | 否 |

**结论：无一项关键量满足 <3%，且误差随 J 单调放大（J≥1.0 处 K_T 偏差 300%）。**
这不是"精度不足"，而是模型形式不含物理 → 端点应降级为 **MOCK**，台账中的 REAL 属 OVERCLAIM。
