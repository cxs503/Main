# 敞水模型对 Wageningen B 系列回归的绝对量级复核（m1637）

**对象**：`backend/services/propeller_open_water.py`（叶元-动量 BEM，能力清单标 `propeller.open_water = REAL`）  
**基准**：Wageningen B 系列敞水回归多项式（Oosterveld & van Oossanen 1975，经 Bernitsas/Ray/Kinley 1981 Report 237 转载），参考实现 `tools/verify/propeller_open_water/reference_bseries.py`；几何 B4-70（Z=4, A_E/A_O=0.70），P/D ∈ {0.8, 1.0, 1.2}。  
**欠账来源**：`docs/audit/m1413_propulsion_verification_debt.md` §6 第 5 条——「B 系列 KT/KQ 表值未入库，绝对量级对标未完成」。m1393 的验证只有自指判据（作动盘上界 + 尺度/密度不变式），本单补齐绝对量级一侧。

## 1. 方法

- 同一几何、同一 J 网格（0.0–1.2 step 0.1，另加 0.85·J0_ref 工作点）分别跑 BEM（40 环带）与回归多项式；
- 分区判据（两类误差性质不同，不可混算）：**螺旋桨区** `0.2 ≤ J ≤ 0.85·J0_ref`（偏差）、**制动/风车区** `J > J0_ref`（结构性 bug）；
- 量定义与本仓锚点套件一致：K_T = T/(ρn²D⁴)、K_Q = Q/(ρn²D⁵)、η_0 = J·K_T/(2πK_Q)；
- 工件：`artifacts/m1637/bem_vs_bseries_{baseline,final}.json`（机器生成，数字零手抄），图示 `docs/asset/m1637/bem_vs_bseries.png`；
- 复现：`python3 tools/verify/propeller_open_water/bem_vs_bseries.py --tag final`（约 6 s，纯解析/叶元计算）。

## 4. 由基准抓出并修复的缺陷：制动支动量耦合失效

原实现把诱导轴向速度搜索区间设为 `u ∈ [1e-6·ωr, 3·ωr]`（单侧非负）。超过 J0 后环带从流体取能（a<0，风车/制动状态），解应落在 u<0；单侧区间下二分不成立，代码落入 `u≈0` 回退分支，模型退化为**未耦合叶元理论**，制动推力被放大到回归值的 8.7 倍。
修复：下界放开至 `max(-0.999·V_a, -0.9·ωr)`，即在动量理论有效域 a > −1（V_a+u > 0）内允许负诱导速度。

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 制动区最大 |K_T,BEM / K_T,ref| | 8.69 | 3.33 |
| 螺旋桨区平均 |ΔK_T| % | 23.3 | 23.3 |
| 最大 |ΔJ0| % | 7.4 | 7.3 |

修复只影响超 J0 的制动支，工作区数值与既有 29 项单测不变——说明剩余偏差另有来源（§6）。

## 5. 注意点与局限

- 参考系数表为一次性转录（Report 237 转载），本单以「物理自洽 + 图谱量级（J0、η_max）」双向自检，未直接核对 Oosterveld 原文页——二手转载风险仍在。
- 回归式有效域 J∈[0,1.5]、P/D∈[0.5,1.4]、A_E/A_O∈[0.2,1.05]、Z∈[2,7]；本单三点在域内，域外（大侧斜、非 B 系列剖面）不得引用本基准。
- BEM 用 2D 升力线斜率 2π sinα 与常数 C_D0=0.012、无剖面弯度/数据库，是剩余 K_T 高估的主嫌，不在本单修复范围。
- 曾试 Helmbold 有限展弦比升力线修正（叶片 AR=1.22，斜率降为 0.379·2π）：实测 K_T 仅动 0.5%，无收益，已回滚，不留无效代码。
- 未覆盖：桨后伴流、空泡、非定常来流。`tests/test_propeller_open_water.py::TestBatchWrapperWiring::test_batch_executor_uses_bem_model` 为**存量失败**（`tools/batch_scan/batch_executor.py` 返回体缺 `model` 键），与本单改动无关，本单未触碰该文件。

## 6. 误差判定（是否 < 3%）

| 关键量 | 基准 | 误差 | < 3%？ |
|---|---|---|---|
| 制动推力 |K_T| 比（J = 1.08·J0_ref） | 回归值 | 3.33×（修复前 8.69×） | 否 |
| 零推力进速比 J0 | 回归 J0 | ≤ 7.3% | 否 |
| 峰值效率 η_max | 回归峰值 | ≤ 5.1% | 否 |
| 螺旋桨区 K_T | 回归 K_T | 平均 23.3%（最大 37.3%） | 否 |
| 螺旋桨区 K_Q | 回归 K_Q | 平均 12.0% | 否 |
| 螺旋桨区 η_0 | 回归 η_0 | 平均 10.3%（最大 21.9%） | 否 |

**结论（honest）**：绝对量级对标**未达 3% 线，也未达 15% 可用线**——K_T 平均高估 23%、K_Q 高估 12%、η_0 高估 10%、J0 偏小 7%。
因此 `propeller.open_water` 的正确读法是：**守恒/上界/不变式侧成立（REAL 的物理性），但绝对量级精度不足以支撑航速预报用**；
剩余欠账与路线：①按 B 系列剖面几何（NACA 66 mod、a=0.8 弯度线）替换 `2π sinα` 与常数 `C_D0`；②引入叶栅与叶片数相关诱导修正；③补 P/D × A_E/A_O 二维扫描后重测。残余偏差已固化为回归闸门（`tests/test_bem_vs_bseries_reference.py`），恶化即红。
