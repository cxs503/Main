# 数字孪生疲劳链独立复核：ASTM E1049-85 计数 + DNV-RP-C203 S-N + Rayleigh 闭合（m1653）

- 任务：`tp-arch-1` 自找活（strategy 席），mission 1653
- 被复核对象：`backend/services/digital_twin/models/fatigue.py`（数字孪生「结构疲劳」模型，已合入主线）
- 复核类型：**验证欠账清偿**（已合并功能对标准规范 / 解析基准独立复核）
- 复核结论：**1 个真实缺陷（已修）+ 1 个精度缺陷（已改默认路径，遗留待办）**，其余 4 项基准误差 <3 %
- 证据分级：冻结的基准量（ASTM 计数、DNV S-N、Rayleigh 积分）为 **REAL**；
  实船结构损伤历史仍为 **WITHHELD**（平台无实测损伤样本，全尺度剩余寿命不可证）

## 1. 为什么要复核：原来的"验证"是自证循环

模块原 docstring 声称：

> validated in the test-suite against rain-flow counting of a synthesised bimodal
> stress record (the correction reduces the narrow-band over-prediction to a few %).

但 `spectral_vs_rainflow()` 里，**谱方法**和**时域参考**都出自同一个模块：

- 参考侧 `rainflow_damage()` 是自研雨流计数器，**从未与任何外部基准对齐**；
- 被测侧 `rayleigh_bilinear_moment()` 是自研闭式积分。

两者一起错就一起"通过"。复核第一步是把参考侧钉死在标准上（ASTM E1049-85 §5.4 计数规则、
§5.4.4 残段半循环、DNV-RP-C203 curve F 参数），第二步才是拿它去量被测侧。

## 3. 结果

### 3.1 缺陷一：残段（residue）按整循环计 —— 已修复

ASTM E1049-85 §5.4.4 规定，3 点规则收敛后仍留在栈上的转折点构成 **半循环**（Miner 求和中权重 0.5）。
原实现把每个残段对直接当成一个整循环 `1/N(S)` 累加，属标准偏离：

<!-- TABLE_ASTM -->

| 量 | ASTM E1049-85 公布值 | 模块修复后 | 模块修复前（残段按整循环） |
|---|---|---|---|
| 闭合循环 range | 3, 4, 8 | 3, 4, 8 | 3, 4, 8 |
| 残段 range | 8, 6 | 8, 6 | 8, 6 |
| 循环当量数 | 3 + 0.5×2 = 4.0 | 4.0 | 5.0 |
| Miner 损伤 | 8.001827e-11 | 8.001827e-11 | 1.098879e-10 |
| 相对误差 / 偏差 | — | 0.00 % | +37.33 %（高估） |


对**长记录**影响小（残段占比低），但对**短记录/事件型记录**（冰致循环、传感器小时窗、极值事件）
是系统性高估。修复后模块输出与 ASTM 公布分解逐项相等（相对误差 0.0），并新增
`n_full_cycles` / `n_half_cycles` / `max_full_range_MPa` 三个可审计字段。

### 3.2 缺陷二：Wirsching-Light 宽频修正过度修正（非保守）—— 已改默认路径

5 条已知 PSD 的合成记录上逐一实测（图 2）：

| 谱（12 万点，σ_rms = 10 MPa） | ε | λ_WL | 雨流损伤 | 窄带/雨流 | WL/雨流 | 窄带误差 | WL 误差 | <15 %（窄带） | <15 %（WL） |
|---|---|---|---|---|---|---|---|---|---|
| narrow_mono (Hs5,Tp8) | 0.683 | 0.838 | 1.7676e-04 | 1.1010 | 0.9221 | +10.1 % | -7.8 % | 是 | 是 |
| broad_mono (Hs5,Tp4) | 0.421 | 0.873 | 3.5036e-04 | 1.0157 | 0.8864 | +1.6 % | -11.4 % | 是 | 是 |
| bimodal sep3 50/50 (Hs5-8 + Hs2-12) | 0.697 | 0.836 | 1.6592e-04 | 1.1282 | 0.9437 | +12.8 % | -5.6 % | 是 | 是 |
| bimodal sep3 90/10 (Hs5-8 + Hs1.6-12) | 0.692 | 0.837 | 1.6876e-04 | 1.1238 | 0.9404 | +12.4 % | -6.0 % | 是 | 是 |
| bimodal close (Hs5-6 + Hs3-9) | 0.652 | 0.840 | 2.1923e-04 | 1.0710 | 0.8999 | +7.1 % | -10.0 % | 是 | 是 |


读法：
- **窄带（Rayleigh）谱方法**对每一条谱都**高估**（+1.6 % ~ +12.8 %），方向上是保守的、且落在平台
  15 % 判据带内；这正是船级社对船体波浪诱导载荷的常规做法（DNV-RP-C203 窄带法）。
- **Wirsching-Light 修正**把误差翻到负侧（−5.6 % ~ −12.2 %），在平台自己的参考记录上更是 −14.5 %
  （修复前 −15.6 %，见 3.3 表）。原因：谱矩带宽 `ε` 对**双峰谱**严重高估"损伤相关带宽"——
  双峰分离时 ε ≈ 0.7 而雨流损伤几乎等于窄带值，`λ = a + (1−a)(1−ε)^b ≈ 0.84` 就被无谓地乘了上去。
  非保守 = 低估损伤、高估寿命，比保守高估更危险。

因此把**报告的损伤改为窄带值**（`damage_wave`），Wirsching-Light 结果保留为诊断量
`damage_wave_wideband`（`spectral_fatigue(..., apply_wideband=True)` 可回到旧路径）。
最坏情况误差由 15.6 % 降到 14.5 %，方向由"非保守"翻成"保守"。

## 4. 误差判定（逐项回答"是否 <3 %"）

| 关键量 | 基准 | 相对误差 | <3 % ? |
|---|---|---|---|
| 雨流循环分解（ASTM 经典序列） | ASTM E1049-85 Fig.6 公布分解 | 0.0 % | ✅ |
| 雨流损伤（扩张/嵌套螺旋算例族） | 3 点规则解析分解 | <1e-10 % | ✅ |
| S-N `N(100 MPa)` | DNV-RP-C203 curve F = 5.0e5 | 6.9e-3 % | ✅ |

且必须按保守侧取用。** 剩余寿命的绝对精度不可证（无实测样本），报告一律按 WITHHELD 处理。

## 5. 注意点 / 局限 / 适用范围

1. **窄带法的 3 % 目标未达成**：Rayleigh 窄带公式对宽/双峰谱天然有 1.6 %~12.8 % 的系统性高估，
   这是方法固有误差，不是实现误差。要进 3 % 需上时域雨流或 Benasciutti-Tovo 类宽频修正
   （需真实 PSD 输入，而孪生当前只有 `ε` 经验式，无谱），列为后续待办。
2. **Wirsching-Light 的适用边界**：`λ(m,ε)` 由谱矩带宽标定，对连续宽谱有效，对**双峰分离谱**会
   过度修正（本报告实测）。孪生用 `spectral_width()` 的经验式给 ε（0.45~0.90），并非由 PSD 算得，
   这层"假设的带宽"本身就是精度短板。
3. **`σ_rms` 语义**：`spectral_fatigue` 取 `σ_rms = σ_a/√2`（σ_a 为 UR S11 波弯矩幅值名义应力），
   `nu0 = 1.4/Tp` 为经验循环率；这两处是工程近似，未在本单复核（缺目标谱输入，无法独立定标）。
4. **S-N 只查了 curve F in air**：海水自由腐蚀 + 阴极保护两套曲线（curve F1/F3）与其厚度修正
   未实现，冰区低温/冲蚀耦合也未进入本模型——适用范围限于"空/大气环境波浪诱导疲劳"。
5. **截面模量是理想化箱型**：`Z = B T²/6`（等厚度甲板/舷侧），未含板格屈曲、开口与肘板；
   作为孪生的量级代理可以，作为送审计算不行。
6. **短记录**：ASTM 半循环规则下，记录短于约 10 个循环时残段占比高（本单经典序列 4 个循环当量中
   1 个来自残段），损伤估计的方差大；传感器小时窗路径（`damage_from_stress_rms`）用的是闭式谱解，
   不受此影响，但也就带上了第 1 条的系统性高估。

## 附录 A：嵌套收缩螺旋的解析分解（3 点规则手工推导）

转折点序列 `0, n, −n, n−1, −(n−1), …, 1, −1, 0`：

1. `0, n, −n`：`r1 = |n−0| = n`，`r2 = |−n−n| = 2n ≥ r1` → 闭合一个循环 **range n**，移除 `0, n`；
2. 其后每一次"下探再回升"的幅度都严格小于前一次，`r2 < r1` 永远成立 → 不再闭合任何整循环；
3. 剩余栈 `−n, n−1, −(n−1), …, −1, 0` 共 `2n` 个点 → `2n−1` 个**半循环**，range 依次 `2n−1, 2n−2, …, 1`。

故损伤 `D = 1/N(n) + 0.5·Σ_{k=1}^{2n−1} 1/N(k)`；测试对 n = 3/5/9 三点校验，相对误差 <1e-12。
