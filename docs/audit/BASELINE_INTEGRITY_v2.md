## 1. 案例介绍

### 1.1 物理背景

平台上一切「精度合格」结论都是「计算值 X vs 参考值 Y，误差 < tol」。这条判定链的强度
**不超过参考集本身**：参考值错，正确实现会被判 FAIL（假阴性），错误实现会被判 PASS（假阳性）。
因此本任务审计的对象不是求解器，而是**基准（参考集 + 门禁策略）**本身。

选用的都是任何物理自洽的水动力/稳性基准都必须满足的**闭式恒等式**，不需要任何 CFD/求解器：

- 阻力：`Ct = Rt / (0.5·ρ·S·V²)`，`Fr = V/√(gL)`，`V[m/s]=V[kn]·0.514444`，
  物理性下界 `Ct ≥ 1.03·Cf_ITTC57(Re)`；
- 稳性：墙侧公式 `GM = KB + BM - KG`，`KB=T/2`，`BM = I_wp/∇ = B²/(12·T·Cb)`。

### 1.3 几何口径核验（Cb / L / B 先验证再谈精度）

- **L / B / T / S**：SUBOFF 用实测 S=5.42 m²（艇体表面积，L=4.356 m、D=0.508 m）；
  DTMB5415（L=5.72 m、B=0.759 m、T=0.246 m）与 KVLCC2（L=320 m、B=58 m、T=20.8 m）
  **无实测湿表面积**，S 由 Holtrop(1982) 估算（数据集已标注 `wetted_surface_provenance=holtrop_1982_estimate`）。
  S 的口径正确性直接决定 C1 的可信度，已在 E7 项单列判定。
- **Cb**：`Cb` 只以「估算 S 的输入」身份出现（Holtrop 公式含 Cb），本轮判据 C1–C6 **不包含**
  Cb 与排水量/主尺度闭合的自洽判据，故对本轮结论 **Cb 未做独立验证（WITHHELD）**——
  没有型线/静水力表可复算。这是本审计的一个明确覆盖缺口，不能表述为「几何已全部验证」。
- 说明：上一单（m1407 修复）删除过 SUBOFF 上编造的 `cb=0.508 / displacement=0.508`；
  本轮按数据集现值使用，不做二次改写。

1. 用审计器对**修复前**数据集跑 C1–C6 → `audit_before.json`（verdict=FAIL）；
2. 按最小改动修复参考集/门禁库（Rt 由 Ct 恒等式派生、Fr 用记录船长重算、S 标注来源、

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **误差分母口径的坑（本轮自查发现）**：审计器在修复前用「声明值」作分母算偏差、

   不再直接引用工件里的 `deviation_pct` 字段。
2. **参考值错比算法错更危险**：`stability/generic_barge` 旧参考 GM=3.5 m 会让一个**正确**的
   墙侧实现被判 FAIL（假阴性）。基准审计的优先级应高于算法调参。
3. **派生值必须可追溯**：Rt 现由 Ct 恒等式派生，旧手抄值留在 `*_as_listed_20261031`，
   否则下一次审计将无法判断「谁改了谁」。
4. **DTMB5415 高速点超出常规量程**：修复后 Fr=1.374/2.060 属滑行区，若被当作常规排水型
   阻力基准使用会误导算法对比；本轮只保证恒等式一致，不改工况，建议后续单独立项重设工况。
5. **S 来源标注存在遗留缺陷（D1，本轮未修）**：数据集已标 `wetted_surface_provenance=holtrop_1982_estimate`
   的 8 条（DTMB5415+KVLCC2），审计器仍把它们写成 `wetted_surface_source="measured"`、
   `C1.indicative=false`（8/12 条命中）。

   因本单禁止改业务/工具代码（EDIT_WHITELIST: docs/, artifacts/），**如实登记为遗留缺陷**，
   建议下一单修 `tools/audit/baseline_integrity.py`（读 `wetted_surface_provenance` 再决定 indicative）。
6. **审计器 summary 计数器口径混用（D2）**：见 §3.1 注。
7. **端到端未能实跑**：本轮 `call_ship_api`（:8001）仍不可达（返回 404/不可用），

## 6. 误差判定（关键量 vs 基准，逐项显式回答「是否 <3%」）

### 6.1 判定标准与口径声明

- 阈值：owner 升级要求 **关键量 vs 基准误差 < 3%**；回答只允许「是 / 否 / WITHHELD（并写原因）」三种。
- 分母：一律为**基准（参考/真值）**，即 `|X − X_ref| / X_ref`；修复前数值按同一口径重算（见 §5 坑 1）。
- 基准类型分三档，分别标注：**(a) 解析恒等式/定义值**（可精确复算，残差只反映浮点与舍入）；
  **(b) 可复算几何/解析式**（含模型化近似）；**(c) 无基准**（不得回答是否 <3%，只能 WITHHELD）。
- 下表中的「独立复算残差」= 本席用 `gen_error_determination.py` 重算值与工件记录值的差，
  用于证明报告没有照抄工件。
