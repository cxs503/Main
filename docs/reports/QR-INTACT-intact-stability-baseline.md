## 1. 案例介绍

审查对象是船舶总体性能平台完整稳性子域（`POST /api/v1/calculations/stability`），它向阻力/推进链与 IMO 合规判定提供 GM、GZmax、稳性消失角与 GZ 面积判据。
复核用船型必须是**有闭式解**的船型，否则“误差”无法定义：矩形驳船（Cb=Cm=Cw=1）是唯一可给出精确 GZ 的几何，故作为量具船型。参数表（程序化取自工件）：

| 参数 | 符号 | 数值 |
|---|---|---|
| 船长 | L | 100.0 m |
| 型宽 | B | 20.0 m |
| 型深 | D | 10.0 m（低干舷对照 6.3 m）|
| 吃水 | T | 6.0 m |
| 重心高 | KG | 5.0 m |
| 方形系数 | Cb | 1.0（矩形驳船，精确基准适用） |

物理背景：横倾 φ 时浮心横向坐标 KN 由浸没截面形心决定，GZ=KN−KG·sinφ。该驳船甲板边缘入水角（进水角）atan2(D−T, B/2) = **21.80°**，开敞甲板驳船的正浮力曲线在此外终止；水线离开舭部的高舷角为 atan2(2T, B) = 30.96°（取更小者约束 wall-sided 适用区间）。

## 2. 方法

两条**互不共享数值路径**的独立推导构成本次量具，互为校验：

1. 精确截面法（`tools/verify/intact_stability_baseline.py`）：把横剖面矩形按横倾旋转后，用水线半平面做 Sutherland–Hodgman 裁剪，二分求水线偏移使浸没面积恒等于 B·T（排水体积守恒、无纵倾），再由多边形形心算 KN，GZ=KN−KG·sinφ。可覆盖任意横倾角。
2. 教科书 wall-sided 闭式解：GZ=sinφ·(GM+½·BM·tan²φ)，KB=T/2、BM=B²/(12T)（矩形精确）。仅在水线同时与两舷相交时有效。

量具自检（`tests/test_intact_stability_baseline.py`，26 项全绿）：角 0.5°~20° 内两路径之差 ≤1e-12 m（机器精度）；dGZ/dφ|₀ = GM（相对误差 <1e-4）；排水面积守恒 1e-9；GZ(φ)=−GZ(−φ)；超出 wall-sided 有效区后两路径**必须**显著分离（防止“量具其实是闭式解换皮”）；面积积分与解析积分 ∫₀^Φ sinφ(GM+½BM tan²φ)dφ = GM(1−cosΦ)+½BM(secΦ+cosΦ−2) 相对差 <2e-4。

平台侧只做只读探测：POST 到稳定性端点，取回 kb/bm/gz_max/gz_max_angle/vanishing_angle/area_*/imo_criteria，与基准逐项比对。端点本身不返回 GZ 曲线，故先做**算法归属**（用端点自报的 GM/BM 重建 (GM+½BM sin²φ)·sinφ 并加 40° 以上 (60−φ)/20 衰减），归属误差 <0.5% 才能把“缺陷”定位到公式而非随机噪声——该归属测试已固化为绿测（`test_attribution_gzmax/areas/taper`）。

判据在跑之前固定（C1~C5）：C1 静水要素 ≤2%；C2 GZ(φ) ≤3%（仅在进水角之内可比）；C3 面积判据 ≤5%；C4 端点必须对干舷有响应；C5 IMO 判决必须可证伪。

## 5. 注意点（坑与局限）

1. **量具必须先自证**：解析基准若用 wall-sided 闭式解直接当“精确”，在进水角以外会误判平台偏大/偏小。本次用多边形精确解覆盖全角域，并强制“有效区外两路径必须分离”的测试，堵住这一自欺路径。
2. **可比区间必须先划定**：开敞甲板驳船的正浮力曲线在进水角终止，若拿平台 40° 的值与精确 40° 值比较，得到的“误差”混入了物理定义差异。报告中 C2 只在进水角内计分，进水角外单列。
3. **端点只回标量，不回曲线**：必须先用自报 GM/BM 重建公式并验证归属（<0.5%），否则无法区分“公式错”与“查表噪声”。
4. 矩形驳船是唯一有闭式解的几何，因此本次结论严格成立于 Cb=1；对常规船型，误差量级由 KB/BM 的经验公式主导（3.5 节给出 Cb 扫描），不能把 33% 直接外推到所有船型。
5. 平台端点缺 `depth` 与 `displacement` 的一致性校验（两者同时给出却不互相约束），本次只用 cb=1 与 displacement=L·B·T 自洽的输入，规避该缺陷。
6. 本仓（TensorPlatform）只读探测船舶平台服务（:8001）；修复落在船舶平台仓，已派单 mission **1546**（runner=native，含 EDIT_WHITELIST 与 F1~F5 逐项判据），故本次不在本仓改算法实现。

## 6. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 平台 vs 基准 | 是否 <3% |
|---|---|---|
| KB（Cb=1） | 33.333% | 否 |
| GM（Cb=1） | 28.138% | 否 |
| BM（Cb=1） | 0.008% | 是（公式在 Cb=1 恰好退化为精确 B²/12T） |
| GZ @5°~21° | 最大 27.966% | 否 |
| GZmax | +146.775%（vs 开敞甲板精确值） | 否 |
| area_0_40 | 35.927%（vs 闭箱精确值） | 否 |
| area_30_40 | 49.258% | 否 |
| 稳性消失角 | 平台恒 60°，精确随干舷 1.72°→54.46° | 否（且恒定值本身是不可证伪门禁） |

结论：**六项关键量中仅 BM 一项满足 <3%**，KB/GM/GZ/GZmax/GZ 面积/消失角均远超 3%，且 C4/C5 揭示的不是精度而是模型缺项与门禁失效。按平台证据分级：该子域应判 **MOCK**（几何无关的解析合成），而非其自述的 REAL；修复前不得用于 IMO 合规或船型优化判据。本结论为 honest-FAIL，不粉饰。
