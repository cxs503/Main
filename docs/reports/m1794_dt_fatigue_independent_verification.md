# m1794 — 数字孪生谱疲劳闭合的独立复核（验证欠账清偿 v1）

**席位** platform（tp-impl-4）· **日期** 2026-11-01 · **仓库** TensorPlatform（分支 `agent/m1794`）
**EDIT_WHITELIST**: `docs/`, `tests/`, `artifacts/`

**证据等级主张**: 窄带双折线 Miner 闭合 = **REAL（独立路径复算，误差 1e-9 量级）**

## 1. 案例介绍

数字孪生疲劳链是平台侧唯一把「海况 → 波浪弯矩（IACS UR S11）→ 名义应力幅 → S-N →
Miner 损伤 → 剩余寿命」串起来的在线预报环节，被两条独立入口共用：

* 设计链 `spectral_fatigue()`（`dt_orchestrator` / 在线预报）；
* 传感器链 `damage_from_stress_rms()`（`state_estimator` 的 EKF 量测模型）。

两条链共用同一闭式核 `rayleigh_bilinear_moment()`：

    D_cycle = ∫_0^∞ f_S(S)/N(S) dS ,   f_S(S) = S/(4σ_a²)·exp(-S²/(8σ_a²))
    N(S) = a1·S^-3 (S > S_k) ;  a2·S^-5 (S ≤ S_k)

参数（DNV-RP-C203 曲线 F，空气）：log a1 = 11.699、m1 = 3、m2 = 5、拐点 N = 1e7
⇒ S_k = (10^11.699/1e7)^(1/3) = 36.841 MPa；a2 由拐点连续性构造（`SN_A2 = SN_A·S_k^(m2-m1)`）。

## 2. 怎么做的（方法 / 工具链）

不复用被测模块的任何中间量（不用它的 Γ、不用它的 x_k），只把 `sn_cycles()` 当**被检对象**，
另建三条独立路径：

1. **自适应积分**：S 空间直接积 f_S(S)/N(S)，拐点处断开以消除导数间断
   （`scipy.integrate.quad`，显式 `epsabs=0, epsrel=1e-11`）。
2. **渐近指数法**：σ_a ≪ S_k 时全域落在 m=5 段 ⇒ D ∝ σ⁵；σ_a ≫ S_k 时 ⇒ D ∝ σ³。
   纯解析结论——不完全 Γ 上下界用反、或 knee 判据指数错位，斜率立刻偏离 3/5。
3. **跨链一致性**：同一海况下设计链窄带项 vs 传感器链（Tz = Tp/1.4，与 nu0 = 1.4/Tp 对齐）。

工具链：`artifacts/m1794/gen_verification.py`（纯解析+积分，无服务调用，<5 s）
→ `fatigue_verification.json` + `fig1_fatigue_verification.png`；
回归测试 `tests/test_dt_fatigue_spectral_verification.py`（7 项全绿）。下文数字全部由脚本注入，零手抄。

## 4. 注意点（坑 / 局限 / 适用范围）

- **坑 1（本轮踩到）**：`quad` 默认 `epsabs=1.49e-8`，损伤量级仅 1e-11~1e-6 ⇒ 低应力段
  "提前收敛"，制造假的 4.6e-4 偏差。必须显式 `epsabs=0, epsrel=1e-11`。
  **先怀疑自己的参考实现，再怀疑被测对象。**
- **坑 2**：第一版用固定步长梯形（n=2e5）在 σ=5 MPa 处报 1.9% 偏差 —— 实际被检方正确、我方偏
  1.9%，梯形在 S⁵ 陡升段的离散误差主导。参考实现须两法互校后才具裁判资格。
- **局限 1（WITHHELD）**：模块 a2 由连续性构造 ⇒ log a2 = 14.832；记忆中 DNV-RP-C203 曲线 F
  公开表 log a2 = 15.081（对应 m=5 段更保守约 1.8 倍），但**仓内无该表引文**，本次不作断言，
  记 WITHHELD。建议后续凭标准原文核对；若成立则长寿命段偏乐观。
- **局限 2**：只覆盖**统计闭合**。IACS UR S11 弯矩系数、薄壁剖面模数假设、冰循环率系数
  `ICE_CYCLE_RATE=0.020` 的标定均未纳入判据。
- **局限 3**：`spectral_width()` 带宽经验式（0.62+0.004U+0.002(Tp−8)）无可比基准，本次不计分。
