# 操纵性 MMG 时域求解器的解析裁决（mission m1691）

> 对象：`backend/physics/ship_env_maneuvering`（风-流-冰耦合操纵，mission W3-N08 的实现）  
> 参考船：KVLCC2 形式（L=320.0 m, B=58.0 m, T=20.8 m, Cb=0.8098），U0=7.717 m/s（15 kn），无风/无流/无冰  
> 工具链：Python 3.11 + numpy + scipy(`expm`) + matplotlib；单进程总耗时约 10 s（轻量核算）

## ① 案例介绍与判据缺口

操纵性是船舶总体性能四大水动力学科之一。`validation.py` 给 W3-N08 的评级由两类证据构成：**模型对模型**（另一套独立公式/求解器）与**外部锚点**（IMO 风压）。缺的一类是「时域积分是否真的解了它所声明的 MMG 方程」——若积分器权重、加速度装配或运动学更新写错，只要参考物来自同一套力模型，全部既有检查仍会通过。本单补这类证据：用**精确解析解**（矩阵指数 / 解析恒等式 / 已知收敛阶）作为裁判，对已合并的实现做独立复核，并对其发现的两处缺陷给出最小修复。

## ② 怎么做的

1. **精确线性化**：在直航平衡点对模块自身 `_rhs` 做 Richardson 外推中心差分，得 `A`、`b`；线性化噪声 1.04e-04，平衡残差 du/dt = 1.86e-11 m/s²。
2. **精确解**：`dx/dt = Ax + bδ` 用 Van Loan 增广矩阵的矩阵指数闭式求解（无时间步进），与 RK4 实现完全独立；之字形用分段矩阵指数 + 与仿真器相同的切换规则。
3. **六项判据**：R1 线性极限、R2 RK4 观测阶、R3 左右舷反对称、R4 方向稳定性/稳态收敛/涌浪平衡、R5 运动学与试验量复核、R6 之字形过冲极限；R7 给出标准试验无量纲量（不作外部精度声明）。
4. **工具链**：harness `tools/verification/manoeuvring_linear_adjudication.py`，测试 `tests/test_m1691_manoeuvring_linear_adjudication.py`；本报告数字由 harness 程序化注入。

## ⑤ 注意点与局限

1. **发现并修复两处缺陷**：(a) `simulate_turning_circle` 用带符号艏向判定 90°/180°/360°，负舵（左转）工况的纵距/正横距/战术直径为 NaN 且 360° 判据永不触发（跑到 t_max）；已改为按 |ψ| 判定并取横向距离的模。(b) `steady_turning_solution` 的涌浪残差漏掉离心项 `(m+m_y)vr`，返回点并非积分方程的平衡点（圆上速度偏大 1.94 倍，直径巧合不变）；已补上该项。
2. **只裁实现，不裁模型保真度**：本单证明时域积分/运动学/第二条代码路径解的是所声明的方程，**不**证明 MMG 水动力导数等于实船 KVLCC2 值。后者仍是 WITHHELD（外部数据缺失）。
3. **线性判据只在短时窗成立**：该船型方向不稳定（λ≈1.14e-3 1/s），线性解在 ~880 s 后指数发散，与非线性稳态解不可比；长时窗改用精确运动学恒等式与稳态平衡裁判。
4. **R5 的参照物是梯形积分**：其 O(dt²) 截断误差是 x 向 1e-3 偏差的来源，因此该判据的分辨率约为 1e-3，不宜用于更细的断言。
6. **既有断言重定基（须声明）**：`tests/test_ship_env_maneuvering.py` 两条断言随修复调整——(i) 「稳态残差 N < 1 N」改为按物理尺度判据（N/(0.5 rho L^2 T U^2)<1e-6）并新增涌浪平衡断言，原绝对阈值对 1e9 N·m 量级力矩无判别力；(ii) 「冰区稳态速度比低于静水」不再成立（0.3607 vs 0.3591，差 0.5%）：该不等式此前依赖的正是漏掉离心项的非平衡点，故改为断言冰区回转直径增大、漂角减小，并对速度差设 2% 带宽。两处改动均在此显式记录，未引入新的物理假设。
5. **IMO 判据阈值未作为断言**：本单不引用 MSC.137(76) 的具体过冲限值表，以免引入无法离线核实的常数；R7 只给无量纲量，供后续与 SIMMAN 数据对标时使用。
