## 1 结论摘要

平台内三处同名指标 PSI 的实现互不相同，且与文献定义（分箱边界由基准样本单次确定并复用）
存在实质偏差。本轮把定义收敛到唯一实现 `backend/services/drift_metrics.py`，三处调用方委托之，
并以闭式解 + 场景表给出误差判定：共享实现 vs 闭式解最大相对误差 **0.000%**（判据 <3% ✅）；
旧 `model_monitoring` 实现 vs 标准定义最大偏差 **2791.9%**（>15% 不可接受 ❌）。

| 编号 | 缺陷 | 证据 | 处置 |
|---|---|---|---|
| F1 | 联合 min/max 等宽箱：分箱边界随当前窗口自我重塑，与基准分位箱定义不可比（支撑域外扩场景偏差 2792%） | 场景表 + 图 (a)(b) | 统一改为基准分位箱（共享实现） |
| F2 | 基准分位数去重后不足 3 个边界时，`data_analysis_service._psi` 直接返回 0.0 → 离散数据"完全分离"被判成"无漂移"（漏报 100%） | 两箱数据 p=0.4→1.0：旧实现 0.0，正确值 5.3640 | 改为去重取值中点分箱（`distinct_values`） |
| F3 | eps 兜底三套（1e-10 / 1e-4 / 1e-6），1e-4 等价于给零箱注入 1e-4 质量，系统性抬高/压低 PSI | 同场景 0.2836 / 0.2418 / 0.2250 / 0.2250 | 统一 eps=1e-6 并写入 docstring |

## 2 方法

- 复核对象按源码逐行等价复刻为纯函数（不 import 平台模块，避免数据库依赖），保证审计脚本可独立复算。
- 基准：教科书 PSI 定义 + **两箱闭式解**
  `PSI = (p_cur−p_ref)ln(p_cur/p_ref) + ((1−p_cur)−(1−p_ref))ln((1−p_cur)/(1−p_ref))`。
- 场景：S0 无漂移 → S6 重尾，共 7 组，基准 n=1000，种子 20261101（可复现）。
- KS 侧核对：`_compute_ks_drift` 的纯 numpy 兜底与 `scipy.stats.ks_2samp` 逐位一致（最大绝对差 0.0）。

## 4 改动

1. 新增 `backend/services/drift_metrics.py`：`psi` / `psi_detailed` / `ks_statistic` / `ks_detailed`，
   仅依赖 numpy；分位边界用 `method="lower"` 取实测值，避免线性插值在离散数据上造出不存在的假边界
   （审计中实测：0/1 两值样本插值出 0.6 的伪边界）。
2. `backend/api/model_monitoring.py`：`_compute_psi` / `_compute_ks_drift` 委托共享实现。
3. `backend/services/drift_detection_service.py`：`_psi_test` 委托共享实现（接口与阈值语义不变）。
4. `backend/services/data_analysis_service.py`：`_psi` 委托共享实现，修 F2 漏报。
5. 新增 `backend/tests/test_drift_metrics.py`（15 项）：闭式解、单调性、跨窗口边界不变性、
   F1/F2 回归守卫、KS 与 scipy 逐位一致、三处调用方委托（含 AST 结构级校验，不依赖运行时依赖）。

## 5 注意点与局限

- PSI 是**分箱指标**，对箱内位移与尾箱内越界样本天然不敏感（S5 标准 PSI 仅 0.021，尽管 5% 样本越界）：
  这是 PSI 的定义性局限，不是实现错误；本轮不改语义，只在 docstring 写明，跨域监测建议 KS/Wasserstein 并用。
- 阈值 0.1/0.2/0.25 是为**基准分位箱 PSI** 标定的；历史库里按旧联合箱算出的历史值不可与新值直接比较。
- 平台运行时依赖（psycopg2 / sklearn / cryptography）在本机不齐，三处调用方的运行时等价性断言
  在 CI 全依赖环境下生效；本机以 AST 结构级校验兜底（`np.histogram`/`searchsorted` 不得再出现在调用方）。
- 未改动告警阈值、未重建历史监测数据、未改前端展示。
