# 箱型驳大倾角静稳性力臂 GZ/KN 的平台精度验证（verification debt）

> 证据等级：平台能力 `calc.stability` = REAL（有真实公式实现，非硬编码），但**大倾角精度未经基准复核**。本报告补这份欠账：给出两路独立参考解，对平台 `/stability-imo/gz-curve`、`/stability/gz-curve` 逐点误差判定。

> 任务：mission 1513（selfstart，平台席自主工时）｜算子代码 `tools/ops/stability_gz_benchmark.py`｜用例定义、参考解、判定阈值均在同一文件内可复现。

## 1. 案例介绍（物理背景 / 几何 / 参数）

静稳性力臂 GZ(φ) 是完整稳性衡准（IS Code 2008 Part A 2.2）的唯一输入：面积准则、GZmax 准则、消失角准则全部由它积分或取极值得到。平台实现走经验式路线（KB、BM 用回归式，KN 用 `(BM sinφcosφ + KB sinφ)·(1+0.001φ)`，另叠加 φ>30° 线性衰减与甲板进水 ×0.95 两个经验修正，并对 GZ 做 `max(0, GZ)` 截断）。这类近似对常规船型难以给出可判定的误差，而**矩形剖面箱型驳存在严格闭式解**，是天然验收基准，因此选它做判据载体。

## 2. 怎么做的（方法 / 流程 / 工具链）

**两路互相独立的参考解**（互不共享公式，互为校验）：

1. *直舷式（wall-sided）闭式解*：`GZ = sinφ·(GM + ½·BM·tan²φ)`，`KB=T/2`、`BM=B²/(12T)`。矩形剖面在甲板边缘未入水、舭部未出水时水线面宽度恒为 B，故该式**精确**，适用 φ ≤ 21.80°。
2. *几何裁剪精确解*（全角度可用）：剖面多边形绕龙骨中线横倾 φ 旋转到地坐标系，用 Sutherland–Hodgman 裁剪出 `z≤0` 的浸没多边形，二分水线抬升量使浸没面积守恒（= Cb·B·T），由面积一阶矩（shoelace）得浮心，`KN = η_B`、`GZ = KN − KG·sinφ`。不依赖任何经验式。

**核对流程**：① 参考解自检（守恒量/闭式量/两解互校）→ ② 以平台同一 5° 网格取参考值，逐点算相对误差 → ③ 面积量用同一梯形积分核（隔离‘公式误差’与‘积分误差’，另报 0.25° 细网格积分作积分误差上界）→ ④ 用 IS Code 阈值（与平台 `check_imo_criteria` 同一套阈值、曲线换成参考解）做判据翻转扫描。

**工具链**：Python 3.11 + numpy/matplotlib（仅出图）；HTTP 直连平台 `http://127.0.0.1:8001/api/v1`；判定阈值 3%（对有严格闭式解的量，严于平台 15% 的通用线）。全程无 CFD/无重算，CPU 秒级。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **二分方向坑**：水线抬升量 c 增大时浸没面积单调*递减*（不是递增），初版二分写反导致面积恒为 0、参考解自检立刻报错——这也是先写自检的原因。
2. **适用边界**：矩形剖面闭式解与裁剪解只对棱柱形箱型驳严格；对带舭部圆弧/外飘的真实船型，GZ 基准需真实型线 + 数值积分（本报告的结论不能外推为‘任意船型误差 25%’）。
3. **平台实现的定性判断**：偏差主要来自 KN 近似式缺大倾角项（`½BM sin³φ/cos²φ` 一类项）与 φ>30° 的线性衰减、甲板进水 ×0.95 两个无可溯源的经验修正；`KB = T(0.5+0.05Cb)` 在 Cb=1 时给出 0.55T，而箱型驳精确值为 0.5T（KB 本身就有 10% 误差，虽未在 API 响应中暴露，但通过 KM 反演出 +2.7% 的合成偏差）。
4. **保守性方向不单调**：小倾角段平台**高估** GZ（+3%~+7%，对初稳性不保守），20°–60° 段**低估** 12%~41%（对面积/GZmax 准则偏保守），70° 以上符号翻转。因此不存在‘整体偏保守’的免责空间。
5. **本次未做**：真实船型（KCS/KVLCC2 量产库）的大倾角 GZ 复核需要型线驱动的数值积分，且会触发重算——本机 load15 已 ≥100，按容量纪律未起重算进程；已按拆分逻辑另派修复单。

**结论（honest）**：11 项关键量中 10 项超过 3% 验收线，仅 1 项达标（KM 反演、以及小倾角附近的少数点）。因此**平台大倾角 GZ 精度不满足 3% 判据**；按平台 15% 的通用线，20°–60° 段（最大 −41%，GZmax −25.1%）同样超出，属于**不可接受**区间，需修复而非调参。修复方案见任务派单（mission 拆分说明）与本报告第 5 节。

**参考解本身的精度**：自检显示排水面积守恒 1e-12 量级、dGZ/dφ 与 GM 一致到 1e-10 相对误差、两路独立参考解在直舷式有效区内一致到 1e-11，故上述误差判定不是基准误差引入的。
