# 耐波响应谱矩的频率窗截断欠账：量化裁决与回归护栏（m1696）

**结论先行**：m1645 §局限① 声明的「`response_statistics` 响应矩与疲劳 `m4` 仍为窗内积分、同源偏差未修」
经量化裁决为 **有界偏差、非实质性缺陷**：
- 由周期类量 `Tz_*`（比值 m0/m2）**完全免疫**，|偏差| ≤ 7.7e−5 %（< 1e−4 相对）；
- 由幅值类量（`significant_*`、`sigma_vertical_acc_m_s2`，均为 √m0 型，后者是 m4 型矩）
  在产线网格（ω∈[0.10, 2.00] rad/s，191 点）上带 **单一方向 +0.2728 %** 的正偏差；
- 该偏差是**纯截断**，随上界按下式塌缩：ω_max = 1.0 / 1.5 / 2.0 / 4.0 / 8.0 → 4.35 / 0.862 / 0.273 / 0.017 / 0.001 %（拟合幂次 ≈ −3.4）；
- 全部 35 组（5 工况 × 7 量）比较中 **最大 |偏差| = 0.2729 %**，远低于 3 % 判据线与 15 % 不可接受线。
**故本条欠账按「显式结案为 <0.3 % 有界系统偏差 + 回归护栏」处理，不主张已精确修正。**

---

## 1. 案例介绍

KVLCC2 级油船设计工况（平台自有几何闸门可闭合：Cb/L/B/T 与排水量一致）：

| 参数 | 值 |
|---|---|
| L × B × T | 320.0 m × 58.0 m × 20.8 m |
| Cb / Cwp | 0.8098 / 0.8700 |
| 排水量 | 320 000 t |
| KG / GM_T | 18.5 m / 5.00 m |
| 谱 | JONSWAP(Hs=6 m, Tp=11 s, γ=3.3) 与 ITTC 双参数(Hs=6 m, T1=11 s) |
| 工况 | 迎浪 0 kn、迎浪 ITTC、首斜浪 135°/8 kn、横浪 90°/0 kn、随浪 0°/8 kn |

被审对象：`backend/services/seakeeping.py::response_statistics`（RAO²·S 的谱矩，窗内梯形积分），
及其下游使用者（耐波统计量、垂向加速度 σ——即疲劳链 m4 型矩的同源量）。

## 2. 怎么做的

1. **参照系（不依赖文献表值）**：同一份实现放在超宽超细网格上积分
   （ω∈[0.01, 20.0] rad/s，40001 点）。响应谱密度在高端按 `exp(−kT)·ω⁻⁵`（k=ω²/g）
   **指数**衰减、低端按 `exp(−B/ω⁴)` 衰减，故宽域积分已收敛到远低于 1e−6 相对误差
   （`test_reference_grid_is_converged` 用双倍分辨率实测复核）。
   由此测得的是**积分窗的缺陷**，而不是模型的物理精度。
2. **判据**：对 7 个输出量做产线网格 vs 超宽参照的相对偏差，逐工况列出；
   另做 ω_max 扫描（1.0→8.0）判别"偏差是否来自截断"。
3. **机制说明**：`spectrum()` 把谱按窗内 m0 归一（∫S = Hs²/16），使 Hs 在窗内精确；
   因此幅值量的残余偏差只来自被丢弃的高频尾段上 RAO² < 1 的"亏欠"，故**符号必为正**（实测一致）。
   `Tz = 2π√(m0/m2)` 是比值型量，两矩在同一频带内的截断近似同比抵消，实测偏差量级 1e−6。

## 5. 注意点 / 局限

- **这不是"修好了"**：产线 `response_statistics` 仍是窗内积分，+0.27 % 的正偏差仍然存在；
  本单的价值是把它**界定为有界系统偏差**并加护栏，防止后续席位重复"同源偏差未修"的模糊描述。
- **m4 型矩**用 σ_vertical_acc（∫ω_e⁴·RAO²S）作为同源代表量实测；数字孪生疲劳模块内部的
  `m4` 未逐行复核（模块级审计已在 m1653 做过雨流/宽频修正侧），此处不作越界声明。
- **参照系是同一实现的数值收敛解**，判定的是积分窗缺陷，**不是**与水池试验的物理精度对标；
  绝对 RAO 对模型试验仍为 WITHHELD（仓内无试验数据）。
- 谱峰落在窗外（例如 Tp ≳ 18 s 而 ω_max=2.0）时偏差会远超本文数值，脚本可用于此类工况预检；
  本文未把该区间纳入"有界"结论的适用范围。
- 未修改任何生产默认网格（改动会波及既有耐波/疲劳结果与报告数字，须独立评审单）。

## 6. 误差判定（逐项，显式回答是否 <3 %）

| 关键量 | 基准 | 偏差 | <3 %? | <15 %? |
|---|---|---|---|---|
| Tz_heave（迎浪） | 收敛宽域积分 | 7.7e−5 % | **是** | 是 |
| Tz_pitch / Tz_roll（5 工况全部） | 同上 | ≤ 2.0e−4 % | **是** | 是 |
| significant_heave/pitch/roll（5 工况，NaN 除外） | 同上 | ≤ 0.2728 % | **是** | 是 |
| sigma_vertical_acc（5 工况） | 同上 | ≤ 0.2729 % | **是** | 是 |
| 参照系自收敛性（2 万 vs 4 万点） | 双倍分辨率自比 | < 1e−6 | **是** | 是 |
| 与模型试验的物理精度 | — | **无基准**（仓内无试验数据入册） | 不适用（声明原因，不粉饰） | 不适用 |

**判定**：本条欠账为 <0.3 % 的有界系统偏差，满足 3 % 判据；物理精度对标仍为 WITHHELD。

## 8. 给下次自找活的建议线索

1. 若要让偏差真正归零：给 `response_statistics` 加**解析尾项**——高频端以 `exp(−kT(ω))·ω⁻⁵` 骨架
   + 参考网格实测 RAO² 的幂律拟合做闭式尾积分（不完全伽马，m1645 已具备该工具）。
   验收判据可直接复用本套件：偏差须从 0.27 % 降到 <1e−4。
2. 谱峰外置工况（Tp ≳ 18 s）的偏差包络尚无界，可作为高价值续单。
3. 疲劳模块 `m4` 的逐行同源复核，可与 m1653 的雨流链合并成一条端到端判据。
