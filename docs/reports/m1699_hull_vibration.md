## 1. 背景：为什么先做这一块

`audit_capabilities` 返回的 21 项能力中没有任何一项覆盖 **振动噪声** 学科；在 `backend/`、`tools/`、
`tests/` 全树 grep `vibration|acoustic|blade_rate|6954` 在船舶域内**零命中**。这意味着平台对
"振动/噪声"只能给出不存在（MOCK-by-absence）的结果，而这类结果最危险：它不是报错，而是看起来
像"没有这个功能"，实际却可能被上层写成 0 或空值。近 20 份平台报告的「局限/待办」节也集中
在阻力、推进（敞水 BEM）、耐波、稳性、操纵、疲劳、CII，无一条触及本域。

因此本单的增量不是"再验一遍已合并功能"，而是**给一个完全空缺的学科建立第一块可证伪的核**：
凡是可以给出闭式解的，就用闭式解；凡是要数值的，就用一个独立方法去对撞它；做不到的，
显式拒绝而不是猜。

## 4. 关键踩坑（写入 KNOWN_TRAPS 的候选）

1. **单层源法对闭合体是病态的**，且失效方式极其阴险：`A σ = b` 的残差可以小到 1e-15，
   但势函数是错的。实测圆（纵横比 1）收敛到精确值 −0.27 %，而 2:1 椭圆在 512 面元下给
   `640040 kg/m`，精确值 `1288053 kg/m`（−50 %）；把椭圆压扁到 20:1 变成 −96 %。
   原因是常源强在闭曲面上构成零空间（最小范数解可以去掉它），但还存在**近零空间模态**，
   于是"精确求解"给出一个满足边界条件却势函数错误的解。校正办法是双偶极/混合层
   （Hess–Smith 一族），不是调面板数。**面板加密到 4096 也无济于事（压在 640039 不动）**，
   这一点让"看起来收敛"特别有欺骗性。
2. **刚体模态不能按幅值阈值筛**：自由–自由梁 FEM 的前两阶频率在 1e-4 Hz 量级（舍入噪声，
   甚至出现 −1.2e-6 的负特征值），用 `x > 1e-6*max` 筛会把真正的弹性模态整段丢掉，
   表现为"FEM 与解析解差 99 %"。应按**序号**取第 3 个特征值起。
3. **特征方程残差必须按 cosh(lam) 归一化**：`|cos*cosh−1|` 本身被 cosh(lam) 放大，
   λ≈17 时 1e-15 的根误差在原始残差上就是 1.6e-8，用绝对阈值 1e-9 会假失败。

## 5. 误差判定（逐项回答"是否 < 3 %"）

- 梁特征值 λ1..λ5 vs 公开发表根表：最大相对误差 **1.1e-14 %** → **是**（<3 %）。
- 特征方程残差（按 cosh 归一化）：**1.7e-13 %** → **是**。
- 闭式频率 vs 独立 Hermite 梁 FEM（200 单元）：**1.0e-5 / 3.9e-7 / 5.5e-7 %** → **是**。
- 面元法 vs 精确圆附连水：**0.275 %**（512 面元），Richardson 外推后 **0.0132 %** → **是**。
- 相似律 f(2L)/f(L)：**0 %**（机器精度）→ **是**。
- 叶频运动学与裕度恒等式：**0 %** → **是**。
- **设计算例的绝对 Hz（0.33/0.91/1.78 Hz）：无可比基准 → WITHHELD**。原因是 EI 与干质量是声明
  输入（本树内没有任何实船总振动实测或规范目标值可供对撞），且零频附连水在 0.4–3 Hz 会高估
  5–20 %，即本频率是**下界**。因此本单只把「敏感度曲线 + 叶频线 + 剖面公式估计点」作为可用结论，
  不把 0.33 Hz 当作已验证的实船值报出。
- 面元法在纵横比 > 1.25 的剖面上：**已知失败（−50 %）且已被门禁阻断** → 记为 honest-FAIL 子能力，
  不计入通过项。

## 6. 适用范围与下一步

- 适用：细长船体（L/∇^(1/3) 大）2 节点垂向总振动的量级估算、叶频与结构频率的分离裕度筛查。
- 不适用：局部板格/上层建筑振动、螺旋桨空泡脉动压力、水下辐射噪声、LNG 液舱晃荡耦合。
- 下一步（按价值排序）：①用双偶极面元替换单层源法，把 `MAX_VALIDATED_ASPECT` 提到 ≥ 4 并用
  2:1/5:1 椭圆做门；②高频 Lewis 附连水修正，需先找到本树内可引用的实船实测或 ITTC 推荐值；
  ③按站分布积分附连水（而不是沿船长均布），并给出振型加权；④接 ISO 6954(2000) 舒适度计权
  （需规范原文，当前树内没有，故 NOT_SUPPORTED）。
