## 1 案例介绍（物理背景与对象）

审计对象是平台 `services/seakeeping.py` 耐波性参考核心，证据等级 **REAL**（模型）/ **WITHHELD**（实验精度）。

该模块实现单自由度线性频域响应模型：

```
(M + A) η'' + B η' + C η = F(t)
```

其中：
- 恢复力 C 来自静水力（C33 = ρgAw, C55 = ρg∇GML, C44 = mgGMT），小角度下精确
- 附加质量 A 和阻尼 B 为参数化输入（默认值为常规量级，非拟合）
- 激励力为 Froude-Krylov + Smith 修正 e^{-kT} + 船长方向相位因子 Γ(u)

**验证基准**：不依赖实验数据，而是对以下闭式解析量进行机器精度验证：

| 锚点 | 闭式 | 物理意义 |
|---|---|---|
| 色散关系 | k = ω²/g | 深水波数-频率关系 |
| 遭遇频率 | ωe = ω + kU cosβ | 船速/航向对频率的 Doppler 偏移 |
| 长波极限 | ω→0 ⇒ RAO→1 | 波长→∞时船体跟随水面运动 |
| 共振峰 | r_peak = √(1-2ζ²), H_peak = 1/(2ζ√(1-ζ²)) | SDOF 传递函数共振 |
| 高频衰减 | ω→∞ ⇒ RAO ~ C/((M+A)ωe²) | 对数斜率 -2 |
| 谱矩 | m₀, m₂ (ITTC 双参数谱闭式) | 波浪统计量 |

## 5 注意点（局限、适用范围）

**已验证（REAL 证据）**：
- 所有波运动学闭式（色散、遭遇频率、长度/宽度因子）与解析解一致（机器精度）
- SDOF 传递函数的共振峰位置/幅值与闭式一致（机器精度）
- 长波极限、高频衰减、谱矩闭式均通过
- 强顺浪遭遇频率≤0 时正确标记为 invalid（不静默截断）

**未验证 / 局限（如实声明，WITHHELD）**：
- 附加质量系数 κ33/κ55/κ44 和阻尼比 ζ 为参数化输入，默认值为常规量级，**非拟合到具体船型**
- 激励力的 Froude-Krylov + Smith 修正未与模型试验数据比对
- 模块文档已如实标注：`REAL model / WITHHELD experimental accuracy`
- 本验证**不宣称** RAO 绝对精度达到 <3% 或 <15%——这需要具体船型的模型试验数据
- 线性 SDOF 模型本身不适用于大振幅运动、非线性恢复、砰击等工况
