## 2 怎么做的（方法/流程/关键设置/工具链）

### 2.1 计算方法

平台阻力计算采用 **ITTC-1957 摩擦线 + 经验剩余阻力** 模型：

1. **雷诺数**：Re = V·L/ν
2. **摩擦系数**：Cf = 0.075/(log₁₀Re − 2)² （ITTC-1957 闭式，m1384 已验证与解析解一致）
3. **摩擦阻力**：Rf = ½·ρ·S·Cf·V²
4. **傅汝德数**：Fn = V/√(gL)
5. **剩余阻力系数**：Cr = 0.002·(1 + 2·Cb)·Fn^2.5 （Fn > 0.05 时）
6. **剩余阻力**：Rr = ½·ρ·S·Cr·V²
7. **总阻力**：Rt = Rf + Rr（form_factor = 1.0，裸体）
8. **总阻力系数**：Ct = Rt/(½·ρ·S·V²)

**关键设置**：湿表面积 S 使用几何验证值 5.42 m²（而非经验公式 S = π·B·L·(0.5+0.25·Cb) ≈ 4.42 m²），
因为 m1384 已证明经验式对回转体系统偏小约 18.5%。

## 5 注意点（踩过的坑/局限/适用范围）

### 5.1 剩余阻力模型的局限

平台使用的剩余阻力系数公式 `Cr = 0.002·(1+2·Cb)·Fn^2.5` 是**经验拟合**，无文献出处。
从验证结果看：
- 在 Fn = 0.46–0.76 范围内误差 ≤ 13.5%（可接受）
- 在 Fn = 0.92 时误差达 34.6%（不可接受）

**根因**：Fn^2.5 的幂次过高，导致高 Fn 区 Cr 增长过快。SUBOFF 作为回转体，其剩余阻力
主要来自黏性压差阻力（而非兴波阻力），Fn^2.5 的标度律并不适用。

### 5.2 湿表面积的影响

m1384 已证明经验式 `S = π·B·L·(0.5+0.25·Cb)` 对回转体系统偏小：
- 圆柱（Cb = π/4）：−30.4%
- 长椭球（b/a = 0.25）：−20.2%
- SUBOFF（Cb = 0.542）：−18.5%

**建议**：调用阻力 API 时应传入 `wetted_surface_m2` 参数（几何验证值），而非依赖经验式。

### 5.3 HONEST-FAIL 声明

SUBOFF-04（Fn = 0.918）的 34.6% 误差**不是 bug**，而是模型适用域外的预期行为。
平台模块文档已声明："The residual-resistance coefficient Cr is an empirical curve fit
without a published provenance; it is exposed as-is but must not be quoted as a
literature-validated model."

### 5.4 DTMB-5415 与 KVLCC2 的验证欠账

`benchmark_reference.json` 中 DTMB-5415 和 KVLCC2 的所有工况均为 WITHHELD 状态
（数据自洽性未通过裁决门），因此**不能用于精度判定**。这是平台当前的主要验证欠账：
- DTMB-5415：航速与 Fn 列互不自洽，湿面积缺失
- KVLCC2：排水量与几何不自洽

需要后续任务补充经过裁决的参考数据。

## 6 误差判定：关键量 vs 基准

| 关键量 | 基准值 | 计算值 | 相对误差 | 是否 <15% |
|---|---|---|---|---|
| Ct (SUBOFF-01, Fn=0.459) | 0.0038 | 0.003462 | 8.9% | ✅ 是 |
| Ct (SUBOFF-02, Fn=0.612) | 0.0040 | 0.003953 | 1.2% | ✅ 是 |
| Ct (SUBOFF-03, Fn=0.765) | 0.0042 | 0.004766 | 13.5% | ✅ 是 |
| Ct (SUBOFF-04, Fn=0.918) | 0.0044 | 0.005921 | 34.6% | ❌ 否 |
| Cf (ITTC-1957, Re=1e7) | 0.003000 | 0.003000 | <0.0001% | ✅ 是 |

**结论**：在 Fn ≤ 0.77 范围内，平台阻力计算对 SUBOFF 的 Ct 误差 < 15%；
在 Fn = 0.92 时误差超限，属模型适用域外的 honest fail。
