## ① 案例介绍（物理背景 / 几何 / 参数）

操纵性是 IMO MSC.137(76) 强制验证的船舶总体性能域，其工程判据为回转圈（战术直径 ≤5L、
进距 ≤4.5L）与 10/10 Z 形首超越角（L/V>30 s 时 ≤20°/≤20°）。平台以 MMG 模型
（船体 + 螺旋桨 + 舵三分力）实现该域。基准船取 KVLCC2（公开标定船型），其几何先验
必须先自洽：Cb·L·B·T 与排水体积一致（误差 0.003%）。

| 量 | 值 | 来源 |
|---|---|---|
| Lpp / B / T | 320 / 58 / 20.8 m | KVLCC2 公开主尺度 |
| Cb / ∇ | 0.8098 / 312 622 m³ | 同上，Cb·L·B·T = 312 633 m³（自洽） |
| U0 | 15.5 kn = 7.973 m/s | 设计航速 |
| Dp / Ar / Hr | 9.86 m / 112.5 m² / 14 m | 桨径、舵面积、舵高（Λ=1.74） |
| 自航转速 | n = 1.363 rps | 由推力-阻力平衡反解（本参考实现） |
| 平台入参 | L,B,T,displacement,Cb,Dp,n,Ar,V0,rudder_angle | OpenAPI 必填项（探针按此构造） |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **平台探针**：按 `openapi.json` 的必填字段构造 KVLCC2 载荷，对两端口各取 3 个舵角
   （5°/15°/35°）共 6 次请求，记录 HTTP 状态与响应体。
2. **根因只读复现**：`importlib` 加载外部仓库模块（**不修改、不落盘**），直接构造
   `TurningTestInput` 并调用 `simulate_turning_test`，捕获异常类型与字段缺失信息。
3. **shadow 复算（内存补丁）**：把源码读入内存、文本注入缺失字段 `Hr` 后 `exec` 成影子模块，
   使被 500 阻断的数值路径可被执行，从而取证"指标是否伪造"——外部仓库零改动。
4. **伪造式识别**：对平台 `T = L/(2V0)` 做恒等式检验（换尺度的 3 组参数）；用非物理输入
   （Cb=0.05 / Ar=1 m² / Ar=500 m²）检验 `straight_stability` 是否恒真；解析比较平台舵升力式
   `Cl = 2πα/(1+2/Ar)` 与 Fujii(1960) 展弦比饱和式。
5. **独立参考实现**（`mmg_ref.py`，不依赖平台）：MMG 标准型 3-DOF 方程
   `(m+m_x)u̇-(m+m_y)vr=X`、`(m+m_y)v̇+(m+m_x)ur=Y`、`(I_zz+J_zz)ṙ=N`，RK4 时域积分；
   稳态回转用 Newton 解代数方程 `X=Y=N=0`（与时间推进互为**独立**校验）；sway-yaw 2-DOF
   线性化闭式解给出特征根与 course-stability 判定量 `D=Y_vN_r−N_v(Y_r−m u0)`；
   舵法向力用 Fujii 展弦比饱和式。导数表为**声明式标定假设**（`calibrate.py` 网格
   (N'_r, x'_H) 标定，目标 td≈3L、10/10 首超越≈15°）。
6. **量纲自洽加固**（本轮实测踩坑，见 ⑤）：力/力矩/质量/惯量四个因子由
   `Mass0·U0²/L = F0` 链条约束，并与 Cb·L·B·T、自航平衡逐项对齐。

FastAPI 返回 500。**这是一行修复（补 `Hr`）即可解除整域瘫痪的失效**，但源码属外部仓库

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **单位/因子链条坑（本轮实测踩到三次）**：MMG 无量纲化中力/力矩/质量/惯量四个因子必须满足
   `Mass0·U0²/L = F0`。首版把力因子写成 `0.5ρL²TU0²`（多乘一个 L，舵力整体偏大 320 倍），
   修正后又出现阻力常数化（`R0'` 不随合速度变化）导致长时航速塌陷——两次都被"自航平衡残差
   <1e-8"与"ΣF 量级对齐 1.96 MN"这两条判据抓出。**结论：先立量纲判据，再谈标定。**
2. **线性化耦合项量纲坑**：舵攻角 `α = δ − v_R/u_R` 对 v 的偏导是 `−γ_R/u_R`（单位 1/(m/s)），
   漏掉 `1/u_R` 会使线性模型把 Y_v 放大近 10 倍，进而把"稳定"判成"不稳定"。
3. **参考模型未完成绝对标定（本轮最大局限）**：虽在短时域给出合规的回转圈（3.20L）与 Z 形
   （11.78°），但长时推进出现 **漂角锁死**（u→0、β→90°），使：
   - Newton 代数稳态 vs RK4 时域推进误差 **43.9%（未达 3%，honest FAIL）**；
   - δ=2° 时线性闭式稳态增益 vs 非线性稳态 **相差 594%（honest FAIL）**。
   因此本轮**不对平台回转直径/Z 形指标作绝对准确度判决**（该两项在平台侧本就 500，
   属 WITHHELD）；参考模型目前只能支撑"判据级/量级级"结论。根因已定位：舵/桨干扰与漂角
   非线性项（Y'_vvv…）在中等漂角下压过线性项，且定转速推进在锁死状态下无法提供足够的
   向心补充推力。修复路线见 ⑥ 建议。
4. **只读边界**：外部仓库（`:8001` 源码）未修改一个字节；shadow 补丁仅存在内存副本中，
   因此"平台指标"栏的数值是**取证性复算**，不等于平台当前可返回的结果（平台当前一律 500）。
5. **适用性**：本报告的 A 类结论（500 根因、`T=L/(2V0)` 恒等式、稳定性恒真、舵升力式量纲错位）
   与参考模型的绝对精度无关，可直接作为修复验收判据；B/C 类结论（回转/超越量级）仅在
   量级意义上成立。

**诚实声明**：本报告的实质增量是"**把操纵性域从未审计推进到有判决**"——判死平台两端口
（6/6 全 500）、定位到一行根因（漏传 `Hr`）、并用恒等式/量级判据证明 `T`、`straight_stability`、
`dynamic_stability`、舵升力式四处为**伪造或量纲错位**。参考模型侧 B1/B2 两项自洽校验
**未通过（43.9% / 594%）**，按纪律如实登记为 honest FAIL，不粉饰；这也正是"参考模型尚不能
用于绝对准确度判决"的证据。
