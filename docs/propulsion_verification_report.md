## 1. 案例介绍

平台此前只有阻力（`calc.resistance`）与稳性（`calc.stability`）两个学科的真实算法；**推进（propulsion）在本仓内没有任何实现**，开放水域效率与自航点仅能经由外部船体服务（:8001/:8002）访问，且无本仓验证证据。本单补齐推进学科的最小可用闭环：致动盘动量理论 → 开放水域曲线 → 船机桨平衡自航点 → 准推进系数，并附 IMO EEDI 计算。

## 2. 方法与工具链

实现：`backend/services/propulsion.py`；HTTP 端点：`POST /api/v1/calculations/propulsion/actuator_disk`、`POST /api/v1/calculations/propulsion/self_propulsion`。

1. 致动盘：由 `T = 2ρA v_a (V+v_a)` 闭式解 v_a（二次方程），并与无量纲解析根 `x=(√(1+C_T)−1)/2` 两条独立路径互校；`η_i = 2/(1+√(1+C_T))`（Lanchester–Glauert）。
2. 开放水域：`η_O = J K_T/(2π K_Q)` 与 `P_E/P_D` 两种算法互校。
3. 自航点：对 `f(n)=ρ n² D⁴ K_T(V_a/(nD)) − R_T/(1−t)` 二分求解，轴功率 `P_D = 2π n Q/η_R`，准推进系数 `η_D = η_O η_R (1−t)/(1−w)`。
4. EEDI：IMO MEPC.308(73) attained EEDI 算术链。
5. 测试：`backend/tests/test_propulsion.py`（33 个 test 函数）、`backend/tests/test_propulsion_api.py`（HTTP 契约）。

## 5. 注意点与局限

- **η_O 的绝对精度未被断言**：K_T/K_Q 曲线是调用方输入（本算例用一组自洽的二次多项式，η_O 峰值 0.5968 @ J=0.60）。模块只保证：曲线 → η_O 的定义恒等式、J→0 时 η_O→0、零推力点 η_O=0、代码内部 η_O < 致动盘理想上界。把 B 系列回归系数接进来即可升级为对水池试验的验证，但本单**没有**伪造任何试验值。
- **伴流分数/推力减额是输入而非平台拟合**：w、t 的绝对值来源（模型试验或经验公式）由调用方负责，本模块只做力平衡与效率链。
- **t 与 w 的大小关系**：本算例 t=0.18 < w=0.28，因此 η_D 高于 η_O（比值 η_R(1−t)/(1−w) = 1.1389）；这是船身-螺旋桨相互作用的正常结果，不是效率越界（效率上界由致动盘理想值守住）。
- **η_R 的处理**：轴功率按 `P_D = 2π n Q_open/η_R` 折算，否则 `η_D = η_O η_R (1−t)/(1−w)` 这根恒等式不成立（首版踩过这个坑，测试 `test_relative_rotative_efficiency_scales_eta_d` 守住）。
- **自航点求解有物理上限**：`n_max_hard=100 rps`，超出即抛 `ValueError`（HTTP 400），避免弱曲线在二分里边扩边跑不停。
- **阻力链继承既有偏差**：自航点用的 R_T 来自平台 SUBOFF 简化阻力模型；该项在高 Fn（>0.30）相对实验低估 3–35%（另一单的结论），因此 P_E/P_D 的绝对值继承同一偏差，本报告不重复宣称阻力精度。
- **未做**：水池试验对标（无数据源）、B 系列多项式回归、空泡/伴流不均匀性、齿轮箱与轴系损失（SFC/传动效率未建模，EEDI 仅算术链）。
